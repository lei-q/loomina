# 声音：第二条表演线

> 核心判断：**声音不是后期补丁，是和画面并行的第二条表演线。**
> 对白是主角，音乐和音效是配角；混音的第一优先级永远是"台词听得清"。

---

## 一、先看短剧的听觉环境

短剧不是影院，是手机外放：

- **单声道近似**：很多场景就是一只扬声器，立体声信息大量丢失。
- **低频缺失**：手机放不出 60Hz 以下，靠低频营造的"氛围"基本无效。
- **环境嘈杂**：地铁、街道、办公室，观众听不全。
- **可能静音**：大量用户刷视频不开声音。

由此得到三条硬约束：

1. **信息必须双通道**：字幕能独立看懂，声音能独立听懂。
2. **中频是主战场**：人声、主要音效要落在中频。
3. **不要依赖低频和细微层次**：那是在为耳机用户做片子。

---

## 二、声音的四层，各司其职

| 层 | 职责 | 典型手段 |
| --- | --- | --- |
| **对白** | 信息 + 表演 | 配音、气口、重音、停顿 |
| **音乐** | 情绪 + 节奏 | 情绪曲线、主题动机、卡点 |
| **音效** | 真实感 + 强调 | foley、强调音、画外音 |
| **环境** | 空间 + 时间 | 房间底噪、街声、雨声 |

四层不是"都加上就丰富"，而是**每层只做一件事**。层与层抢频段，就是混音灾难的开始。

---

## 三、配音不是朗读

TTS 默认产出是"平"的：没有气口、句尾走向不对、情绪标签假。要把配音当成表演来调，逐句给参数：

| 参数 | 作用 |
| --- | --- |
| 音色 / 年龄感 | 角色识别 |
| 口音 / 地域 | 人物背景 |
| 语速 | 情绪与紧迫度 |
| 音高 | 紧张/放松 |
| 音量 | 强弱对比 |
| 气声比例 | 亲密/虚弱/危险 |
| 停顿 | 思考、犹豫、压迫 |
| 重音位置 | 决定句子的意思 |
| 句尾走向 | 上扬=疑问/挑衅，下沉=确定/失望 |
| 呼吸 | 活着的感觉 |

**一句台词的意思，一半在重音落在哪个字上。** 这是纯文本 TTS 最容易丢、也最值得产品化的地方。

可用手段：

- 逐句参数（SSML 风格）+ 情绪标签；
- 参考音频克隆（需本人授权，见合规）；
- 人工微调：拖动重音、加气口、改停顿；
- 多 Take：同一句给 3 个读法让用户选。

---

## 四、配音表演要和画面表演对齐

声音的节拍必须和 [PERFORMANCE.md](PERFORMANCE.md) 的表演节拍咬合：

- **台词前**留 0.3–0.5s 反应（画面在演"听到"）。
- **台词中**气口、重音与表情/动作对齐。
- **台词后**留 0.5s 余韵（画面在演"消化"）。
- **哭腔 / 笑 / 喘**要单独分段，不要混在一句里让模型猜。
- 口型只在特写启用；中景用侧背、遮挡、反应镜头规避。

**顺序仍然是音频先行（P5）**：先有配音时长，才有镜头时长；画面去适配声音，不是反过来。

---

## 五、音乐：跟情绪曲线走，不要从头铺到尾

### 情绪曲线 → 音乐状态

每个 Beat 对应一个音乐状态，只做三件事：**进、转、出**。

| Beat | 音乐动作 |
| --- | --- |
| hook | 进来就要有（或故意留白制造不安） |
| setup | 低存在感铺底 |
| escalation | 加层/加节奏 |
| turn | 突变或抽空 |
| climax | 最强点 |
| endHook | 收住，留一个未解决的和声 |

### 主题动机（leitmotif）

给角色、关系、地点各一个短动机，重复与变奏。这是"高级感"最便宜的来源，也让系列有记忆点。

### 三条纪律

1. **留白**：不是每一秒都要有音乐；安静比铺满更有力。
2. **不盖对白**：台词期间音乐必须让路（见混音）。
3. **卡点服务剪辑**：BPM → 切点建议，但不要为了卡点破坏表演节奏。

### 版权

- 生成音乐：确认商用条款与训练数据合规。
- 曲库：授权范围要覆盖"用户生成内容 + 商业发布"。
- 用户上传：需权利声明。

## 六、音效：补画面省掉的信息

- **foley**：脚步、开门、放下杯子、衣物摩擦——让画面"有重量"。
- **强调音**：打脸、心跳、耳鸣、闪回 whoosh——短剧的"标点符号"。
- **画外音**：门外脚步、警笛、手机震动——用声音扩展画外空间，比多拍一个镜头便宜。
- **空间感**：混响必须匹配场景。卧室不该像大厅，街道不该像录音棚。

**音效密度要克制。** 每个动作都配音效，会变成广播剧；只给"有意义的动作"配音。

---

## 七、混音：对白优先

| 元素 | 目标 |
| --- | --- |
| 对白 | 最清晰，中频突出 |
| 音乐（台词下） | 比对白低 12–18 dB，或用 sidechain ducking |
| 音效 | 不遮对白字头 |
| 整体响度 | −14 LUFS 左右（平台常见） |
| 真峰值 | ≤ −1 dBTP，避免削波 |
| 单声道兼容 | 必须检查；手机外放下不能有人声消失 |

**验收标准不是"听起来专业"，而是"手机外放、嘈杂环境下，台词每个字都听得清"。**

**当前实现（2026-11-11，ADR-0099）**：

- 配乐只有一条床：作者导入本地文件（≤18 MB），标情绪与授权来源，默认循环铺满全片。
- Ducking 用已知台词窗（这一版时间线里有音轨的台词，间隔 ≤500ms 合并），生成写死的 `volume` 表达式：压深就是界面上的 12–18 dB，台词前 200ms 起坡、结束后 300ms 抬回。不用 sidechain，因为压缩量会随对白电平漂。
- 对白与音乐各成一条总线再 `amix`（`normalize=0`），混音单独输出 48k 立体声 PCM。
- 两遍 loudnorm：先量 `input_i / input_tp / input_lra / input_thresh`，再以 `linear=true` 归一到 I=−14、TP=−1.5（给 AAC 留 0.5 dB，成片仍 ≤−1 dBTP）。
- 编码后再测成片集成响度、真峰值与 `aphasemeter` 反相 / 单声道时长。偏离 ±1 LU 或真峰值 >−1 dBTP → 不交付；反相 >500ms → 交付但标「需复核」；量不到 → 写「未测」。
- **未做**：音效层与空间混响、按段落换曲（C10）、分段响度、自动二次归一、5.1。

---

## 八、声音的一致性

和画面一样，声音也要跨镜头、跨集一致：

- **角色音色**：`VoiceProfile` 固定，跨集不变。
- **空间混响**：同场景同一套 reverb 参数。
- **音乐风格**：服从 `StyleProfile`，不每集换一种。
- **响度**：整片统一，不能一段大一段小。

---

## 九、声音 QA

| 检查 | 方法 | 失败处理 |
| --- | --- | --- |
| 对白清晰度 | 手机外放试听 + 频谱检查 | 提中频 / 降音乐 |
| 响度/削波 | LUFS + true peak | 重新混音 |
| 音画同步 | 对白 ±40ms 内 | 微调 offset |
| 情绪匹配 | 人工 + 模型判断 | 换 Take / 调参数 |
| 静音可懂 | 关声音看字幕 | 补字幕信息 |
| 空间一致 | 混响与场景比对 | 统一 reverb |
| 版权授权 | 元数据检查 | 阻断发布 |

## 十、失败模式

| 失败 | 表现 | 原因 | 对策 |
| --- | --- | --- | --- |
| TTS 平 | 像念稿 | 无气口/重音 | 逐句参数 + 多 Take |
| 音乐盖对白 | 听不清台词 | 没做 ducking | 对白优先混音 |
| 音效过密 | 像广播剧 | 每个动作都配音 | 只给有意义动作 |
| 空间错 | 卧室像大厅 | reverb 未匹配 | 场景混响预设 |
| 响度跳 | 一段大一段小 | 分段生成未统一 | 整片响度归一 |
| 静音看不懂 | 关声音不知所云 | 字幕依赖声音 | 字幕独立承载信息 |
| 音色变 | 跨集像换人 | 未固定 VoiceProfile | 音色资产锁定 |
| 版权风险 | 音乐/音色来路不明 | 未做授权检查 | 元数据 + 阻断 |

## 十一、IR 映射

```ts
interface VoiceProfile {
  characterId: ID;
  timbre: string;
  age: string;
  accent?: string;
  basePitch: number;
  consentRef?: ID;          // 声音授权记录
}

interface LinePerformance {
  dialogueLineId: ID;
  voiceProfileId: ID;
  rate: number;             // 0.5–2.0
  pitch: number;            // 半音偏移
  volume: number;
  breathiness: number;      // 0–1
  emphasis: { text: string; strength: number }[];
  pauses: { afterChar: number; ms: number }[];
  emotion: string;
  takes: ID[];
}

interface MusicCue {
  id: ID;
  startMs: number;
  endMs: number;
  role: "bed" | "hit" | "transition" | "silence";
  mood: string;
  motifId?: ID;
  duckUnderDialogue: boolean;
  licenseRef?: ID;
}

interface SfxCue {
  id: ID;
  atMs: number;
  kind: "foley" | "accent" | "offscreen" | "transition";
  assetId: ID;
  gainDb: number;
}

interface MixSpec {
  dialogueLufs: number;
  musicUnderDialogueDb: number;
  masterLufs: number;       // ≈ −14
  truePeakDb: number;       // ≤ −1
  monoCompatible: boolean;
}
```

**新增不变量**

25. **每条对白必须有 `VoiceProfile` 与 `LinePerformance`**，否则不得生成配音。*落地口径（ADR-0124）：两者都是可选字段，缺失按默认值处理；参数影响下一次出声，不阻断既有音轨的使用。*
26. **台词期间音乐必须 ducking**；未经 ducking 的音乐不得进入混音。
27. **成片必须通过响度与真峰值检查**（≈ −14 LUFS / ≤ −1 dBTP）。
28. **所有音乐/音色资产必须有授权引用**；无授权不得发布。
29. **静音观看时字幕必须能独立传达剧情信息**。

**落地形态（C2 / C9 / C10，ADR-0124 / ADR-0125，2026-11-11）**

- 逐句表演参数是 `DialogueLine.performance?: VoicePerformance`（rate / pitch / volume / breathiness / emphasis / pauses / emotion / ending），走既有 `dialogue.updated`。重音与停顿**按字符区间**定位，不按文本匹配——重复词有歧义，改一个字会让按文本定位的重音静默失效。
- 多 Take 走独立试听台 `Project.voiceTakes`，`audioAssetId` 仍是「当前采用的那条」；配音 Take 不进 `DialogueLine`，避开 ADR-0085 担心的语义混淆。
- **不假设供应商支持 SSML**：`rate` 映射请求体 `speed`，情绪类拼进 `instructions`；`emphasis` 与 `breathiness` 第一版只进 IR 与提示词，不承诺生效，界面如实标注。
- 音乐曲线（`analyzeMusicCurve`）是派生的，不进 IR；`MusicCue` 新增 `role` / `motifId`；主题动机 `Project.motifs` 进 IR（同一目标只许一个）。
- 留白不建实体：没有 cue 就是留白，不新增 `silence` 角色——空 cue 会让「忘了铺」与「故意留白」看起来一样。
- **仍受 TTS 403 阻塞**：参数能存、能编辑、能回放，出声路径待分组授权后才能端到端验证。


---

## 十二、一句话

**对白是主角，音乐和音效是配角。**
配音是表演不是朗读，音乐跟情绪曲线走而不是铺满，音效只补有意义的信息，混音永远先保住台词。
