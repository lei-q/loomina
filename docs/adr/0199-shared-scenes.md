# ADR-0199：跨空间取一场剧本（C24）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C.1、C1、C16、C17、C20、C21、C22、C23、ADR-0197、ADR-0198

## 背景

用户清单 C.1 要求「故事、剧本……都可加入资产库并复用，跨集直接复用同类场景」。
到 ADR-0198 为止：故事能跨空间取，素材能逐个取，但**剧本结构本身**（场 / 镜 / 台词）
还不能跨空间搬——同类场景（走廊、门口、桌边）每一集都要重写一遍分镜与台词。

剧本比故事多三样东西，直接搬会出事：

1. **id 引用**：场指向地点，镜指向演员 / 道具，台词指向说话人；两边 id 各自编。
2. **成片痕迹**：镜头上挂着 take、关键帧、锁定状态，都属于来源空间的制作进度。
3. **半场风险**：搬一半才发现缺人缺地点，回来要一条条修。

## 决定

1. **剧本页多一个入口**：页头「从别的空间取一场」。
   打开时才回放本机其它工作空间日志（`loadWorkspaceProjects`），列出所有场次：
   `第 N 场 · 地点 · 第一镜动作或第一句台词` + `空间名 · X 镜 · Y 句`；
   能整场取的排前面。

2. **地点与演员必须同名同 id，否则整场拒绝**
   - 地点：来源场的地点在当前空间要有同 id 同名的一条，否则缺「地点「走廊」」。
   - 演员：镜头的 `characterIds` 与台词的 `characterId` 里出现的每一个人，
     都要在当前空间同名同 id；缺一个人就整场不能取。
   - 道具宽松：对不上的道具只摘引用，行内先说「缺道具「台灯」只摘引用」。
   - 不做模糊匹配：猜错一次就是把别人的人写进自己的场。

3. **取用 = 一批事件**
   - `scene.added`（追加到末尾）→ 逐镜 `shot.added` → 逐句 `dialogue.added`。
   - 所有 id 重编：`sc-<tag>` / `s-<tag>-<镜序>` / `d-<tag>-<镜序>-<句序>`，
     `tag` 是这次取用的短标记；与本空间已有 id 撞了就补 `x`。
   - 同一批事件共用一个 `at`，正好落进 F2 的「同毫秒一组」：撤销一步整场退回。
   - 先在草稿上整批 `applyEvent` 回放，全部通过才写进状态：不落半场。
   - 不调模型、不花钱、不新增事件类型、不改 `LOG_VERSION`。

4. **只取剧本结构**
   - 镜头字段（动作、景别、机位、光影、构图、调度、走位、节拍、目的、表演、接续、
     时长、出场人物、道具）原样带；
   - `takeIds`、`keyframes`、`dialogueIds` 清空；关键帧与成片不跟；
   - 台词保留文字、时长、断句偏移与译文，**不带** `audioAssetId` 与配音 take
     （那是另一个空间花钱录的，要用来 C21 取）；
   - `locked` 一律改成 `false`：取来的是这一集的初稿，不是别的空间已经锁死的镜头。

5. **反馈**
   - 清单里先写清缺什么（缺人 / 缺地点 / 缺道具）；
   - 失败时保留对话框并显示 `castError`（「这一场取不过来：本空间缺 …」）；
   - 成功时按钮下方写「已取用「夜班」的第 1 场：3 镜 · 2 句。关键帧、take 与配音没有跟过来。」

## 理由

- **整场为最小单位**：场是剧本里作者真正在写的东西；按镜取会得到一堆没头没尾的镜头。
- **id 全重编**：跨空间保留原 id 必然撞车（两个空间都从示例项目长出来），
  而且撞了之后分不清「同一个人」还是「两个恰好同名的人」。
- **同毫秒一批**：F2 已经用「同毫秒」表示一次操作，取一场天然就是一步，撤销不用新概念。
- **不带成片**：take / 关键帧 / 配音是花钱的资产，跨空间要取用有各自的入口
  （C20 / C16 / C21），不该混在「取剧本」里顺带复制。

## 后果

**正面**

- 同类场景的分镜与台词可以整场搬过来，改几处就成新的一集。
- 缺人缺地点在取之前就写在行里，不会取回半场。
- 整场事件共用 `at`，撤销一步退回；日志清清爽爽，没有「导入快照」这种黑盒。

**负面 / 代价**

- 只要有一个演员对不上就整场不能取；跨不同模板的空间大多对不上，需要先在定妆页
  用 C17 把演员取过来。
- 关键帧、take、配音不跟，取来的场要重新出片、重新配音。
- 锁定的镜头取过来会解锁；来源空间的锁定状态不保留。
- 场次编号按当前项目重排；来源的显式场号（`2A` 之类）会带过来，可能与现有场号视觉重复。
- 一次只取一场，没有「整本剧本一起取」。
- 道具对不上就摘引用，不拦；作者可能没注意到某个关键道具没跟过来。
