# ADR-0049 动作文案：点一下就地改，仍走 shot.updated

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0043（剧本页）、ADR-0044（台词改写）、FEATURES A21

## 背景

剧本页上，动作是每一镜的正文：观众看到什么、提示词也由它拼出来。之前它只是被摊平显示，想改一个字得去分镜页；A21 的负面清单里一直写着「动作只读」。IR 里动作就是 `Shot.description`，`shot.updated` 的 patch 本来就允许改它，缺的只是一条 store 动作与一个入口。

## 决策

1. **不加事件、不加字段**：改动作写一条 `shot.updated { patch: { description } }`。`description` 已经是 IR 里的正式字段，回放、提示词、导出都读它。
2. **store `editAction(shotId, text)`**：
   - 只读标签页、锁定镜头都拒绝并说明原因；
   - 去掉行尾空白后为空则拒绝（「动作不能是空的。」）——这一镜的正文不能是空白；
   - 与原文相同不写事件（「动作没改。」）；
   - 成功写一条事件，时间戳一次。
3. **时长不动**：动作是画面描述，不参与 `durationMs` 的估算；改字不改秒。
4. **入口是动作本身**：动作段落整块做成按钮，点一下就地变成文本框，`保存` / `取消`，⌘↩ 保存、Esc 取消。不额外挂一个小「改」按钮——每镜一个按钮会让十二镜的页面多出一排噪声；动作文字本身就是最自然的目标。
5. **锁定与只读**：动作按钮置灰，悬停说明「这一镜已锁定，先解锁才能改动作」；只读标签页同样不可点。

## 理由

- **最少的机制**：字段已经存在、事件已经存在，「改动作」是把已有能力接到界面上，不是新造一层。
- **点正文而不是点按钮**：剧本里动作是连续阅读的段落，给它单独的编辑按钮会把阅读节奏切碎；点哪里改哪里更接近纸面剧本的经验。
- **不联动时长**：按 P5，镜头时长由台词与音频决定，动作不是计时单位；硬估一个动作时长只会制造假精确。
- **与台词编辑同一套键位**：⌘↩ 保存、Esc 取消，同一个页面里两种编辑行为一致。

## 后果

**正面**
- SH-01 动作从「走廊尽头，灯管闪了一下」改成「…闪了两下」：页面立刻更新，页头 5 场 / 12 镜 / 6 句台词 / 35.6s 全部不动；日志只多一条 `shot.updated { description }`。
- 改动作不再需要跳到分镜页，剧本页的「动作只读」收口。
- 锁定镜头与只读标签页都有明确的拒绝理由，不静默失败。
- 测试：web 115 条（新增 3 条：改写与回放、锁定、空 / 未改 / 只读）；IR 60、gateway 17、pipeline 21 不变，合计 213。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：headless Chrome 点动作 → 改字 → 保存；IndexedDB 第 18 条为 `shot.updated { description: "走廊尽头，灯管闪了两下。" }`。

**负面**
- **没有动作的历史**：台词有「改过 n 次 / 用这版」，动作没有；改错了只能手打回去，或翻日志。
- **一次只能改一镜**：不能批量替换用词，也不能跨镜头复制同一句动作。
- **空动作不可保存**：想清空一镜的动作做不到；要留白只能写一句占位。
- **没有提示词预览**：动作改了以后提示词会变，但页面上看不到新提示词。
- **动作与场次描述没有联动**：改了这一镜的动作，场头的地点与日夜不会跟着变。

**跟进**
- 动作的版本历史（复用 `dialogueHistory` 的思路，按 `shot.updated` 里的 `description` 取）。
- 下游产物（提示词、已生成的首尾帧）在动作改动后标记过期。
- 场次本身的编辑：内 / 外景与日夜。
- 空动作的显式表达（「无动作」而不是禁止保存）。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 新开 `shot.description.updated` 事件 | `shot.updated` 的 patch 已覆盖，多一种事件只会让白名单与回放更啰嗦 |
| 在动作旁加一个小「改」按钮 | 十二镜多十二个按钮，噪声大于收益 |
| 在弹窗里改 | 上下文被遮住，改一句动作要开一次弹窗 |
| 顺带按字数重估镜头时长 | 动作不是计时单位，估出来的是假精确，还会破坏 P5 的「时长 ≈ 台词 + 余量」 |
| 允许存空动作 | 这一镜的正文没了，提示词与导出会留一行空白；要留白应显式表达 |
