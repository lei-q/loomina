# ADR-0008 合规与 AI 标识内建（Compliance by default）

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P9、H5、H6、R1、R2、R3

## 背景

面向中国大陆公众提供生成式 AI 服务，合规不是"上线前补一张表"，而是会影响数据模型、导出管线、审核流程、甚至产品形态。如果在后期才补：

- 导出文件缺少标识，需全量重渲染；
- 审核接口不在主链路，违规内容会直接外泄；
- 授权记录缺失，无法应对肖像权/版权争议。

## 决策

合规能力在**架构层内建**：

1. **AI 标识**：AILabel 进入 Project IR 与 PublishPackage；导出时写入显式标识（画面/简介）与隐式标识（文件元数据）。
2. **内容安全**：生成前（提示词/剧本）+ 生成后（图/视频抽帧）双检，走统一审核服务。
3. **授权留痕**：素材、肖像、声音的使用记录可追溯（H7）。
4. **数据权利**：用户可导出、删除项目与数据（H9）。
5. **最小化收集**：只收集必要个人信息。

> 具体适用法规与申报口径（生成式 AI 服务备案、算法备案、内容标识等）以主管部门最新要求为准；本文只固定"必须内建"这一架构原则。

## 理由

- 改造既有管线的成本远高于一开始就内建。
- 平台与监管对 AI 内容的标识要求越来越明确，这是准入门槛。
- 授权链是内容型产品的诉讼防线。

## 后果

**正面**
- 上线路径清晰，避免返工。
- 对外可讲"合规"，对 B 端/平台合作是加分项。

**负面 / 代价**
- 审核会带来延迟与成本。
- 隐性标识可能影响部分下游工具，需要兼容测试。

**跟进**
- 尽早确认属地网信办口径与所需资质。
- 审核服务需有降级策略（不可用时应阻断发布，而不是放行）。

## 替代方案

- **上线前集中治理**：返工大、风险高，否决。
- **只在发布环节打标**：无法覆盖中间产物与外泄，否决。
