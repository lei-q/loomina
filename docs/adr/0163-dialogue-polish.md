# ADR-0163：台词压缩与金句

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：A20、A5、A18、A2、C13、准则 P2 / P3 / P8 / P15

## 背景

短剧的台词只有两个任务：把信息压到最短，把该响的那一句留到最后。作者
在剧本页能逐句改台词（A5），剧本医生（A18）会报「台词效率」偏低，但
这两处都只给一个分数或一句方向，**没有告诉作者哪一句该删什么字**。

实测样本里最常见的三种病：

| 病 | 例子 | 20 字里删掉 |
| --- | --- | --- |
| 填充词开头 | 「其实我觉得你现在应该先回去把合同签了再走」 | 「其实我觉得」「应该」→ 13 字 |
| 解释性从句 | 「你先把合同放下，因为签字的人根本不是我」 | 「因为……」整段 → 7 字 |
| 一镜塞两句以上 | 一镜三句，每句都要 3–4 秒 | 镜长撑到 12 秒以上 |

短剧一镜 2–5 秒，单句超过 15 字就读不完；一镜两句以上，观众的耳朵跟不上
画面。这两条是 STORY.md 里已有的口径，但一直没有工具落地。

## 决定

1. **纯规则、纯派生、不调模型**
   - 新增 `apps/web/lib/dialogue-polish.ts`：`compressLine`、`punchScore`、
     `polishDialogue`，全部是纯函数。
   - 报告不进 IR：它是当前剧本的函数，关掉抽屉就没了，采用一条建议才写
     一条 `dialogue.updated`。

2. **压缩只做「删」，不做「写」**
   三步，依次尝试，任一成功即停：
   - 删填充词（其实 / 我觉得 / 你知道 / 然后 / 真的 / 可能 / 应该 / 反正……）；
   - 删含解释引导词（因为 / 所以 / 如果 / 虽然 / 但是 / 而且 / 于是 / 结果）
     的那一段，留主句；
   - 留最后半句——短剧的响点通常在句尾。

   三步都压不进 15 字时**不给文本，只给方向**（「整句拆成两句，或把说明
   改成动作」）。硬截断会毁掉原意，作者还得从头想。

3. **金句分只回答「像不像一句能被记住的短台词」**
   基线 40 分，按可解释项加减：字数（≤8 +20 / ≤12 +12 / >16 −15）、
   落点词（凭什么 / 不可能 / 滚 / 闭嘴 / 真相 / 签字 / 监控 / 报警……）、
   句末标点、具体物件、填充词（每条 −8，最多 −24）、引号。
   分数不写 IR、不阻断生成，只决定「金句候选」里谁排前面。

4. **界面：剧本页顶栏「台词」抽屉**
   - 顶栏按钮带要改句数徽标，与「医生」并列，不占额外一行。
   - 抽屉三区：要压的句子（建议文本 + 「用这版」）、金句候选（只标不改）、
     一镜多句（给拆 / 删方向 + 「去这一镜」）。
   - 「用这版」走既有的 `editDialogue`，锁镜 / 只读 / 空文本校验原样保留，
     时长按新字数重估，历史里能看到上一版。
   - 顶部一张汇总：压完能省多少字、几句要改、几句金句候选、几镜两句以上。

5. **阈值写成常量并对外暴露**
   `MAX_LINE_CHARS = 15`、`MAX_LINES_PER_SHOT = 2`、`PUNCH_LINE = 70`。
   C13（静音可懂度）会复用同一个 15 字口径，不再各写一套。

## 理由

- **先删再改**：作者不缺「再写一版」的能力，缺的是「这句里哪个词是废话」
  的判断。删字比写新句子便宜，也不改变人物语气。
- **不猜语境**：规则读不懂「其实」有时是人物性格。所以建议只在作者点
  「用这版」时落库，工具不自动改写。
- **可解释**：每条建议都带理由（「删掉填充词，20 → 13 字」），作者不同意
  能直接看出来为什么。
- **不新增依赖、不花钱**：本地字符串处理，毫秒级，离线可用。

## 后果

**正面**

- 剧本页第一次能回答「这句该删什么」，而不只是「台词效率 62 分」。
- 一镜两句以上从「感觉有点挤」变成一行明确读数。
- 15 字 / 2 句的口径被抽成常量，C13 静音可懂度可直接复用。
- 全派生：旧项目、旧事件、旧日志不需要迁移。

**负面 / 代价**

- 规则读不懂反讽、留白与人物口癖：一句「其实」可能是伏笔，被标成废话。
  界面已写明「规则只看字数、填充词与解释词」。
- 压不进 15 字时只给方向，作者仍要自己想；这是有意为之，不是缺陷。
- 金句分是启发式：它偏爱短句与落点词，会漏掉长而有力的句子。
- 删台词会牵动镜头时长与已出的配音，工具不自动删——只在「一镜多句」里给方向。

**不做**

- 自动改写、自动删句、批量采用。
- 调模型做「台词重写」（那会改变人物语气，且要花钱）。
- 按题材 / 平台 / 角色标定阈值（归 I9 评测集）。
- 金句历史、跨项目对比、把分数做成硬闸门。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 交给模型逐句重写 | 改变人物语气、要花钱、要等；作者只想知道删哪个词 |
| 超过 15 字直接截断到 15 字 | 会毁掉原意，作者还得从头想 |
| 把建议直接写进 IR | 规则会误判，作者没确认就改台词不可接受 |
| 只在剧本医生里加一维 | 医生给的是整片分数，作者要的是逐句该删什么 |
| 一镜两句以上自动拆镜 | 拆镜会改变节奏与已出帧，工具不替作者做这个决定 |
