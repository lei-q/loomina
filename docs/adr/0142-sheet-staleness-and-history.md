# ADR-0142 定妆四格的过期标记与旧版回退

- 状态：已接受
- 日期：2026-11-12
- 决策人：用户 + Claude
- 关联：ADR-0028（三视图）、ADR-0031（定妆出图）、ADR-0057（关键帧过期）、ADR-0075（主镜过期）、ADR-0082（文本按版回退）、B1、B14、H3

## 背景

四格三视图是整个项目的**一致性锚点**：以后每一镜的人物长相都从这几张图里来。B1 一直挂着两条：四格一致性检查、清单历史回退。

两个问题都很具体：

- 改过外形描述（「剪了短发」）之后，四格里还是旧发型，界面不说；作者以为新描述已经生效，直到成片里出现两种发型。
- 重出某一格时换了模型（或供应商换了默认模型），四张脸不是一个画风。这个更隐蔽：单看每张都像，摆在一起才不对。

历史回退同样有场景：重出一格，新图更差，想换回上一张——今天的「生成三视图」只能再花一次钱赌一次。

## 决策

1. **过期按格算，不按人算。** `staleSheetCells(events, project)` 拿每一格资产的 `createdAt` 与 `character.updated` 的时刻比：改过 `name` / `appearance` / `mustNotChange` 之后出的图不算过期，之前出的标出来，并列出原因。改名也算——名字进提示词。
2. **四格之间比一次模型。** 已有格子来自两个以上模型时，按数量取多数派，标少数派；两种各半时四格都标，原因写「四格生成模型不一致」。只比不拦，不改生成。
3. **只做派生，不加 IR 字段。** 过期与时序都能从事件日志与资产时间算出来；写进 IR 就多一份会漂移的事实（与 ADR-0057 / ADR-0075 同一原则）。
4. **旧版从日志回放。** `sheetAssetHistory(events)` 扫 `project.created` 与 `asset.updated`，同一个资产 id 出过哪几张；只留带 `uri` 的版本，按 uri 去重，当前版不算旧版，新的排前面。
5. **换回旧版只写一条 `asset.updated`。** 不重新生成、不花钱、不写新的资产 id；换回来的资产保留它**原本的** `createdAt` 与 provenance，所以它仍会按原生成时间被判断过期——这是事实，不该被一次「用这版」洗白。
6. **锁定即只读。** 定妆锁定后「用这版」禁用，与重新生成同一条规则；要换先解锁，解锁留痕（P14）。
7. **界面贴在格子上。** 过期是格子左上角一个品牌色小点，`title` 写原因；有旧版时图注下多一个 `历史 n`，展开一条横向缩略图带，`用这版` 一步换回。

## 理由

- **按格算才对**：作者常常只重出一格；按人算会把刚出的新图也标成过期，等于逼他四格全重出。
- **模型不一致值得说**：它不是错误，但它是四张脸不像的最常见原因；作者有权知道。
- **回放比新表可靠**：事件日志已经是唯一事实来源，再建一张「清单历史」表要同步、要迁移，还会与日志打架。
- **换版本不该花钱**：旧图字节还在资产库里，换的只是当前指向；把它当成一次生成来收费是抢钱。
- **保留原时间**：过期标记回答的是「这张图是不是按现在的设定出的」，换回旧图不改变这个答案。

## 后果

**正面**

- 改完外形立刻看见哪几格对不上，不用等成片。
- 单格重出失败或更差时，一条点击换回上一张，零成本。
- 四格模型不一致被点名，减少「每张都像、摆一起不像」。
- 没有新增 IR 字段，`LOG_VERSION` 不变。

**负面**

- **历史只在本地日志里**：清掉浏览器数据就没有旧版；对象存储里的旧对象也不保证还在（H3 清理会删没人引用的）。
- **只比时间，不比内容**：把描述改回原样，旧图仍被标过期——它确实是「改动之后」出的判断，重出一次才清掉。
- **模型比较只看少数派**：四个模型各一张时四格都标，界面会显得吵；这是刻意的，因为确实没有一个统一画风。
- **没有视觉相似度**：脸到底像不像仍要人看；embedding / pHash / VLM 留在 B14。

## 未做

- 按人物回收没人引用的旧图（现在走设置页「本机资产库」的全局清理，H3）。
- 四格的视觉相似度评分与人脸 embedding（B14）。
- 一次回退四格到同一轮生成（「整组用这版」）。
- 旧版备注（哪一版为什么被换掉）。

## 验证

- 单测 5 条（`read-model.test.ts`）：
  - 没改设定不标过期；
  - 改外形 / 名字 / 不许变之后，只标改动之前出的格子，原因为三条合一；
  - 改动之后重出的一格不因时间过期，换模型的那一格标「四格生成模型不一致」，其余三格只因时间过期；
  - `toCastView` 把过期挂到对应格子，周不受影响，不给日志就不算；
  - 旧版回放：当前版不算、按 uri 去重、新的在前；换回旧版后再回放，旧版集合随之变化；没有 uri 的示例占位没有历史。
- web 881 条全过；`tsc --noEmit` 与 `next build` 干净。
- 浏览器（`/cast`，示例项目）：给林的正脸灌两版带图资产（红 / 蓝 1×1 PNG）→ 刷新后正脸出现 `历史 1` → 展开写出「正面 · 旧版 1」→ 点「用这版」→ 正脸 `<img src>` 变成红色那一版，事件 17 → 18；把林的外形改成「剪了短发」→ 四格各出现一个「出图之后改过：外形描述」小点，周的四格没有。
