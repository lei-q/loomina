# ADR-0235：IR 增加 dutch 机位，A4 落地（I8 第三档）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：I8、A4、B13.2、ADR-0126、ADR-0216、ADR-0229、DIRECTOR-GRAMMAR.md §四

## 背景

ADR-0229 纠正过一条标注：A4「dutch 单场 ≤ 1」当时标着「可以查，但优先级低」，
实际上 **IR 的 `Camera.angle` 只有 `eye / low / high / top`，根本没有 dutch**，
要先扩枚举才能查。

这次把枚举补上。关键判断是：**dutch 与前四个不是同一类**。

- `eye / low / high / top` 讲的是「相机比主体高还是低」——是俯仰；
- `dutch` 讲的是「相机沿光轴滚转」——画面歪斜，与高度无关。

所以不能简单往枚举里塞一个值就完事：凡是用「档位顺序」表达俯仰的地方，
dutch 放进去都会算错。

## 决定

1. **`CAMERA_ANGLES` 成为唯一一份枚举**，从 `packages/ir` 导出；
   `CameraSchema` 与 web 侧的指令 schema 都从它取，不再各写一份
   （web 的 `instruction-ai.ts` 原来就有一份本地副本，这次一并消掉）。
2. **dutch 不参与俯仰换算**：`angleFromPitch` 永远不会返回 dutch；
   `elevationOf` 遇到作者写了 dutch 时 `agrees` 直接为 `true`
   ——dutch 没有「相机该多高」的主张，拿它去算 `indexOf` 会得到 −1，
   凭空造出一条假警告。
3. **dutch 不进「换个角度」轮换**：轮换仍是平 → 仰 → 俯。
   轮换是「在同一类里换一档」，把滚转混进去会让这句话变成随机行为。
4. **词表补齐**：`SHOT_ANGLE_CN.dutch = "荷兰角"`；故事草稿解析的别名加
   `荷兰角 / 斜角 / 歪斜`。
5. **V14：dutch 单场 ≤ 1**，登记 `docId: "A4"`、`category: "angle"`、`priority: "may"`。
   按场汇总、报一条并点名所有超量镜头（与 V13 手持同一口径）。
6. **不动 `LOG_VERSION`**：加一个枚举值不改变事件形状，旧日志照样能读；
   新日志里出现 dutch 只影响「旧版本客户端读新日志」，那不是迁移问题。

## 理由

- **先想清它是不是同一类，再动手**：把 dutch 当第五个俯仰档，会让
  「平视高度对不对」这类几何检查全部误报。这条判断比加字段本身更重要。
- **枚举只留一份**：这一轮已经因为三份副本出过一次类型错误
  （`ANGLE_CN` / `SHOT_ANGLE_CN` / `CAMERA_ANGLES`），趁改枚举收口。
- **按场汇总而不是逐镜报**：dutch 连用的问题在「这一场晕」，不在某一镜。
- **may 级仍要查**：A4 在文档里是 may（风格化选项），但「单场 ≤ 1」是写死的上限。

## 验证

`storyboard.test.ts` +3 条：一场一个不报、一场两个报一条并点名、跨场不累计。
`chain.test.ts` +3 条：不进轮换、提示词有说法、俯仰换算不给 dutch。
`elevation.test.ts` 更新断言（标签多一个 dutch，俯仰换算仍只有四档）。
评测集 +2 条（V14 正反例），28 条用例全过、14 条规则全覆盖。

浏览器实测（`next start` + 无头 Chrome）：镜头语言抽屉的机位里出现「荷兰角」，
点它写出 `shot.updated { patch: { camera: { angle: "dutch" } } }`，持久化生效。

IR 260 / gateway 32 / pipeline 158 / web 1454（4 skipped）全过；`pnpm -r typecheck` 全过；
`scout check` 全绿。

## 后果

**正面**

- 荷兰角从「模型里没有」变成「能写、能看、能查」。
- 机位枚举只剩一份，以后加值只改一处。
- A4 从「查不了」变成自动查，语法库覆盖 14 条 / 待落地 23 条。

**负面 / 代价**

- **提示词层只是多了个词**：`"荷兰角"` 进技术参数那一句，模型能不能稳定画出
  滚转构图没有验证过（供应商侧仍未通）。
- 走位台账、立面读数这些几何工具都不理解 dutch，只做到「不误报」。
- 旧版本客户端读新日志会解析失败（新枚举值），没有降级处理。
- 没有「滚转角度」的数值字段：dutch 只是一个档位，不能指定歪 10° 还是 30°。
