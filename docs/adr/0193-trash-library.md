# ADR-0193：废片库——淘汰 / 删掉的拍与旧关键帧汇到一处取回（C14 第三档）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C14、C2、B5、F4、ADR-0185、ADR-0187、ADR-0067

## 背景

生成过的故事、关键帧、视频都是花过钱的资产。现在三处各自留了半套：

- **关键帧**有版本库（ADR-0185），但只在那一格的「旧版 N」里看得到；
- **故事**有版本库（ADR-0187），但只在故事圣经底部；
- **视频 take** 淘汰后仍留在 `shot.takeIds` 里，删掉后只剩日志；
  淘汰的拍散在每一镜里，「删掉」的那一拍在界面上彻底消失。

用户的要求（C.2 / C14）是：淘汰或被二次覆盖也不要删除，进版本库与废片库，
之后可取回或作参考。缺的是**一处能看见全部废片、并能取回的地方**。

## 决定

1. **废片库是只读汇总，不是新的存储**
   - `apps/web/lib/trash.ts` 的 `trashOf(project, events)` 从三处取材：
     1. 项目里 `status: "rejected"` 的 take；
     2. 日志里 `take.added` 之后又 `take.removed`、且项目里已经没有的 take；
     3. 每一镜 `keyframes.history` 里不是当前这一张的旧关键帧。
   - 每一项带：哪一镜（「第 1 场 · 第 3 镜」）、镜头描述、时间、
     原文件地址、模型；take 另带当时花的钱；关键帧另带首 / 尾帧。
   - 按时间新 → 旧排；同一镜同一帧的同一地址只列一次；当前帧地址不列。
   - **不新增 IR 字段、不新增事件类型、不改 `LOG_VERSION`**：
     日志与现有资产记录已经足够，另存一本废片表会多出第二份真相。

2. **取回淘汰的拍：改回待审 + 挪到本镜最后一拍**
   - `restoreTake(takeId)` 写一条 `take.updated { status: "draft" }`；
     如果它不在 `takeIds` 末尾，再写一条 `shot.updated { takeIds }` 把它挪到最后。
   - 挪到最后是因为界面默认显示最后一拍、闸门也只认最新一拍；
     不挪的话「取回」在界面上看不出变化。
   - 只处理 `rejected` / `draft`：已留用的拍不在这里动（避免把已定的拍改回待审）；
     锁定镜头拒绝——与淘汰 / 留用同一条规矩。

3. **取回删掉的拍：按日志里的原记录重新 `take.added`**
   - `takeFromLog` 先看 `project.created` 里的拍（示例 / 导入项目），
     再看后来的 `take.added`；`take.removed` 之后项目里没有这一拍，才进废片库。
   - 取回写一条 `take.added`，take 内容照抄、只把 `status` 改成 `draft`；
     原资产、原花费、原溯源都不变，不重新生成、不花钱。
   - **时间线上的片段不自动接回**：`take.removed` 当时把时间线项一起摘了；
     取回只回到镜头，接不接回成片由作者决定。界面明写这一点。
   - 资产记录也被删掉的拍不列：点不动的空卡片比没有更糟。

4. **旧关键帧走既有 `useKeyframeVersion`**
   - 不另写恢复逻辑：它已经把旧图写回标准资产位、把现在这一版归档、
     保留资产位上的花费；废片库只是多一个入口。

5. **界面在资产页**
   - 资产页（F4）本来就是「钱花在哪、谁在用」的页面；废片库跟它同一类问题。
   - 汇总行「淘汰 n · 删掉 n · 旧版 n」，最多列 40 条，其余提示先处理前面的。
   - 只读窗口禁用；每一项一个「取回」/「换回」，点完在页面上方给人话反馈。

## 理由

- **废片是资产问题，不是编辑问题**：放在资产页，和「谁在用、多少钱」一起看，
  作者才知道哪些钱还有救。
- **只读汇总**：日志与资产已经是事实来源；废片库如果自己存一份，
  就会出现「废片库里还有、日志里没有了」这种对不上的状态。
- **取回不自动接回时间线**：删除时作者的目的可能就是把它从成片里拿掉；
  自动接回会悄悄改变成片时长与花费口径。分开两步更诚实。
- **删掉的拍用 `take.added` 复活**：事件日志天然可重放，不需要「反删除」事件；
  复活本身也留痕，之后还能再删。

## 后果

**正面**

- 淘汰 / 删除 / 覆盖过的成片与旧关键帧，在一个页面上都看得见、点得回来。
- 取回不调用模型、不花钱、不复制字节；旧资产与旧花费原样保留。
- 废片库与关键帧版本库、故事版本库共用一个事实来源（日志），不会互相打架。

**负面 / 代价**

- **删掉的拍只能从日志里找回**：日志被压缩掉早期 `take.added` 后，
  那一拍就真的找不回来了（会从废片库里消失）。
- 只汇总 **视频 take 与关键帧**；配音 take 的删除、剧本 / 分镜整份快照还没有入口。
- 旧关键帧不显示当时的花费（历史复制件本来就不抄 `costCny`），只显示时间与模型。
- 「作参考」还没有直接动作：要拿旧图当参考，仍得去定妆页 / 素材库挑图。
- 没有筛选、搜索、分页；超过 40 条只提示，不提供「加载更多」。
- 取回删掉的拍不会恢复它的时间线片段，也不会恢复它当时在成片里的位置。
