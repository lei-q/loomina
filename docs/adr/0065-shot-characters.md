# ADR-0065 这一镜里谁出场：人物点名进 `characterIds`

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0029（锚点）、ADR-0040（提示词可见）、ADR-0046（换人）、ADR-0064（新建镜头）、FEATURES B2

## 背景

`Shot.characterIds` 决定三件事：提示词里写谁、锚点带哪几张定妆图、剧本页「加一句」时说话人下拉列出谁。但它此前只存在于示例数据里——界面没有任何地方能改。ADR-0064 新建出来的镜头 `characterIds` 为空，等于一个没人物的空镜，而用户无从下手。

台词这边已经有「换人」（ADR-0046），可那改的是 `DialogueLine.characterId`，与「谁在画面里」是两件事：一个镜里可以有人不说话，也可以有画外音。

## 决策

1. **`store.toggleShotCharacter(shotId, characterId)`**：一个人一枚签，点一下加入或移出 `shot.characterIds`，写一条 `shot.updated { characterIds }`。加入时追加到末尾——**出场顺序就是点名的顺序**。
2. **校验**：
   - 镜头不存在 / 人物不存在 → 拒绝并命名。
   - 镜头已锁定 → 拒绝：「这一镜已锁定，先解锁再改出场人物。」
   - **人走了，这一镜里他的话还在** → 拒绝：「X在这一镜还有台词：先删掉或换人，再把他从出场里拿掉。」理由：字幕会烧出一个画面里没有的人。
3. **界面**：分镜页大画面下方、提示词折叠与锚点之间，一行 `出场`，每个角色一枚小签（未出场描边灰、出场实底）；点一下即写；锁定的镜头与只读标签页置灰，悬停说明原因。位置紧挨 `锚点`：改了人，下一行的锚点立刻跟着变，改动看得见。
4. **不新增事件类型**：与 `shot.updated` 的现有语义一致（人物是镜头自己的字段）。
5. **不联动台词**：加人不会给他的台词补上，减人也不会删台词（后者被第 2 条挡住了）。

## 理由

- **点名即出场**：`characterIds` 本来就是「这一镜里谁在」，把它做成可点的签，比再开一个「演员表」页面直接。
- **顺序即提示词顺序**：先点的人写在提示词前头，符合「先说谁在场」的阅读顺序；也让用户能调整主次。
- **台词挡住减人**：这是唯一会产出自相矛盾画面的路径（画面里没人、字幕里有话）。其他矛盾（有人不说话）是合法的，不挡。
- **与锚点挨着**：人物签是输入，锚点是结果；同一屏上下对照，比藏在侧栏里更容易看出「我点了人，参考图有没有跟上」。
- **锁定即冻结**：与动作、台词、机位的处置一致（ADR-0041）。

## 后果

**正面**
- 分镜页 SH-02 点 `林` → 签点亮，`锚点` 行立刻出现 `林 · 正面`、`林 · 3/4`；提示词里也写上林；日志一条 `shot.updated { characterIds: ["c-lin"] }`。
- 在周有台词的 SH-07 上点掉 `周` → 一行 `pick` 色说明「周在这一镜还有台词：先删掉或换人，再把他从出场里拿掉。」；签保持点亮，日志不动。
- 新建的空镜（ADR-0064）从此可以点名，点名后就能生成有人的关键帧。
- 测试：web 165 条（新增 3 条：加点名 + 锚点 / 提示词联动 + 回放、有台词的人拿不掉、锁定 / 陌生 / 只读拒绝）；IR 76、gateway 17、pipeline 22；合计 280。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：SH-02 点 `林` → 锚点出现两张林；SH-07 点掉 `周` → 被挡下；IndexedDB 多一条 `shot.updated { characterIds }`。

**负面**
- **只能点人，不能点道具**：`propIds` 仍没有界面，道具出场只能改数据。
- **人员没有「群演 / 背景」概念**：所有角色平等，一起点名。
- **换人会写两处**：画面人物（`characterIds`）与台词说话人（`characterId`）要分别改；没有「这一镜里换主角」的一步操作。
- **没有出场顺序的拖拽**：只能靠「点掉再点回来」调整先后。
- **锁定后要解锁才能改人**：一个字的修正也要先解锁、再锁回，两条事件。

**跟进**
- 道具出场（`propIds`）的同一套签。
- 「这一镜里换人」：一次改掉 `characterIds` 与该镜所有该角色的台词。
- 出场顺序拖动。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 新事件 `shot.cast.updated` | 人物就是镜头字段，`shot.updated` 已经够；多一种事件让 ADR-0057 的过期判据也要多认一种 |
| 从台词说话人反推 `characterIds` | 有人不说话（沉默的反应镜）是常态；反推会把画外音与画内人混成一体 |
| 允许直接拿掉有台词的人，台词留着 | 画面里没人、字幕里有话，审片时是穿帮而不是选择 |
| 点掉人时自动删掉他的台词 | 删台词是不可逆的动作（可恢复但要写事件），不该由一个点签动作顺带完成 |
| 把人物签放进侧栏的「演员表」页 | 分镜页要的是「这一镜」，跨镜的演员表解决不了单镜的问题 |
