# ADR-0014 跨镜头一致性采用多维分层防线

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P3、T1、B1、B4、B11、B12、R16

## 背景

"跨镜头一致性"常被当成一个技术点，但实际至少包含 8 个独立维度：身份、服化道、场景、光影、空间、表演、动作、风格。不同维度的失败原因与修复手段完全不同。

如果只用一种手段（例如"多给参考图"或"固定 seed"），会出现：

- 身份稳住了，但衣服每镜不同；
- 衣服稳住了，但房间布局跳变；
- 都稳住了，但光的方向反了；
- 都稳住了，但切点接不上。

## 决策

采用 **5 层防线 + 分维度验收 + 诊断式修复**：

### 5 层防线
1. **资产锚定**：角色三视图/表情/服装、场景主镜、道具特写；闸门 1 锁定。
2. **结构锚定**：3D 灰盒（ADR-0013）+ 关键帧优先 + 首尾帧（仅连续动作）。
3. **生成约束**：seed 管理、固定描述 token、模型能力路由、负向约束。
4. **量化验收**：人脸 embedding 余弦、VLM 清单、pHash、色温/Lab/直方图；输出 `ConsistencyReport`。
5. **后期统一**：LUT、颗粒、锐化；**不做换脸**。

### 分维度验收
每个镜头产出分维度分数，阈值按景别分级（特写严、全景松），而不是一个总分。

### 诊断式修复
QA 失败先判断维度，再走对应修复路径（身份→参考图/seed/换模型；光影→重编译/调色；空间→3D 重摆位），不盲目重抽。

## 理由

- 不同维度需要不同技术，单一手段必然留下短板。
- 分维度分数可解释、可指导修复，也能作为产品界面上的"诊断"。
- 资产 + 结构 + 验收 + 后期是互补关系，不是替代关系。

## 后果

**正面**
- 一致性可度量、可迭代、可解释。
- 修复有方向，减少无效重试（R12）。
- 为"一键修复"提供数据基础。

**负面 / 代价**
- 需要维护多套 QA 逻辑与阈值标定。
- 人脸 embedding 对侧脸/遮挡不稳定；不能只靠它。
- 3D 结构条件在视频阶段支持有限，主要在关键帧阶段生效。

**跟进**
- 在自有样片上标定各维度阈值，写进能力矩阵与 QA 配置。
- 明确"不可逾越的边界"（侧背、复杂花纹、多人、长镜），产品主动规避。
- 人工兜底始终保留（准则 P6/P7）。

## 替代方案

- **只靠参考图**：解决身份，不解决空间/光影/动作，否决。
- **只靠后处理**：能统一色调，不能修身份，否决。
- **换脸/换身体**：法律与 artifact 风险高，否决。
