# ADR-0002 默认采用「先图后视频」的关键帧管线

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P3、P4、B1、B2、B3

## 背景

当前视频模型（seedance、可灵、Veo 等）在单镜头内表现力强，但**跨镜头的角色一致性**和**构图可控性**不足。纯文生视频等于"抽卡"：同一个角色每镜都可能变脸、换衣服，重试成本高。

## 决策

默认生产路径固定为：

```
剧本/台词 → 关键帧（首帧 / 尾帧，图生图）→ 图生视频（首尾帧约束）→ QA → 重试
```

- **关键帧阶段**负责角色、服装、构图、光线、空间关系。
- **视频阶段**只负责运动与表演，不再负责"长什么样"。
- 纯文生视频保留为补充能力，不作为默认。

## 理由

1. 图像模型的可控性和迭代成本远优于视频：一个关键帧重试的成本约为视频重试的 1/10。
2. 首尾帧约束能显著提升运镜与转场的可控性。
3. 一致性可以在廉价阶段被"锁定"，而不是在昂贵阶段反复赌。

## 后果

**正面**
- 角色一致性显著提升（对应 R16）。
- 重试成本下降（对应 R12）。
- 关键帧本身可复用、可对比，便于人工介入。

**负面 / 代价**
- 管线更长，首帧生成失败会阻塞后续。
- 依赖图生视频模型对首尾帧的支持程度，供应商间能力不一。

**跟进**
- 网关需抽象"首帧/尾帧/双帧"能力位。
- 关键帧 QA 要早于视频生成。

## 替代方案

- **纯文生视频 + 参考图**：一致性靠提示词，波动大，否决为默认。
- **仅首帧约束**：可控性弱于双帧，作为降级方案保留。
