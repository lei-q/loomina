# ADR-0045 台词的增与删：两条事件，镜头时长跟着加减

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0011（事件日志）、ADR-0044（台词改写）、PRINCIPLES P5、FEATURES A5

## 背景

ADR-0044 只让改已存在的台词。可剧本里更常见的是「这里少一句」「这句不要了」：IR 的 `Shot.dialogueIds` 与 `Project.dialogue` 两处要一起变，镜头时长也要按 P5 跟着加减。没有事件类型，界面上什么都做不了。

## 决策

1. **两条事件**：
   - `dialogue.added { shotId, line }`：把台词加进 `project.dialogue`，同时挂到镜头的 `dialogueIds` 上；
   - `dialogue.removed { lineId }`：从项目与所有引用它的镜头上一起摘掉。
2. **镜头时长在 store 里跟着写**：加一句 `shot.updated { durationMs: 旧 + 这一句 }`，删一句减去这一句；减到 500ms 就停，不出现负时长。与改写同一条先例：一次动作、两条事件、同一时间戳。
3. **id 由 store 生成**：`d-<shotId>-<8 位随机>`，不用「第几条」计数——删过再删会撞号。
4. **界面**：
   - 每镜末尾一个 `+ 加一句`；点开是说话人下拉（这一镜里有谁排在前面）+ 文本框，⌘↩ 保存、Esc 取消；
   - 每句台词旁一个 `删`，点了变成 `确认删 / 取消`——删是摘掉，不适合一键就没。
5. **锁定镜头**：加不了、删不了，与改同一把锁。
6. **说话人不在这一刀里改**：换人仍然等于换一句台词，留给后面单独的事件。

## 理由

- **两处引用必须一起动**：只加 `project.dialogue` 不挂 `dialogueIds`，剧本页看不到；只挂 `dialogueIds` 不写项目，回放找不到。放在 `applyEvent` 里一次做完，回放与操作一致。
- **事件里带整句**：`dialogue.removed` 只带 id，日志里就只剩「删过」而不知道删了什么；以后要「恢复被删的台词」得靠别处。现在的 `dialogue.added` 保留了整句，删掉时那句在更早的事件里还在。
- **时长跟着加减**：P5 的镜头时长 = 台词 + 余量；不改就是坏项目。
- **确认再删**：删一句会改剧情，误触代价比多一次点击大。

## 后果

**正面**
- SH-02 从无台词到有一句：加「门开着呢。」（林，1.5s）后台词 4 → 5 条，镜头 2.4s → 3.9s，全片 32.6s → 34.1s；点 `删` → `确认删` 后全部回到原样，日志里是 `added + shot.updated` / `removed + shot.updated` 两对事件。
- 说话人下拉默认取这一镜里的人，不用从全剧名单里找。
- 测试：IR 58 条（新增 3 条：加与挂载、删与摘除、四种非法输入）；web 107 条（新增 5 条：加、删、锁定与校验、说话人候选、每镜有谁）。

**负面**
- **不能换人**：加错说话人只能删了重加，会多两条事件。
- **台词顺序不可调**：只能追加到这一镜末尾，不能插到中间。
- **删掉没有界面上的恢复**：日志里那句还在，但要多走一步「加一句」重打一遍；A5 的恢复要等。
- **时长仍是估的**：加一句按 0.3 秒 / 字估，和改写的口径一致。
- **一次只加一句**：不能从别的镜头复制，也不能批量。

**跟进**
- 换说话人：单独事件 `dialogue.speaker.updated`，或允许 `dialogue.updated` 带 `characterId`（需要改 ADR-0044 的约束）。
- 台词排序 / 插入位置。
- 从被删事件里恢复整句。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 在 `shot.updated` 里直接改 `dialogueIds` | 台词本体在 `project.dialogue`，两个字段分开写容易只写一半 |
| `dialogue.removed` 只摘 `project.dialogue`，`dialogueIds` 留脏 | 回放后镜头指向不存在的台词，剧本页出现空行 |
| 用序号生成 id | 删过之后重加会撞号 |
| 一键删、不给确认 | 误触会改剧情，且界面上的恢复还没做 |
| 把加 / 删合进一个 `dialogue.changed` | 分支更多，日志难读，回放校验也更绕 |
