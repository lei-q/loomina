# ADR-0146 按角色点名指定字幕颜色

- 状态：已接受
- 日期：2026-11-12
- 决策人：用户 + Claude
- 关联：ADR-0140（按角色着色）、D3、ADR-0130（版式微调）

## 背景

ADR-0140 按 `project.characters` 的顺序从六色板取色，六个以内不撞色。这条规则对「谁在说」够用，但对连续剧不够：主角的颜色应该跨集稳定，不能因为这一集新加了一个角色、顺序变了，主角就从琥珀变成天蓝。作者也会有自己的偏好——比如反派固定用冷色。

D3 一直挂着「自定义色板 / 单角色指定颜色」。自由色板会毁掉可读性（深色画面、肤色、灯光都可能吃掉颜色），点名指定则是在同一个六色板里挑，既保住对比度，又让作者的决定稳定下来。

## 决策

1. **只换颜色，不换色板。** `SubtitleLayout.speakerColorOverrides?: Record<characterId, "#RRGGBB">`，界面只给 `SPEAKER_COLORS` 的六个颜色；IR 只校验 `#RRGGBB` 格式（未来换色板不用改事件层）。
2. **点名的优先，没点名的照旧按顺序取。** `toEditView` 先按顺序建色板，再用覆盖表逐个替换；覆盖表里指向已删除角色的键被忽略，不报错、不影响其他角色。
3. **只存改过的角色。** 空对象与 `null` 等价，都表示「全部回到色板默认」；事件层把空对象规范掉，`isCustomSubtitleLayout` 不会因为一个空表就显示「已调」。
4. **整份替换，不是按角色合并。** 与 `speakerColors` 同一个 `subtitle.layout.updated` 事件；要摘掉某一个角色，就发一份不含它的表。事件层统一转成大写，避免 `#ffd666` 与 `#FFD666` 被当成两份不同的配置。
5. **一处改，四处生效。** 颜色仍写在 `EditCue.speakerColor` 上，播放器、预览 HTML、ASS 行内颜色与成片叠加层照旧共用这一份；发布包的 `subtitleLayout` 多记 `speakerColorOverrides`。
6. **界面贴在「版式微调」里。** 勾着「按角色着色」时，下面列出项目里的每个角色：六个色块 + 当前色值 + 「默认」；点色块立即写一条事件，点「默认」把该角色从表里摘掉。「恢复模板」一并清掉覆盖。

## 理由

- **点名而不是自由取色**：六色板是经过对比度考虑的；开放任意十六进制等于把这个判断交给作者，深色字幕在夜景里就是看不见。
- **主角颜色要稳定**：按顺序取色的隐含规则是「别动角色顺序」；点名把这条隐含依赖变成显式配置。
- **不新增事件类型**：版式已经在 `subtitle.layout.updated` 里，配色是版式的一部分；多一条事件只会多一处要同步的读写。
- **未知角色键忽略**：角色删了，配色留着不碍事；清理它要么需要联动事件（ADR-0073 那套），要么在读模型里做迁移，都不值得。

## 后果

**正面**

- 主角 / 反派可以跨集固定颜色，新增角色不再挤掉别人的颜色。
- 发布包能看出这一版哪些颜色是点名的，素材复用时可追溯。
- 界面上的「已调」与「恢复模板」把配色和字号、位置放在同一层，作者不用记两套规则。

**负面 / 代价**

- 多一个可选字段与一份覆盖表；老项目没有它是正常的。
- 角色很多时列表很长（最多 24 条覆盖，超出被事件层拒绝）；超过六个人本来就该靠剧本区分。
- 配色按角色 id 存，角色 id 在不同项目之间不通用——跨项目复制版式没有做。

**边界**

- 不能自定义色板、不能按角色换字体或字号（D3 的其余条目仍未做）。
- 没有「配色主题」或预设（例如「冷色系反派」）。
- 角色名前缀、逐字动画仍不做。

## 验证

- IR：整份替换、统一大写、`null` / `{}` 清空、非法颜色拒绝（`events.test.ts` 新增 2 条）。
- web：读模型用点名颜色、未点名的角色仍按顺序、ASS / 预览 / 发布包三处同源（`edit.test.ts` 新增 1 条）；store 写事件、键序无关的幂等、空对象清空（`workbench-store.test.ts` 新增 2 条）。
- 全仓 1233 条测试全过（IR 214 / gateway 28 / pipeline 98 / web 893）；`tsc --noEmit` 与 `next build` 干净。
- 浏览器：版式微调里给「林」点 `#FFA6C9` → 色块变选中、「默认」出现、日志写一条 `speakerColorOverrides { c-lin: "#FFA6C9" }` → 跳到林的那句，播放器字幕颜色是 `rgb(255, 166, 201)` → 点「默认」写回 `null`，颜色回到色板默认。
