# ADR-0020 声音分层，对白优先混音

- 状态：已接受
- 日期：2026-11-09
- 决策者：用户 + Claude
- 关联：P5、P19、SOUND.md、C1–C8

## 背景

声音在短剧里承担了很大一部分表演与情绪，但常见做法是"画面做完再补声音"：

- 配音当朗读，平铺直叙，没有气口与重音；
- 音乐从头铺到尾，盖住台词；
- 音效堆满，像广播剧；
- 每段单独生成，响度忽大忽小；
- 观众静音观看时，字幕不承载信息。

短剧的播放环境是手机外放、嘈杂、可能静音，这决定了混音策略不能照搬影院。

## 决策

**声音拆四层（对白 / 音乐 / 音效 / 环境），对白优先混音。**

1. 配音按表演处理：逐句参数（语速/音高/音量/气声/停顿/重音/句尾/呼吸），多 Take，允许人工微调。
2. 配音节拍与画面表演节拍对齐：台词前反应、台词中气口、台词后余韵。
3. 音乐按 Beat 情绪曲线走，只做"进/转/出"，留白，主题动机。
4. 音效只给有意义动作；画外音扩展空间。
5. 混音：台词期间音乐 ducking 12–18 dB；整体 ≈ −14 LUFS；真峰值 ≤ −1 dBTP；单声道兼容。
6. 一致性：`VoiceProfile` 跨集固定，场景 reverb 统一，音乐服从 `StyleProfile`。
7. 信息双通道：字幕能独立看懂。

## 理由

1. **手机外放决定物理约束**：低频无效、单声道近似、环境嘈杂——只能靠中频与对白。
2. **对白是信息主通道**：听不清台词，观众立刻划走，情绪设计再好也没用。
3. **配音表演是最便宜的质量杠杆**：同一句话的重音与停顿，比换一个更贵的模型更能改变观感。
4. **声音可以先于画面完成**（P5 音频先行），从而反过来决定镜头时长。

## 后果

**正面**
- 对白清晰度有硬指标，混音不靠"感觉"。
- 配音、音乐、音效可分别重做，非破坏。
- 与音频先行、关键帧表演天然对齐。

**负面**
- 逐句配音参数增加编辑成本，需要好的默认值。
- 音乐版权与音色授权需要流程与元数据。

**跟进**
- 建立配音默认参数模板（按情绪/性别/年龄）。
- 建立场景混响预设与音乐情绪曲线模板。
- 静音可懂度纳入 QA 清单。

## 替代方案

- **画面先行、声音后补**：违反 P5，且镜头时长会被画面绑架，放弃。
- **影院式混音**：手机外放听不出层次，反而丢对白，放弃。
- **全程铺音乐**：情绪没有起伏，且盖台词，放弃。
