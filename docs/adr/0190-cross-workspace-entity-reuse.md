# ADR-0190：跨空间复用演员 / 场景 / 道具（用户清单 C.1 / 功能 C17）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C.1、C17、C16、C15、H3、ADR-0128、ADR-0188、ADR-0189

## 背景

C16 解决了「从别的空间挑一张参考图」。但做第二集时真正费钱的是**整块实体**：
一个人连同定妆三视图与参考图、一个场景连同主镜与几何、一件道具连同参考图。
现在只能回到别的空间看一遍，再逐张重挂——或者干脆重新生成。

用户要求「跨集直接复用同类场景、道具、演员，不再花钱生成」。

## 决定

1. **每个区段一个入口，只列别的空间**
   - 定妆页的人物 / 场景 / 道具三个区段头各一个「从别的空间取」，
     弹层只列**当前空间以外**的实体（当前空间自己的不重复出现）。
   - 打开时才回放各空间日志（与 C16 同一套 `loadWorkspaceProjects`），坏日志跳过。

2. **清单是纯函数**
   - `sharedEntitiesOf(spaces, kind)` 输出实体的名字、描述、来源空间、缩略图，
     以及它引用到的、**有地址**的资产；`sharedEntitySummary` 给出
     「n 格定妆 · m 张参考图」「主镜 1 张 · m 张参考图」这种能一眼判断搬多少东西的小字。

3. **取用 = 换新 id + 复用地址，绝不重新生成**
   - `sharedEntityImport(shared, project, at)` 是纯函数，返回要喂给 `applyEvent`
     的事件序列：**先资产、后实体**（不变量要求实体引用的资产先存在）。
   - 实体 id 换成 `c-share-…` / `l-share-…` / `p-share-…`（按时间戳 base36，撞了加 `x`）；
     名字在当前项目里重了就自动加「（复用）」「（复用 2）」。
   - 资产按 `uri + kind` 查重：当前项目已有同一地址就复用；同一轮里两张图指向
     同一地址也只登记一份。没有地址的占位资产不搬，并在结果里计数。

4. **资产的来源与花费口径**
   - 复制件的 `source`：原件是 `generated` 的记 `library`；`upload` / `imported`
     原样保留。这样生成过的图不会触发「上传素材缺授权」，也不会被 `spendOf`
     当成一次「未定价调用」；真人素材的授权要求照旧成立。
   - `costCny` 不跟过来（钱花在原来的空间里）；`review` 不跟过来（新项目要自己终审）。
   - `provenance` 保留模型、提示词、种子与生成时间，但清空 `referenceAssetIds`
     ——那些 id 在新项目里不成立，留着就是悬空引用。

5. **各类型带什么**
   - **演员**：外形描述、不许变清单、音色 id、定妆四格、参考图。
     源项目缺哪一格，就用新 id 的占位格补上，界面照旧显示「待生成」。
   - **场景**：描述、模板 id、主镜、参考图、几何（尺寸 + 锚点，深拷贝）。
   - **道具**：描述与参考图。

6. **C16 的取图口径顺带修正**
   - 单张挑图现在也按同样规则传 `source`：原件是生成的记 `library`，上传的保留。
     三个参考图动作（人物 / 地点 / 道具）多了可选的 `source` 参数，默认仍是 `upload`。

## 理由

- **搬记录、不搬字节**：素材按内容寻址全机一份，复制实体的意义只是「让当前项目
  知道这些图和这个人有关」。同一地址复用让资产页不会出现两行同一张图。
- **先资产后实体**：`applyEvent` 是顺序回放，不变量在每一步都检查；顺序错了，
  回放直接失败。
- **名字自动去重**：跨空间同名很常见（两集都有「林」）。直接拒绝会让人以为取不了，
  静默覆盖更糟；加后缀能让两个人物同时摆在一页里。
- **来源口径**：`source` 不只是标签，它决定授权体检与花费统计。生成图取过来记
  `upload` 会误报「缺素材授权」，记 `generated` 又不带钱会误报「未定价调用」，
  只有 `library` 两项都不触发。

## 后果

**正面**

- 第二集可以直接把第一集的演员、场景、道具全搬过来，定妆 / 主镜不重新生成、不花钱。
- 搬来的实体与当前项目自洽：id 不冲突、引用齐全、回放可验证。
- 花费与授权统计保持诚实：不在本空间花的钱不记在本空间，真人素材仍要授权。

**负面 / 代价**

- 只搬实体本身：弧光、关系、台词、镜头、闸门、审批都不跟过来（它们属于故事与流程）。
- 源项目的复核结论不跟过来，搬来的图在新项目里仍是「未复核」。
- 同名后缀可能让作者需要手动改名；目前没有「覆盖 / 合并到已有实体」的选项。
- 只覆盖演员 / 场景 / 道具；故事、剧本、分镜、音频、视频的跨空间取用还未做。
