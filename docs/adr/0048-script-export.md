# ADR-0048 剧本导出：从读模型直接吐纯文本

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0043（剧本页）、ADR-0011（事件日志）、FEATURES A21

## 背景

剧本页能改、能回退、能加删，但改完的东西还在这个浏览器里。A21 的负面清单上一直挂着「没有导出」：剧本要拿去读、拿去让人看、拿去粘进别处，就得能离开这一页。顶栏那个「导出」按钮一直是灰的。

## 决策

1. **导出纯文本（`.txt`）**，不做 PDF / Markdown / 富文本。文本是剧本最通用的形态：手机能看、能粘、能打印。
2. **格式由读模型生成**：`read-model.ts` 新增 `scriptToText(view: ScriptView): string`，输入是剧本页已经在用的读模型，不碰 IR、不碰 store。
   - 第一行 `标题 v版本`；
   - 第二行 `n 场 · n 镜 · n 句台词 · 总时长`；
   - 场头 `第 n 场 · 地点（时长 · n 镜）`；
   - 镜行 `SH-xx · 景别 · 机位 · 时长`，下一行动作，台词缩进成 `角色：文本`；
   - 场与场、镜与镜之间空一行。
3. **下载靠 Blob + object URL**：`new Blob([text], { type: "text/plain;charset=utf-8" })`，一个临时 `<a download>` 点一下，随即 `revokeObjectURL`。文件名 `${title}-v${version}.txt`。
4. **不写任何事件**：导出是只读操作，日志不变。改过多少次、导出过多少次，是两回事。
5. **按钮跟页走**：`TopBar` 新增 `onExport` / `exportLabel`；没有 `onExport` 的页面按钮置灰、悬停写「这一页还不能导出」。剧本页传进去，标题为「把剧本导出成纯文本（.txt）」。

## 理由

- **读模型是唯一的出口**：屏幕上看到什么，导出的就是什么；不必在导出时再拼一遍 IR，也不会出现「页面改了、导出没跟」的第二套格式。
- **纯文本而不是 PDF**：PDF 要排版、要字体、要分页，中文还要嵌字库；这一刀的目标是「东西能拿出去」，不是「印刷级交付」。
- **不记事件**：导出不改变项目事实，写进日志只会让「改过几次」和回放多出噪声。
- **按钮不加新位置**：顶栏本来就有导出位，补上行为比新开一个菜单轻。

## 后果

**正面**
- 剧本页顶栏「导出」可用：示例项目导出 `夜班-v3.txt`，1.2KB，含 5 场 12 镜 6 句台词与 35.6s 总时长；场头、镜号、动作、台词、技术行一条不缺。
- 导出内容与屏幕一致：同一份读模型，改一句台词后导出的文本立刻跟着变。
- 其他页面（故事 / 定妆 / 分镜 / 关键帧 / 声音 / 成片）按钮明确置灰，不假装能导出。
- 测试：web 112 条（新增 1 条：标题 / 页头四数 / 场头 / 镜号 / 台词 / 十二个 `SH-` 都在）；IR 60、gateway 17、pipeline 21 不变，合计 210。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：headless Chrome 用 `Browser.setDownloadBehavior` 指到 `/tmp/loomina-dl`，点顶栏「导出」，落盘 `夜班-v3.txt` 并逐行核对。

**负面**
- **只有纯文本**：没有加粗、没有分镜表、没有页眉页脚，粘进 Word 要自己排。
- **中文缩进用全角空格**：等宽字体下对齐，但在别的字体里可能不齐。
- **没有导出选项**：不能只导一场、不能选「带 / 不带技术行」、不能带台词时长。
- **文件名固定**：同名版本重复导出会变成 `夜班-v3 (1).txt`，由浏览器决定。
- **不记导出这件事**：日志里看不出「谁在什么时候导过」。

**跟进**
- PDF / Markdown 导出（PDF 要处理中文字体嵌入）。
- 按场 / 按角色导出，勾选是否带技术行与时长。
- 导出时把版本号与导出时间写进文件末尾。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 直接一键复制到剪贴板 | 看不见导出了什么，也不方便存成文件；剪贴板权限还要额外处理 |
| 导出 PDF | 中文字体、分页、排版成本远大于这一刀的价值 |
| 导出 JSON（IR 原文） | 人读不了，也不是「剧本」 |
| 在 store 里写 `exported` 事件 | 导出不是项目事实，会污染版本与回放 |
| 服务端生成文件 | 现在没有服务端存储，纯前端 Blob 就够；上云再换实现 |
