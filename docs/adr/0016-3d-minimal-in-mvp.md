# ADR-0016 3D 灰盒最小版纳入 MVP

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P3、P11、P14、B13、B15、ADR-0013

## 背景

ADR-0013 已决定采用 3D 灰盒场景板。但"是否放进 MVP"是另一个决策：

- 放进 MVP：多 2–3 周，但空间一致性与机位可控性从第一天就是对的；
- 放到 v1：MVP 更快，但分镜/机位/关键帧都要先按"没有 3D"设计，后补等于重构。

## 决策

**3D 灰盒最小版纳入 MVP**，但严格限定范围。

### 做
- 6 个场景模板（见 [SCENE-TEMPLATES.md](../SCENE-TEMPLATES.md)）；
- 灰盒几何 + 胶囊人物 + 朝向箭头；
- 自动摆位（按剧本/关系/门/窗锚点）；
- 机位放置与视锥显示，焦段预设（24/35/50/85）；
- 轴线绘制与越轴检测；
- depth / edge 参考图导出；
- 拖动人物/机位后，同场镜头自动重校验。

### 不做（v1）
- 自定义搭墙/导入模型；
- 写实材质与完整灯光模拟；
- 角色动画、复杂路径、物理；
- 复杂室外/多层空间。

## 理由

- **不可逆**：`Blocking` / `CameraPlacement` 是分镜与关键帧的上游数据；后补会改 IR、分镜器、渲染链路。
- **一致性依赖它**：空间一致性无法靠提示词解决（CONSISTENCY.md 第 5 维）。
- **成本可控**：6 个模板 + 灰盒几何，工作量集中在交互与数据，不在美术。
- **可降级**：若进度紧张，可先只做"自动摆位 + 轴线检查 + depth 导出"，编辑能力后补。

## 后果

**正面**
- 分镜校验（V3）从第一天可用。
- 关键帧可获得结构条件，构图更可控。
- 为后续虚拟制片能力打底。

**负面 / 代价**
- MVP 周期增加约 2–3 周（16–22 周）。
- 需要维护模板库与自动摆位规则。
- 用户可能不愿调 3D，必须自动优先。

**跟进**
- 先实现最小交互，不做"3D 编辑器"的完整功能。
- 模板只做 6 个，验证后再扩。
- 若 3D 延期，保留 IR 结构与"场景主镜 + 走位台账"兜底。

## 替代方案

- **放 v1**：MVP 更快，但重构成本高，否决。
- **只做 2D 俯视**：无法表达机位高度/焦段/遮挡，作为降级方案保留。
