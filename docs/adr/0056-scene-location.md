# ADR-0056 场次地点：沿用一个字段，往 scene.updated 里加一项

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0050（场头）、ADR-0051（动作历史）、FEATURES A21

## 背景

ADR-0050 只把内 / 外景与日夜做成可改，负面清单里写着「场次本身仍不能编辑：地点、场号、场顺序都不能改」。其中**地点**是最常错的一项：写剧本时把「桌边」那场先挂在走廊，进场才发现；现在只能看着场头错。地点已经是 `Scene.locationId`，改它就是往回指一个已存在的地点。

## 决策

1. **`scene.updated` 的 patch 加一项 `locationId`**：`Partial<Pick<Scene, "space" | "timeOfDay" | "locationId">>`。`applyEvent` 校验地点存在（`scene.updated 指向不存在的地点`），空 patch 照旧拒绝。
2. **store `editScene` 接地点**：与其它两项同一套「只写有变化的字段」；地点不存在时拒绝（`找不到这个地点。`）；三项都没变化时仍是 `场头没改。`
3. **界面**：场头编辑器从两个下拉变成三个——`内 / 外` · `日 / 夜 / 晨 / 昏` · 地点名。地点下拉列 `project.locations` 的全部名字；若老日志里的地点已不在库里，补一个同名的当前项，不至于选出一个不存在的值。
4. **读模型带 `locationId`**：`ScriptScene` 加这个字段，界面与导出都从它读地点名。
5. **导出不用改**：`scriptToText` 一直是从 `locationById` 取名字，地点变了文本自然跟着变。

## 理由

- **同一件事的一种改法**：场头三项都是「这一场是什么」的信息，一次编译器、一条事件、一套拒绝；另开 `scene.location.updated` 会让场头散在两种事件里。
- **只允许指向已有地点**：地点本身有主镜、有锚点、有提示词（B8）；在剧本页顺手造一个新地点，会让它没有主镜也没有参考图。
- **不做场号 / 场序**：场号是镜号的前缀（SH-04 属于第 2 场），改场号要牵动镜号、导出与历史里所有引用，另做一刀。
- **不联动下游**：换地点之后，这一场镜头的关键帧、提示词按理会过期；过期标记还没做，先不假装联动。

## 后果

**正面**
- 第 1 场从`走廊`改成`桌边`：场头三位小签后仍写 `桌边`，导出文本的场头同步变成 `第 1 场 · 内 · 夜 · 桌边（10.9s · 3 镜）`；页头 5 场 / 12 镜 / 6 句 / 35.6s 不动。
- 日志只多一条 `scene.updated { locationId: "loc-table" }`；回放一致。
- 选择同一个地点不写事件（`场头没改。`）；不存在的地点拒绝且不写事件。
- 测试：IR 64 条（新增 1 条：改地点与回放，非法地点并入原拒绝用例）；web 137 条（新增 1 条：改地点、重复与非法地点）；gateway / pipeline 不变，合计 239。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：headless Chrome 打开第 1 场场头、选`桌边`；IndexedDB 第 37 条为 `scene.updated`；导出的 `.txt` 里第 1 场地点已变。

**负面**
- **换了地点不换镜头**：这一场镜头的画面、景别、机位都不会变；换成完全不同的空间（如室内换室外）需要自己改镜头。
- **不标记下游过期**：这一场镜头的关键帧、提示词不会提示重做。
- **没有「新建地点」**：只能从已有地点里选；地点库目前只能在数据里加。
- **没有场头历史**：改过几次地点、上一版是什么，页面上看不到（ADR-0050 / 0056 都没做）。
- **场号、场序仍不能改**：场次结构还是只读。
- **地点选择不显示主镜状态**：下拉里只有名字，不知道哪个地点已经有主镜、哪个还空着。

**跟进**
- 新建 / 编辑地点（名字、模板、主镜）。
- 场头改动标记这一场下游产物过期。
- 场头改写的版本列表（与动作、台词同一套折叠）。
- 场号与场序调整（牵动镜号与全部引用）。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 新增 `scene.location.updated` | 场头三项是同一件事，两种事件会让读模型与历史都要写两遍 |
| 允许在剧本页顺手新建地点 | 新地点没有主镜与参考图，提示词会指向一个空场景 |
| 直接改 `project.created` 快照 | 抹掉历史，回放与「改过几次」都对不上 |
| 把地点写成自由文本 | 地点是有主镜与锚点的实体；文本无法引用资产 |
| 改地点时顺带改这一场镜头 | 景别、机位、动作都是用户的决定，自动改会把编辑偷走 |
