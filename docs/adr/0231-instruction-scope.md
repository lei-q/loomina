# ADR-0231：一句话可以落在这一镜 / 这一场 / 整片（E11 第一档）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：E11、F7、H19、ADR-0039、ADR-0217、UX.md §七

## 背景

UX.md §七 说时间线默认不露，理由是「大多数修改可以用语义编辑完成」。
但语义编辑（F7 / H19）一直只能改**当前这一镜**——想「这一场都快一点」，得逐镜说一遍。

E11「语义编辑入口」要的是**意图层**的修改：作者说的是「整片太暗了」，工具该知道那是整片。

## 决定

1. **`parseInstructionScope(text)`**（pipeline，与 `parseInstruction` 同处）：
   - 「整片 / 全片 / 整条片 / 所有镜头 / 每一镜 / 每一场都」→ `film`；
   - 「这一场 / 整场 / 这场」→ `scene`；
   - 「这一镜 / 这镜 / 当前镜」→ `shot`；
   - **没说就按调用方给的默认**（界面传 `shot`）。
2. **匹配顺序先整片后整场**：说「整片每一场」时不能被「每一场」抢走。
3. **`instructScope(text)`**（store）：
   - 按作用域取目标镜（整片 = 全部；这一场 = 同场；这一镜 = 当前）；
   - **每镜各自算补丁**——同一句「快一点」在 2 秒的镜与 6 秒的镜上改出来不一样；
   - 锁定的镜跳过；一句都没听懂时不写事件；
   - **整批共用一个 `at`**：撤销一步整批退回（与 I7 批量套用同一口径）。
4. **界面**：reel-bar 的输入框改用作用域版本，改完在输入框旁提示「这句改了 N 镜」；
   占位文案补一句「前面加『这一场』『整片』改一片」。
5. **只认明确说的**：宁可少改，不可多改。认不出作用域就只改当前这一镜。

## 理由

- **作用域是指令的一部分**：作者说「整片」和说「这一镜」是两件事，工具不该替他猜。
  但猜的代价不对称——多改要撤十几步，少改只是再说一遍。所以默认最保守。
- **每镜各算补丁**：`parseInstruction` 的补丁依赖镜头当前状态（景别、时长、机位），
  套用同一份补丁会让所有镜变成一模一样，那是「批量重设」，不是「都改快一点」。
- **共用 `at`**：一次说出口的操作，撤销就该是一步。
- **不做「撤销半边」**：范围内的镜要么都改要么都不改（锁定的除外），
  不做「部分成功」的复杂态。

## 后果

**正面**

- 「这一场都快一点」「整片都暗一点」从逐镜说变成一句话。
- 改完能看见「这句改了 N 镜」，不会不知道影响面。
- 与 I7 批量套用共用「整批一个 `at`」的口径。

**负面 / 代价**

- **作用域靠词面判断**：说「这片子整体感觉偏暗」不一定被认出是整片
  （没有「整片 / 全片」这些词就按当前镜）。
- 只做**时间线上的镜**：不能按「所有特写」这类条件筛（那是另一套查询语言）。
- 模型兜底那条路（`instructWithModel`）仍然只作用于当前这一镜，没有跟着扩。
- 整片范围可能一次写几十条事件，日志会变长。
