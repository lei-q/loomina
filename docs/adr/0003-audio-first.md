# ADR-0003 音频先行：对白时长决定镜头时长

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P5、C1、C2、A5、E2

## 背景

直觉流程是"先生成画面，再补配音"。但在短剧里，对白是叙事骨架；若画面先定，配音就必须靠变速、裁剪、拉伸去凑，结果是：

- 口型永远对不上；
- 剪辑反复重卡点；
- 台词被删改后画面全废。

## 决策

对白场景采用**音频先行**：

1. 剧本/台词定稿。
2. TTS 生成对白，得到每句的精确时长。
3. 镜头时长与剪辑点服从音频时长（允许 ± 少量呼吸空间）。
4. 再生成关键帧与视频，使画面适配已知时长。
5. 口型同步作为后期微调，而非结构性依赖。

非对白镜头（空镜、动作、氛围）仍可用画面定节奏。

## 理由

- 对白时长是硬约束，画面是柔性的；让柔性的一方去适配硬性的一方，返工最少。
- 配音质量直接影响"AI 味"，先定音频可以早期发现问题。
- 自动初剪可以直接用音频时间轴驱动。

## 后果

**正面**
- 音画对齐自然，避免机械变速。
- 台词改动影响面可控（重生成对应镜头即可）。
- 自动剪辑的节拍有可靠依据。

**负面 / 代价**
- 管线顺序被约束，不能"先随便出画面"。
- TTS 失败会阻塞；需要多音色备选与重试。

**跟进**
- IR 中 `DialogueLine.durationMs` 与 `Shot.durationMs` 的一致性检查。 
- 非对白镜头走画面优先模式的开关。

## 替代方案

- **画面先行 + 后期对齐**：返工成本高，否决。
- **音频与画面并行**：看似快，但需要反复协商时长，实际更慢。
