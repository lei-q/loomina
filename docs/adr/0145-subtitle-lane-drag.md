# ADR-0145 字幕条上的整句拖动

- 状态：已接受
- 日期：2026-11-12
- 决策人：用户 + Claude
- 关联：ADR-0087（字幕派生）、ADR-0131（按句偏移）、E1

## 背景

ADR-0131 给每一句台词加了 `voiceOffsetMs` / `subtitleOffsetMs`，成片页用 `‹ ›` 按钮挪：点一下 100ms，按住 Shift 500ms。这个设计对「对一下口型」够用，对「把这句话挪到画面空的地方」不够：挪 1.5 秒要按 15 下，眼睛还得来回核对字幕条。

E1 的「自由拖动起点」一直挂着。字幕条已经按绝对时间画出了每一句的位置（ADR-0131 之后，挪过的字幕在条上能看见它离开原位），最自然的交互就是直接拽它。

## 决策

1. **只在字幕条上拖，拖的是字幕偏移。** 画面轨必须首尾相接（渲染清单要求），不能自由挪；配音没有自己的条，继续用按钮。拖一条字幕改的是那一句的 `subtitleOffsetMs`，不是整条时间线。
2. **像素按轨道宽度线性换算，取整到 10ms。** `dragDeltaMs(dx, laneWidth, totalMs)` 是纯函数：轨道宽度或时长无效时返回 0。10ms 一档比按钮的 100ms 细，也比逐帧对齐粗，适合「整句挪个位置」。
3. **夹取发生在目标值上。** `clampedDeltaMs(current, delta)` 先把「当前偏移 + 位移」夹进 ±30 秒（`TRACK_OFFSET_MAX_MS`），再取整、折回成本次要写的增量。已经贴着上限时往同方向拖，增量是 0，不会越界报错。
4. **拖动只在本机预览，松手才写一次事件。** 按下记起点，pointermove 只更新一个本机 `deltaMs` 并让那条字幕实时跟手；pointerup 才调一次 `shiftLineTrack`，写一条 `dialogue.updated`。一次拖动在日志里留一条记录，不是一百条。
5. **3px 以内算点击。** 手一抖不算拖动；真正的点击仍然跳到那一句并打开断句编辑器。拖动之后的 click 会被吞掉，避免松手顺手打开编辑器。
6. **只读、锁定照旧。** `readOnly` 时不接管 pointerdown，拖动与按钮同时失效；按钮与 Shift 精调保留，拖动不是替代品。
7. **不新增 IR 字段、不新增事件类型。** 拖动的结果就是已有的 `subtitleOffsetMs`；SRT、ASS、预览、渲染清单与 OTIO 都自动跟着走。

## 理由

- **直接操作比按钮快一个数量级**：大体位置用拖，最后几十毫秒用按钮，两种手感落在同一个字段上。
- **松手才写是对日志的尊重**：事件日志是唯一事实来源（ADR-0001），拖动过程的每个中间位置没有语义，不该进日志。
- **纯函数换算可测**：像素与毫秒的关系不依赖 DOM，边界（0 宽、±30 秒、亚像素）用单测锁住，组件只负责把事件接上。
- **不做吸附**：没有可靠的「对白起点 / 画面切点」吸附目标时，吸附只会让拖动更难预测；等 C5 有节拍检测再谈卡点。

## 后果

**正面**

- 挪 1.5 秒从 15 次点击变成一次拖动，字幕条上的位置实时可见。
- 事件条数从「每次点击一条」降到「每次拖动一条」；日志更好读，撤销也按一次拖动回退。
- 与按钮、Shift、`↺` 归位共用同一条路径，不存在两套偏移。

**负面 / 代价**

- 拖动是鼠标 / 触摸交互，键盘用户仍靠按钮；快捷键没有新增。
- 字幕条只有 26px 高，微小的横向抖动会被 3px 阈值过滤，但也会让「拖 10ms」在低缩放下不现实——那本来该用按钮。
- 拖到轨道外时字幕会被 `overflow-hidden` 裁掉一部分；松手后仍在片外时由读模型夹回成片之内（既有规则），IR 保留作者填的原值。

**边界**

- 配音没有自己的条，不能拖；独立多轨（画外音层）仍未做。
- 不能拖动画面片段或改变镜头顺序（那不是 E1 的范围）。
- 没有吸附、没有跨句联动、没有多选。

## 验证

- `track-drag.test.ts` 4 条：线性换算与 10ms 取整、无效宽度 / 时长返回 0、±30 秒夹取（贴边同向拖为 0）、从中间一次拉回另一侧。
- web 890 条全过；`tsc --noEmit` 与 `next build` 干净。
- 浏览器：成片页字幕条上按住第一句向右拖 40px → 条上实时跟手并出现聚焦描边 → 松手后日志只多一条 `dialogue.updated { subtitleOffsetMs: 440 }`，提示「字幕整句挪了 +440ms」，「音轨与字幕轨」里写「字幕 +440ms」；点一下同一句不挪动、直接打开「手改断句」；点 `↺` 写 `subtitleOffsetMs: null` 归位。
