# ADR-0155：覆盖率模板、独立报告与补镜估价

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：A10、A12、A13、ADR-0096、准则 P15 / P21

## 背景

ADR-0096 把覆盖率定义为「每一拍同时有信息镜头与情绪 / 反应镜头」，并检查抽屉里逐拍显示缺口。它明确把这轮不做的三件事写进了 §7：独立 `CoveragePlan` 实体、Beat 级成本估算、覆盖率模板库。当时 `Shot.beat` / `Shot.purpose` 的读写闭环刚落地，先保住读模型比堆模板重要。

现在 A10 的三个欠账要收口：`STORYBOARD.md` 与 `DIRECTOR-GRAMMAR.md` 已经列了六种常用覆盖率模板；`requoteShot` 已经能按价目表给单镜草稿档估价；分镜抽屉已有覆盖率、逐拍缺口、当前镜目的下拉与 `setShotPlan` 写入口。剩下的工作是把这些**已有的事实**摆到作者手边，而不是再造一份项目结构。

## 决定

1. 新建纯函数层 `apps/web/lib/coverage-plan.ts`，只吃 `StoryboardReport`，不碰 IR、不写事件。
2. 模板是六条纯数据，来自 `docs/STORYBOARD.md` §四：双人对话、对峙冲突、信息揭示、单人情绪、动作、蒙太奇。每条带镜头序列、信息 / 情绪目的、建议补镜数与一句适用说明。
3. `coverageGaps(report)` 把未覆盖的拍收成 `{ information, emotion, both }` 三类缺口；`coverageTemplatesFor(gap)` 只给能补齐这三类缺口的模板，不为已经齐的拍硬推荐。
4. `coverageEstimate(report, templates)` 用 `requoteShot(3000)` × 每个缺口建议补几镜。它与 V8 是同一份价目表、同一档草稿规格；报不出价就返回 `basis` 与 `undefined`，界面写「报不出价」，不把未知当 0。
5. `coverageReportText(input)` 产出一份独立纯文本报告：项目名、覆盖率、拍数、逐拍缺口、推荐模板、成本口径、当前校验错误 / 提示。界面「复制报告」与「下载 .txt」用的是同一个字符串，不另造格式、不引依赖。
6. 抽屉里新增「覆盖率收口」段：先显示缺口汇总与补镜估价，再列模板按钮。选中模板后展示景别序列；「把这一镜标成 X」只对**当前镜**生效，走既有 `setShotPlan` 写一条 `shot.updated`。只读、锁镜、当前镜没有拍时禁用按钮。
7. 模板不写进 IR：景别序列只是给作者看「下一镜该拍什么」，真正改项目仍然只有作者点目的下拉或一键标目的。不自动插镜头、不自动拆长镜、不自动发请求。

## 理由

- **不重复造实体**：ADR-0096 的 `BeatSpan` 已经是派生读模型，模板与报告只要吃这份报告就够了；`CoveragePlan` 一旦进 IR，就要多一套事件、回放、删除与回滚。
- **成本必须和 V8 同口径**：准则 P21 不允许估不出来的价进入界面。复用 `requoteShot` 避免「同一个 3 秒镜头，检查抽屉说 ¥1、整片重做说 ¥2」。
- **作者仍然决定写什么**：模板只是建议，写 `shot.updated` 的动作与手动选目的完全一致；符合「推断不写回 IR」这条既有不变量。
- **独立报告能带走**：浏览器纯文本无需服务端，复制 / 下载同源；作者可以贴到自己的笔记或评审里，不必截图。
- **先收口，不假装评测过**：六种模板来自文档，没有 30 条授权样片的 A/B 数据；界面与报告都标「文档模板，未标定」。

## 后果

**正面**

- A10 的三个欠账都有可操作界面：按缺口选模板、把推荐目的落到当前镜、复制 / 下载报告、看补镜估价。
- 价目未知时如实说「报不出价」，不制造假预算。
- 锁镜、只读、空项目都不会误写；模板不进事件日志。
- 不新增依赖、不新增 API、不新增 IR 字段；旧项目直接可用。

**负面 / 代价**

- 3 秒是补镜估价的名义时长，真实镜长由作者决定；报告里写明口径。
- 模板未经样片标定，可能不适用于具体题材；作者要自己选，不设硬闸门。
- 一键标目的只改当前镜的 `purpose`，不改景别、不插镜头；模板里的 master / OTS / CU 仍需作者到分镜页落实。
- 报告是当下快照，不随项目改动自动更新；重新打开抽屉即重算。

**不做**

- 独立 `CoveragePlan` / `Beat` 实体、模板库持久化、跨项目复用。
- 自动补镜、自动改景别、自动改提示词、自动生成关键帧或视频。
- 模板 A/B 标定与通过率统计（归 I9 评测集）。
- 供应商回执级成本、按自定义单价重算补镜估价（H22 的自定义单价另有落点）。
- 把覆盖率做成导出或生成前的硬闸门；仍按 ADR-0096 保持提示级。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 把模板序列存进 `Project` | 它是建议不是项目事实，会让每次改稿都多一整套回放 / 回滚 |
| 模型自动按模板生成分镜 | 供应商不可控，且违背 P15「LLM 创意 + 规则合法性」的约束求解边界 |
| 用真实镜长逐拍估价 | 还没决定补哪一镜、补几秒；拿 3 秒草稿档统一定价更诚实 |
| 下载 JSON / PDF | 需要额外格式或库；纯文本已能复制、存档、diff |
| 不给成本，只给模板 | A10 明确要求成本估算，且 P21 要求贵步骤前给出金额影响 |
| 报不出价就显示 ¥0 | 未知不等于免费，会把预算护栏骗过去 |
