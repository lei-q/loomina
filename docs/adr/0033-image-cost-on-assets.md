# ADR-0033 出图成本记在资产上，未知价目不记 0

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0028（资产层）、ADR-0031 / ADR-0032（服务端出图）、COST.md、H12、准则 P21

## 背景

顶栏的「已花」一直是 `project.takes` 的 `costCny` 之和。ADR-0031、ADR-0032 接通定妆出图之后，一次"生成三视图"实际花了四张图的钱，而账面上是零：

- 用户看到「已花 ¥18.96」，但刚刚为四格定妆付了钱，界面没说，也没数；
- 整片报价（`requoteProject`）只算"重做分镜要多少钱"，不含已经烧掉的定妆图；
- 出图是**重复发生**的动作：不满意就再生成，成本随时累加，比一次性的重做更容易失控。

要记就得有个落点。现有账本只有 `Take.costCny`，出图结果不是 take。

## 决策

1. **`Asset` 增加可选字段 `costCny`**：生成成功时由服务端按价目表写入，`0.12` 这样的数就是这张图的钱。
2. **未知价目就不写字段**，不写 `0`。`Asset.costCny === undefined` 表示"不知道多少钱"，与"免费"是两件事。
3. **服务端算价，客户端不算**：`generateCastImage` 调 `imageCostCny(model)`（`packages/gateway/pricing.ts` 里已有的价目表），随回包带回 `cny`；store 只把它写进 `asset.updated` 的资产里。
4. **已花 = take + 有价目的资产**：新增 `spendOf(project)`（`apps/web/lib/read-model.ts`），`StageView.spent` 与 `CastView.spend` 都从它来。
5. **无价目的图单独计数并显示**：`spendOf` 返回 `unpriced`（生成过、有 `uri`、但没有 `costCny` 的张数），金额面板里写一句"另有 N 张定妆图没有价目，没算进已花"。
6. **定妆台也显示金额**：`TopBar` 在定妆页同样显示已花 / 预算，展开可看明细——钱是在这一页花出去的，不能只有分镜页看得见。

## 理由

- **成本跟着产物走**：资产是被买下来的东西，价钱记在它身上，重放事件日志就能还原账目，不需要第二套账本。
- **不写 0 是这条 ADR 的重点**：把未知算成免费，会让预算条永远是绿的，等到月末账单来才发现超了。宁可显示一句"没算进去"。
- **服务端持有价目表**：单价属于供应商知识，和密钥一样不该进浏览器 bundle；客户端只接收一个数。
- **`unpriced` 是可见的债**：当前 `IMAGE_MODEL` 是 `gpt-image-2`，而 CNY 价目表里只有 `-c` 系列。这句话每天都在提醒"要么确认单价，要么换模型"。

## 后果

**正面**
- 定妆出图第一次进账：价目表有价的模型（`gpt-image-2-c` 等）每张 ¥0.12 立刻体现在已花里，重放事件日志后金额一致。
- 无价目时界面如实说，不把未知洗成免费。
- 价目只在服务端查一次，客户端与测试都不复制单价。

**负面**
- **当前定妆图全部落在"无价目"**：`secrity.env` 的 `IMAGE_MODEL` 是 `gpt-image-2`，`IMAGE_PRICES` 没有它。界面上会一直显示"另有 N 张…"。要消掉这句，得拿真实账单确认单价，或改用 `-c`（约便宜一个数量级）。
- 只有"生成"的资产有机会带价：上传、素材库的资产没有成本，这是对的，但 `unpriced` 的判定必须排除它们（新加字段时容易漏）。
- 预算条仍然不阻断：超了只是数字变红，没有拦（H12 的另一半）。

**跟进**
- 对一次真实账单，补 `gpt-image-2` / `gemini-2.5-flash-image` 的 CNY 单价；或者把 `IMAGE_MODEL` 换成有价目的一档。
- 重做报价与"已花"合并成一个面板（现在一个在分镜页、一个在定妆页）。
- 账本要能按阶段分组（定妆 / 分镜 / 声音），否则片子长了只有一个总数。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 新增 `CostEntry[]` 账本并写独立事件 | 为一次性的记账多一套结构与事件；资产本身就是产物，挂在它上面够用 |
| 未定价按同档均价估 | 估出来的数会被当成真账；宁可缺一行，不要假一行 |
| 在客户端读取价目表算价 | 单价进 bundle，且两处价目早晚漂移 |
| `costCny` 默认 0 | 抹掉"未知"与"免费"的区别，正是这次要修的毛病 |
