# ADR-0188：多工作空间——一份日志一条完整流程（C3 / C4）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C3、C4、C1、C15、F3、H3、ADR-0034、ADR-0180、ADR-0128

## 背景

现在一个浏览器只存**一条**事件日志（ADR-0034）：一个新项目就是新的 `project.created`，
旧日志被替换。做第二集时，要么把第一集的日志覆盖掉，要么把两份东西挤在同一份日志里。
用户要的是「多个工作空间，每个空间独立创作，同时开多条故事 → 成片的完整流程，
资产库共用」。

单写者锁也只有一个 key：第二个标签页一打开就只读，两条流程没法同时跑。

## 决定

1. **工作空间 = 一条独立的事件日志**
   - `events` 仓继续共用，每行多一个 `workspaceId`；读的时候按它过滤。
   - **老行没有这个字段，一律归 `w-default`**：升级不搬行、不改内容，也就不可能搬丢；
     `meta` 里的日志版本也改成按空间存（`log:<workspaceId>`），老键按版本 1 迁移。
   - 工作空间自己的登记表放在新仓 `workspaces`：`{ id, name, createdAt, lastOpenedAt }`。
     第一次打开时把当前空间补登记进去，名字取项目标题——老用户升级后看到的是
     「默认工作空间」，不是一个空列表。

2. **换空间走整页加载，不在内存里换日志**
   - 顶栏选另一个空间 → 记住 id（`localStorage: loomina.workspace`）→ `location.assign("/")`。
   - 理由：每个页面都有自己的播放器、当前镜、草稿与异步任务；在内存里换日志，
     很容易留下上一份项目的局部状态。整页加载是最便宜也最不会错的做法。
   - 反过来说，**同时开多个工作空间 = 多个标签页各停在一个空间**；每个空间一把写锁
     （`loomina-writer:<workspaceId>`），不同空间的标签页可以同时写。

3. **新建工作空间从示例项目开工**
   - 新空间写一条自己的 `project.created`（项目 id 按空间生成，标题 = 空间名），
     作者随后在故事页生成 / 导入自己的项目，旧日志照旧被替换。
   - 不做一个「空白项目」的新 schema：示例项目已经是可回放、可操作的最小起点。
   - 重名拒绝（名字用于切换时认人）；名字上限 40 字；改名只改登记表，
     不动项目标题与日志。

4. **素材库保持全机共用**
   - `.loomina/assets` 与对象存储本来就是内容寻址、全机共享（ADR-0128）；
     工作空间只分开事件日志，不分开素材文件。同一个文件在两个空间里被引用时，
     盘上仍只有一份。
   - **跨空间挑素材的界面还没做**：现在资产库页只列当前项目的资产记录；
     下一档再做「从别的空间取一张参考图 / 一段音轨」，取用时把资产记录复制进当前项目，
     不改地址、不重新生成、不花钱。

## 理由

- **日志隔离是唯一需要隔离的东西**：项目、预算、闸门、发布记录都从日志回放；
  素材字节按地址共享，本来就不该复制。
- **不搬家老数据**：迁移最怕「写一半失败」。这里连行都不动，只在读的时候把
  `undefined` 当默认空间，升级失败也仍然读得到原项目。
- **整页加载换空间**：听起来土，但它把「两个项目的状态混在一起」这类 bug 一次性关掉；
  切换是低频动作，多等一次加载完全值得。
- **锁按空间分**：这正是「同时开两条流程」的技术前提；同一空间仍然只许一个写者。

## 后果

**正面**

- 可以同时做多集 / 多个题材，各自的日志、撤销、回滚、闸门互不干扰。
- 两个标签页能同时编辑两个工作空间，一个空间仍只有一个写者。
- 升级零迁移：老项目自动成为「默认工作空间」。
- 素材文件仍全机一份，不会因为多开空间把同一张图存两遍。

**负面 / 代价**

- 工作空间名与项目标题是两套名字：改名不改标题，界面上要能分清。
- 新建空间暂时从示例项目开始，不是空白；作者要先在故事页开工。
- 工作空间不能删除（第一档只做建、切换、改名）——删除是破坏性动作，
  要先想清「删日志还是删素材」，不在这一刀里顺手做。
- 跨空间资产取用还没有界面；共用目前只体现在文件层。
- 每个空间各自一份预算与名额，顶栏的账目只对当前空间。

## 不做

- 删除 / 归档工作空间、导出某个空间为独立文件。
- 跨工作空间挑素材的界面（C4 后半段 / C1）。
- 工作空间级别的团队、权限、分享（单机单用户）。
- 在内存里并发加载多个空间（不做「同时显示两个空间」的工作台）。
