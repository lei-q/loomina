# ADR-0012 短镜头与覆盖率优先，不为长镜头而写

- 状态：已接受
- 日期：2026-11-09
- 决策者：产品 / 工程
- 关联：P3、P4、P13、L4、B3

## 背景

当前视频模型稳定输出的时长通常在 5–10 秒，且同一镜头内越往后越容易"漂移"（人物变形、动作失稳、场景变化）。而剧本写作的直觉是写长镜头、连续对话。

如果按直觉写分镜，会得到：

- 一个 20 秒的对白镜头，模型无法一次生成；
- 强行拼接多段，首尾帧误差累积，人物越拼越不像；
- 运镜不可控，节奏拖沓。

影视剪辑的常规做法不是长镜头，而是 **coverage（覆盖率）**：同一场景拍 master、双人、过肩、特写，靠剪辑组织叙事。

## 决策

分镜默认按"为剪辑而写"设计：

1. **单镜默认 2–5 秒**，不超过所选模型的安全上限。
2. 长场景拆成多镜：master（交代空间）→ over-the-shoulder / 双人 → 特写（情绪）→ 反应镜头。
3. 确需超过模型上限的镜头，拆成 **GenerationSegment**，用上一段尾帧作为下一段首帧衔接；但**限制段数**（建议 ≤ 2），超过则改为多镜剪辑。
4. IR 中 `Shot` 挂 `segments[]`，每段有独立 Take 与首尾帧。
5. 分镜提示词、摄影参数、时长都按"短镜"生成。

## 理由

- 短镜是模型能力与叙事节奏的交集：既避开模型上限，又符合短剧快切。
- 覆盖率让剪辑有选择，减少"一个镜头毁全场"的风险。
- 反应镜头/特写比重更高的成本更低、情绪更强。

## 后果

**正面**
- 生成成功率上升，重试成本下降。
- 节奏更接近成熟短剧。
- 剪辑素材充足，自动初剪更容易。

**负面 / 代价**
- 镜头数量增加，分镜与 QA 的工作量上升。
- 需要教会 LLM 分镜师"覆盖率"思维，提示词与模板要相应调整。
- 段间衔接仍有漂移风险。

**跟进**
- 在剧本/分镜模板中加入"覆盖率检查"（是否有 master、是否有反应镜头）。
- 能力测绘（S1）确定各模型的安全时长，写入能力矩阵。
- QA 需检查段间衔接处的一致性。

## 替代方案

- **长镜头 + 视频延长**：漂移累积、成本高，否决为默认。
- **一镜到底**：叙事单调、模型不可控，仅在特殊风格时使用。
