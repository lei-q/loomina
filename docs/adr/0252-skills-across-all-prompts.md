# ADR-0252：技能作用到全流程提示词，并支持就地编辑

- 状态：已采纳
- 日期：2026-11-15
- 决策者：用户 + Claude
- 关联：C18、A1、A18、H19、B3、C1、C4、ADR-0191

## 背景

C18 的技能原先只拼进**四类出图提示词**（关键帧 / 定妆三视图 / 场景主镜 / 道具）。
用户明确要求技能要作用于**视频、故事、剧本、定妆、分镜、关键帧、配音、配乐**，
并且「要像 agent 工具那样方便地集成 / 切换 / 移除」。旧界面只有新增、开关与删除，
没有就地编辑，阶段也只有五个。

## 决策

### 1. 阶段扩到 11 个

`all` / `story` / `script` / `sheet` / `storyboard` / `master` / `prop` / `keyframe` /
`video` / `voice` / `music`。`all` 对每个入口生效；同阶段才拼。

### 2. 每个阶段接进哪个提示词

| 阶段 | 接入点 | 拼接位置 |
| --- | --- | --- |
| story | `generateStory`（含导入 txt 改写） | 系统提示词的硬约束后 |
| script | 剧本医生 `doctorMessages` | 系统提示词末尾 |
| storyboard | 一句话指令 `instructionMessages` | 系统提示词末尾 |
| sheet / master / prop / keyframe | 四类出图提示词 | 风格那句之前（风格永远最后） |
| video | `buildVideoPrompt` | 同上 |
| voice | TTS 的 `instructions` | 表演说明之后 |
| music | **暂无模型调用**（C4 音乐生成未做） | 先存着、不生效 |

### 3. 服务端再校验一遍

三个路由（story / doctor / instruction / video / voice）用
`ProjectSkillSchema` 数组校验，最多 20 条；格式不对直接 400，不截断、不猜。

### 4. 管理界面补「改」

设置页技能区每条多一个「改」：把名字 / 阶段 / 说明 / 内容填回表单，
存的时候走既有的 `updateSkill`（只写改过的字段，仍是一次 `project.updated`）。
开关、删除、导入导出、跨空间取用保持不变——它们已经是「集成 / 切换 / 移除」的三条路径，
缺的只是**编辑**这一个动作。

## 理由

- **技能是「作者对模型的长期口味」**，不是出图专属：故事要「主角必须女性」、
  视频要「不要水印」、配音要「语速偏慢」，都是同一类东西，按模态分家会让作者写五遍。
- **只加阶段，不加新实体**：仍是 `Project.skills`，仍走 `project.updated`，
  日志版本不变；旧项目里的 `stage` 值全部合法。
- **配乐阶段先占位**：技能字段可以写，但 C4 的音乐生成还没做，
  不假装它现在有效——界面文案写清楚。

## 后果

**正面**

- 一条技能可以覆盖多阶段（`all`），也能精确限定到某一个阶段。
- 编辑不再需要「删了重建」，历史里是一条更新而不是两条事件。

**负面 / 跟进**

- **没有提示词总量上限**（C18 未做项）：几十条技能会挤占上下文，
  目前靠 2000 字 / 条与 20 条上限兜底，仍需一条总预算。
- 配乐阶段暂时空转；C4 落地后要补接入点。
- 视频与配音的真实效果仍受供应商能力限制（音频部署、视频只收首帧图）。

## 替代方案

1. **每个模态一张独立技能表**：查询清晰，但作者要维护多份、跨阶段复用要复制——否决。
2. **只扩到视频 / 故事**：用户明确列了八个阶段，做一半等于没做。
3. **把技能塞进「提示词手改」**：手改是单次覆盖，技能是可复用、可开关的，语义不同。

## 落地节（2026-11-16）：每页抽屉、总预算、配乐阶段先收起

### 每页抽屉

`SkillsPanel`（`apps/web/components/skills-panel.tsx`）挂在共享 `TopBar` 上：
只要页面传了 `skillStages`，顶栏就出现「技能」按钮，抽屉里只列**这一页会用到**的技能
（同阶段 + 全部阶段），加 / 改 / 开关 / 删都在抽屉里做完。页面与阶段：

| 页面 | 阶段 |
| --- | --- |
| 故事 | story |
| 剧本 | script |
| 定妆 | sheet / master / prop |
| 分镜 | storyboard |
| 关键帧 | keyframe |
| 声音 | voice |

设置页的「技能」区保留，作为全量管理（导入 / 导出 / 跨空间取用 / 所有阶段）。
关掉的技能在抽屉里折进「已关掉的技能」，能在原地重新打开——否则在设置页关了之后
到页面里就找不到了。

### 总预算

`SKILL_TOTAL_BUDGET = 4000` 字（`skillCharsOf` / `skillsForStages`）。
抽屉里显示「本轮拼进 N 字」，超过只是标红提示，**不静默截断**：
作者写的东西不能不打招呼就少一半；真要压，由作者自己删。

### 配乐阶段先收起

C4 的音乐生成还没做，技能存了也不会生效。决定**不等 C4**：阶段枚举保留
（旧数据合法），但设置页的下拉与页面抽屉都不再提供 `music`，成片页不挂技能按钮。
C4 落地后把 `music` 放回下拉即可，不需要改数据。

### 验证

- pipeline 163 条（新增并集筛选与预算 2 条）、全仓测试与 typecheck 通过。
- 抽屉在六类页面出现；设置页仍是全量入口。
