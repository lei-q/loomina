# ADR-0115：ASS 字幕与节拍摘要

- 日期：2026-11-11
- 状态：已采纳
- 关联：D4、A11、ADR-0086、ADR-0087、ADR-0096

## 背景

两条小尾巴，都卡在「数据已经有，只差读出来」：

- **D4**：SRT 早就能导，ASS 一直没做。剪映 / Premiere / DaVinci 里做字幕样式，ASS 比 SRT 省事——它能把字号、描边、底边距离一起带过去。
- **A11**：`Shot.beat` 与覆盖率检查都在，检查抽屉能逐拍列出，但**没有一句总览**。作者要自己数「一共几拍、哪拍最长、整条片子的节拍链长什么样」。

两条都不需要新数据模型。

## 决策

### 1. ASS 从同一份 cue 生成，样式跟成片页对齐

`buildAss(view, styleId)` 与 `buildSrt` 读同一份 `view.cues`，所以断句、时间、顺序与 SRT 完全一致。差别只在输出格式：

| 项 | SRT | ASS |
| --- | --- | --- |
| 时间 | `00:00:02,600` | `0:00:02.60` |
| 样式 | 无 | `[V4+ Styles]` 一段 Default 样式 |
| 画布 | 无 | `PlayResX: 1080` / `PlayResY: 1920` |

样式参数从 `SUBTITLE_STYLES[styleId]` 换算：`fontSizeCqw`（画面宽度百分比）换算到 1920 高的 `Fontsize`，`bottomPct` 换到 `MarginV`，`strokeCqw` 换到 `Outline`。切「大字」档导出的 ASS，在剪辑软件里打开就是大字——不用再手工调一遍。

ASS 头里写一行 `; AI 生成内容：本片由 AI 生成（AI生成）`：字幕文件也是交付物，标识跟着走（H5 / R2）。

### 2. 节拍摘要是读模型的派生，不写 IR

`digestBeats(beats)` 只做聚合，不引入新事实：

- `count` / `totalSeconds` / `covered`：数一数。
- `longest`：时长最大的一拍（并列取靠前的）。
- `arc`：「钩子 → 铺垫 → 升级」，按顺序拼节拍名。
- 每一行补上 `sharePct`（占全片时长）与 `missing`（缺信息 / 缺情绪 / 都不缺）。

界面放在检查抽屉「节拍」标题下面：先一行总览，再一行节拍链，然后才是原来的逐拍列表。**不新建独立 Beat 实体**：一拍的边界就是「同场连续同 beat」，`groupBeats` 已经算出来了，再存一份只会多一个会漂移的事实来源。

### 3. Beat 级成本仍不做

「这一拍花了多少钱」听起来有用，但它要求把 take 的 `costCny` 按拍归属，而一拍可以横跨多个镜头、一个镜头只属于一拍——归属是确定的，问题在于**它不改变任何决策**：预算按项目与单镜拦（H10），没人会因为「这一拍贵」就少拍一镜。等真有按拍排产的需求再说。

## 后果

- ASS 与 SRT 永远同步：改断句档位、改字幕样式，两种格式一起变。
- 节拍摘要让「这条片子的节奏长什么样」一眼可见，不用数。
- 摘要是派生值：改了某镜的 beat，总览与节拍链立刻跟着变，不需要额外写事件。
- 导出 ASS 与 SRT 一样受导出闸门约束（合规预检通过才可点）。

## 验证

- 单测 753 全过（IR 149 + gateway 28 + pipeline 51 + web 525）。
  - `edit.test.ts` 新增 3 条：ASS 三段头与厘秒时间、字号 / 底边距离随档位变化、没有台词时只有头。
  - `storyboard.test.ts` 新增 3 条：一拍一行的镜号 / 时长 / 占比 / 覆盖与缺什么、缺信息与缺情绪分开写、最长一拍与空输入。
- `pnpm typecheck`、`next build` 全过。
- 浏览器（生产 3100，成片页）：出现「导出字幕 ASS」按钮，未确认导出闸门时与其他导出按钮一样禁用。
- 浏览器（分镜页，检查抽屉）：「节拍」上方出现「10 拍 · 共 32.6s · 覆盖 0/10 · 最长「铺垫」4.8s（15%）」与节拍链「钩子 → 铺垫 → 铺垫 → 升级 → 升级 → 升级 → 转折 → 转折 → 高潮 → 尾钩」。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| ASS 用固定样式，不跟档位 | 导出的字幕和成片里看到的字号对不上，还得手工调 |
| 把 ASS 当第二种 SRT 只换扩展名 | ASS 的价值就在样式头，去掉等于没做 |
| 建独立 Beat 实体与 Beat 级成本 | 一拍的边界由「同场连续同 beat」完全推出，再存一份只会漂移；按拍的成本不改变任何决策 |
| 节拍摘要写进 IR | 它是派生值，写进 IR 会让「改了 beat 但摘要没更新」变成可能 |
