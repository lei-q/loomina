# ADR-0226：空间混响先定口径，渲染侧暂不接（C11 第一档）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：C11、C7、C4、C12、SOUND.md §八

## 背景

SOUND.md §八 把「空间混响」列为声音一致性的四条之一：
**同场景同一套 reverb 参数**。§九 的声音 QA 里也有一条「空间错：卧室像大厅 → reverb 未匹配」。

C11 的未做项从 C7 起就写着「按场景切换混响」。难点不在滤镜本身，而在**混响跟什么走**：

- 跟镜头走 → 同一场里两镜不同混响，观众听得出「换房间了」；
- 跟场走 → 正确，但需要知道每一场是什么空间；
- 跟地点走 → 最稳，但 `Location` 里没有「客厅 / 走廊」这种结构化字段。

IR 现状：`Scene.space` 只有 `int` / `ext` 两档，`Location` 只有名字与描述。
所以「这是什么空间」只能从名字认。

## 决定

1. **混响跟场走**：`reverbPlanOf(project)` 按场列出预设，同一场只用一套。
   这是 SOUND.md 的硬要求，不是可选项。
2. **六套预设**：干声 / 小房间 / 客厅 / 走廊 / 大厅 / 室外。每套给 `decayMs` /
   `roomSize` / `wet` 三个参数。
3. **空间判定按名字 + 内外景**：`reverbPresetOf(location, sceneSpace)`
   - 名字里有「走廊 / 楼道 / 通道 / 车库」→ 走廊档；
   - 「大厅 / 商场 / 礼堂 / 大堂」→ 大厅档；
   - 「卧室 / 书房 / 车内」→ 小房间档；
   - 「客厅 / 办公室 / 餐厅」→ 客厅档；
   - 认不出就按 `Scene.space` 的内景 / 外景给默认档，**并如实说明「认不出」**。
4. **`reverbFilterOf(preset)`** 翻成 ffmpeg `aecho` 滤镜串：三层回声，
   延迟按 `roomSize` 拉开、衰减按 `decayMs` 收。`dry` 返回空串（与旧命令同构）。
5. **渲染侧暂不接**：成片页只显示「每场用哪套、几镜」，并写明
   「渲染侧暂未接这套参数」。理由见下。
6. **纯计算、不写 IR**：预设是派生的，改地点名字就该换一套，不需要回放。

## 理由

- **先定口径，再改渲染**：混响参数一旦进了渲染命令，就要处理「一场一滤镜、
  按时间段切」的问题——ffmpeg 的 `aecho` 是整条流处理的，按场切换需要
  `atrim` + `concat` 拼装，复杂度高且容易在接缝处爆音。这一档先把
  「该用哪套」定下来，让作者能看见并纠正空间判定，再决定怎么落进命令。
- **跟场不跟镜**：这是 SOUND.md 的原话。跟镜会让同一场听起来像换了房间。
- **名字启发式 + 如实说明**：`Location` 没有结构化空间类型，名字匹配是唯一可行的手段。
  认不出时说「按客厅档」，比假装认得诚实。
- **用 `aecho` 不用 `afir`**：`afir` 需要真实房间脉冲响应文件，项目里没有；
  `aecho` 三层近似虽然不精确，但「房间越大尾巴越长」的听感成立。

## 后果

**正面**

- 每场的混响口径第一次被显式定下来，成片页能看见。
- 空间判定与预设表可测试、可版本化（`REVERB_VERSION = "2026-11"`）。
- 滤镜串已经能生成，将来接渲染时不用重写。

**负面 / 代价**

- **渲染侧没接**：现在只是「看得见」，成片里听不出区别。这是本档最大的限制。
- **名字启发式不可靠**：地点叫「林晚家」认不出是客厅，会按内景默认档。
- **参数没有用真实房间脉冲响应标定**：`decayMs` / `roomSize` / `wet` 都是经验值。
- 不做「同一场里按镜微调混响」（比如特写更干），SOUND.md 也没要求。
- 不做 5.1 或环绕声。
