# ADR-0114：删一拍 take 与无字幕导出

- 日期：2026-11-11
- 状态：已采纳
- 关联：B5、E6、ADR-0083、ADR-0091、ADR-0109

## 背景

B5（多 Take）与 E6（渲染导出）各自只剩一小截：

- 多 Take 能看、能留用、能淘汰，但**删不掉**：试错出来的废拍会一直挂在镜头上，签越排越长，逐拍花了多少钱也只能靠翻记账。
- 成片导出**只能带字幕**：有些平台要自己加字幕，或者片子还要拿去做二次剪辑，烧进画面的字反而碍事。

两条都只差一个明确的口子，不需要新概念。

## 决策

### 1. 新增 `take.removed`，删一拍只删这一拍

```ts
{ type: "take.removed"; at: string; takeId: Id }
```

应用时三件事一起做，避免出现悬空引用：

| 对象 | 处理 |
| --- | --- |
| `project.takes` | 摘掉这一条 |
| `shot.takeIds` | 从所属镜头里摘掉这个 id |
| `timeline.items` | 摘掉引用它的片段（与 `shot.removed` 同一套规则） |
| `project.assets` | **不动** |

资产不删是有意的：素材可能还被别处引用，回收是 F4 的事；而且删掉资产会让「历史回滚」回不来。

### 2. 两步确认，锁定镜头不给删

这一拍花了钱，一次点击就消失太容易误触，所以沿用删台词 / 删一场的两步确认：先「删这一拍」，再「确认删这一拍」。锁定的镜头整个不给动（与留用、淘汰一致），要先解锁。

### 3. 没片子的 take 也能选、也能删

原来 take 签在没有视频时是 `disabled`，于是「导入失败留下的一拍」反而删不掉。改成：没片子也能选中（只是大画面继续显示空态），这样才能把它删掉。签上直接写这一拍花了多少（`¥x.xx`），多拍时下方给一行「共 n 拍 · 合计 ¥x · 最贵 ¥y」——这就是逐拍花费对比，不另做表格。

### 4. 无字幕导出是导出选项，不是另一条渲染链路

`buildRenderManifest` 多一个 `options.subtitles`（默认 `true`）。关掉时只少掉 `subtitleOverlays`，**AI 角标照旧**：显式标识是合规要求（H5），不能跟着字幕一起关。文件名改成 `<原名>-无字幕.mp4`，两版下到同一个文件夹里也分得清。

服务端渲染链路、清单校验、任务队列一行没改——清单里少几个叠加层而已。

## 后果

- 试错成本变得可见也可回收：每一拍多少钱写在签上，废拍能删，删错了在历史抽屉里回滚。
- 删 take 不会省下已经花掉的钱：`costCny` 记在 take 上，删了这条 take，记账里那一笔也随之消失。这是有意的——它是「这一版值多少钱」的注记，不是账本；真正的账在 `spendOf` 与顶栏记账抽屉里，按资产与 take 的引用计算。
- 无字幕版让「平台自己加字幕」这条常见需求不再需要外部工具。
- 历史抽屉多一种人话：「删 SH-03 的一拍 take」。

## 验证

- 单测 749 全过（IR 149 + gateway 28 + pipeline 51 + web 521）。
  - IR 新增 3 条：删一拍摘掉 take / `takeIds` / 时间线片段且资产不动；指向不存在的 take 报错；只删指定的一拍，同镜其他拍不受影响。
  - web 新增 4 条：`removeTake` 写一条 `take.removed` 且同镜其他拍不动；连带摘掉时间线片段；锁定镜头拒绝；不存在的 take 返回 false。
  - `render-manifest.test.ts` 新增 1 条：`noSubtitleFileName` 的三种写法。
- `pnpm typecheck`、`next build` 全过。
- 浏览器（生产 3100，分镜页）：SH-03 的 take 签显示「1 待定 ¥2.12」；点签后出现「删这一拍」；两步确认后 take 数 1 → 0、顶栏版本 v9 → v10、历史抽屉出现「删 SH-03 的一拍 take」。
- 浏览器（成片页）：导出区出现「把字幕烧进画面」勾选框，默认勾上；取消后勾选状态保持，说明文字写明文件名带「-无字幕」且角标保留。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 删 take 时连资产一起删 | 资产可能被别处引用；删了历史回滚也拿不回来。回收归 F4 |
| 一次点击直接删 | 这一拍花了钱，误触代价是真实的；两步确认与删台词 / 删一场一致 |
| 单独做一张「逐拍花费」表格 | 一镜通常 2–5 拍，签上写数字加一行合计就够；再做表格是给 20 拍的场景过度设计 |
| 无字幕导出另开一条渲染路由 | 差别只是清单里少几个叠加层，另开一条会复制整套队列与校验 |
| 无字幕时连 AI 角标一起去掉 | 显式标识是合规义务（H5 / R2），不能作为可选项 |
