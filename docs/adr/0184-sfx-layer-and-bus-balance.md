# ADR-0184：音效层与三路总线平衡（C7）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C7、C4、C12、SOUND、ADR-0099、ADR-0131、ADR-0143、ADR-0149、ADR-0182

## 背景

C12 把混音做成了「一条对白总线 + 一条音乐总线」：对白逐句响度归一、
配乐按台词窗 ducking、整片 loudnorm。C4 又把配乐从一条扩到最多四条 cue。
缺的两块一直在 C7 的「未做」里：

- **音效层**：关门、脚步、雨声、转场一记重音没有地方放。作者只能把它们
  当配乐导进来，于是「音乐」那条线里混着完全不 ducking 的效果音，
  情绪曲线与主题动机也被这些短音污染。
- **多轨平衡**：想「对白清楚一点」只能逐条去调每段配乐与每句对白的增益；
  没有一个站在整条总线上的旋钮。

ADR-0131 当时就写过，将来要加的多半不是「独立音轨」，而是与配乐床同一层的
「叠加音效层」——这次按这条预判落地。

## 决定

1. **音效是一条独立的时间线数组：`Timeline.sfx: SfxCue[]`**
   - 字段与配乐 cue 同构：`assetId` / `title` / `startMs` / `durationMs` /
     `gainDb` / `loop` / `licenseRef`，另加 `role`（拟音 / 环境 / 重音 / 转场）。
   - 与配乐的区别是**用法**而不是结构：音效不 ducking，默认只播一遍
     （`loop: false`），默认增益 −12 dB；`role` 只用于界面分组与复盘，
     不参与渲染。
   - 上限 8 条（渲染清单按这个数校验）。音效本来就多而短，与配乐的 4 段上限
     分开算。

2. **音效走自己的事件：`timeline.sfx.updated`**
   - 与 `timeline.music.updated` 分开：加一声关门不该让「配乐改过没有」也变。
   - 整条替换，校验与配乐同一套：必须挂音频资产、必须写授权来源、
     起点在成片内、时长 > 0、增益 −40–0 dB。

3. **三路总线平衡：`Timeline.mix: { dialogueDb, musicDb, sfxDb }`**
   - 每路 ±12 dB，默认全 0。事件 `timeline.mix.updated`，整块替换。
   - 混音时叠在每条 cue 自己的增益上：对白 = 逐句归一 + 对白总线，
     配乐 = cue 基础增益 + 配乐总线，音效 = cue 增益 + 音效总线。
   - **ducking 深度不跟着配乐总线变**：总线调的是「音乐整体多响」，
     不是「压下去多少」。
   - 全 0 时混音命令与以前逐字节同构，渲染清单也不写 `mix`。

4. **渲染清单扩展但向后兼容**
   - `manifest.sfx?: RenderSfx[]`、`manifest.mix?: RenderMix`；没有音效 /
     全 0 时两项都省略。
   - 音效素材计入 200 MB 总量上限，与配乐同一套 data URI / 本机资产 /
     对象存储 / 远端下载解析。
   - 混音命令先让每组各自 `amix` 成一条总线，再用一条 `amix` 合成；
     只有一条总线时直接 `apad` 到片尾，与旧命令同形。

5. **界面：成片页「音效」与「混音平衡」两块，放在「配乐」之后**
   - 音效卡：起点、长度、增益、循环、试听、移掉；加段表单要文件 + 授权来源，
     类型与循环是选项。
   - 平衡块：三条滑杆（对白 / 配乐 / 音效）+「全部归 0」。
   - 文案说明这是相对平衡，整片随后仍归一到 −14 LUFS。

6. **日志版本 +1**
   - `LOG_VERSION = 4`；v3 → v4 只靠 zod 默认值补 `timeline.sfx` / `timeline.mix`，
     事件形状不变。旧日志照常重放，新事件只有新版本写得出来。

## 理由

- **音效与配乐不是同一件事**：一个要跟着台词让位，一个不该；一个常常循环铺满，
  一个通常只响一下。硬塞进 `music` 会让两者都长出「只有对方才需要的字段」。
- **总线而不是再调一遍每条**：作者说「对白再清楚一点」时，动的是整条总线；
  逐条调在 4 段配乐 + 8 条音效时会变成 12 次操作，而且下次加一段又得重来。
- **同构的 cue**：音效 cue 复用配乐的校验、解析与渲染路径，不引入第二套素材规则；
  差别只在默认值与是否 ducking。
- **向后兼容**：没有音效的项目清单与命令完全不变，旧日志与旧渲染结果不受影响。

## 后果

**正面**

- 关门、脚步、雨声、转场重音终于有自己的位置，且不会污染情绪曲线。
- 一个「对白 / 配乐 / 音效」三路平衡就能改整体听感，不必逐条试。
- 音效与配乐各自一条事件，撤销 / 回放 / 历史文案都清楚。

**负面 / 代价**

- 混音链更长：最多 4 + 8 + N 条输入，ffmpeg 命令与排查信息更长。
- 音效不做按句自动响度归一（只有作者给的增益 + 总线），
  从不同音效库拿来的素材响度差异要自己调。
- `role` 目前只是标签，不驱动任何自动行为（例如「转场」不会自动贴到转场点）。
- 8 条上限对复杂场景仍偏少；要更多得同时改清单校验与混音。

## 不做

- 按场景切换混响 / 空间音频：需要卷积混响与场景声学参数，先在 C7 的下一档讨论。
- 音效自动匹配画面动作（需要视觉理解或关键词检索）。
- 独立多轨拖拽时间线：音效仍是「起点 + 长度」的数字输入。
- 每段独立淡入淡出与交叉淡化。
