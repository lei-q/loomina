# ADR-0164：静音可懂度检查

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C13、A20、D2、D3、A2、准则 P2 / P3 / P15

## 背景

短剧的主战场是静音：地铁、办公室、宿舍里刷到一条竖屏片，声音默认关着。
观众先看字幕，声音是加分项。作者却只能等成片出来、自己静音看一遍，才知道
哪一句读不完、哪一段没有字幕。

字幕这一侧其实全部可算：成片页已经有排好时间的字幕（`toEditView`）与镜头
（`clips`）。缺的是一份把它们放在一起看的报告。

## 决定

1. **只查字幕，纯派生**
   - 新增 `apps/web/lib/silent-watch.ts`：`silentWatch(input)` 纯函数，
     `silentWatchOfEdit(view)` 从 `EditView` 直接算，成片页与顶栏徽标共用同一份。
   - 报告不进 IR：作者改了断句、挪了字幕、换了 take，下一次打开就重算。

2. **五个可测项，各有可解释的阈值**

   | 项 | 判据 | 扣分 |
   | --- | --- | --- |
   | 读不完 | 可见字数 ÷ 停留秒数 > 10（舒适线 7） | 每条 −8，最多 −32 |
   | 一闪而过 | 停留 < 800ms 且 ≥ 2 字 | 每条 −3，最多 −12 |
   | 信息断点 | 连续 ≥ 6 秒没有字幕（含片头与片尾） | 每段 −5，最多 −20 |
   | 指代不清 | 以「他 / 她 / 这个 / 那个人……」开头，前三条字幕里没出现过人名 | 每句 −4，最多 −16 |
   | 说话人不清 | 一镜里两个人先后说话、中间没切镜 | 每处 −4（字幕按角色着色时 −2），最多 −16 |
   | 台词偏少 | 成片 ≥ 30 秒且字幕覆盖 < 20% | −10 |

   分数 100 起扣，85 以上「静音也能看懂」、70 以上「大体能懂」、50 以上
   「静音时容易断」，其余「静音时看不懂」。

3. **指代只认字幕文本里的人名**
   说话人标签（「林：」）不在画面上，静音时观众看不到，所以不能拿它当
   「观众知道这是谁」的证据。判定窗口是前三条字幕。

4. **说话人不清按「换人但没换镜」算**
   同一个人连说两句不报；A → B 的那一句才报，因为静音时观众只能靠字幕颜色
   分辨。字幕按角色着色（D3）时扣分减半，界面如实说明。

5. **界面：成片页顶栏「静音」抽屉**
   - 顶栏徽标 = 五类问题之和；时间线为空时不出现。
   - 抽屉：分数卡 + 一句话结论 → 读不读得完（只列有问题的，带「这段停留
     最多放得下 N 字」）→ 信息断点（带起止时间与「去这一段」）→ 指代不清 →
     说话人不清 → 覆盖率条。
   - 「去这一条」关掉抽屉、把播放头挪到那一条并打开已有的手改断句编辑器；
     「去这一段」只挪播放头（断点没有台词可改）。
   - 报告底部明写「画面里藏了什么、表演能不能读懂，这一份测不了：它只查字幕」。

6. **复用 A20 的口径**
   读速判据与 `dialogue-polish` 的 15 字上限是同一套语言：15 字在 2 秒里
   是 7.5 字/秒，正好压在舒适线附近。

## 理由

- **静音是默认观看状态**，不是无障碍附加项；它决定这条片子能不能被划走。
- **只查能查的**：人脸、表演、画面信息量需要另一条推理链路，用算术分数
  假装看过画面比不查更糟（同 ADR-0097 的口径）。
- **与成片一致**：报告从 `toEditView` 算，作者手改断句、挪字幕、换 take
  之后数字立刻变，不会出现「报告说没问题、成片其实读不完」。
- **可解释**：每一条都能说清为什么被标（字数 / 秒数 / 空档长度 / 开头词）。

## 后果

**正面**

- 作者第一次能在导出前知道「静音时哪一句读不完、哪一段没有字幕」。
- 顶栏一个数字就能看出这条片子静音风险有多大。
- 点「去这一条」直接落到断句编辑器，改完回抽屉数字就变。
- 全部派生：旧项目不需要迁移，不写 IR、不调模型、不花钱。

**负面 / 代价**

- 画面里藏的信息测不了：一句台词可能靠表演补全，报告照样按字数扣分。
- 指代判定是字符串前缀匹配：「他」开头但前文用职务称呼（「周总」）时会误报。
- 说话人不清只在「同一镜内换人」时算；切镜后的换人不报，但观众也可能分不清。
- 覆盖率只按时间比例算，不区分「有字幕但没信息」。
- 6 秒空档是经验值，慢节奏片子里可能误报。

**不做**

- 画面信息量、表演可读性、人脸与情绪识别。
- 自动改断句、自动拆句、自动加旁白。
- 把分数写进 IR 或做成发布硬闸门。
- 按平台 / 题材标定阈值（归 I9 评测集）。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 让作者自己静音看一遍 | 看不到「哪一条读不完」，只能凭感觉 |
| 用模型判断静音可懂度 | 要花钱、要等、不可复现；字数与时间是确定的事实 |
| 在剧本页做（按台词算） | 剧本页没有排好的时间，字幕断句与停留时长只有成片页有 |
| 把分数做成发布硬闸门 | 规则会误报，作者应能带着说明导出 |
| 只报「读不完」一项 | 空档与指代才是静音时真正的断点，缺了等于只查一半 |
