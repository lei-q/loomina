# ADR-0084 预演（Animatic）先在浏览器里播

- 状态：已接受
- 日期：2026-11-11
- 决策人：用户 + Claude
- 关联：ADR-0009（预演作为闸门）、ADR-0003（音频先行）、E10、C1

## 背景

ADR-0009 把 animatic 定为视频生成之前的低成本闸门：关键帧 + 配音 + 临时音乐 + 字幕，540p 快速渲染。眼下关键帧与视频都已在审片台里能看，但没有任何地方能**连着看**：要判断节奏只能一镜一镜点过去，字幕也只出现在当前镜。

真正按 ADR-0009 做需要一条服务端渲染管线（ffmpeg、音频混轨、字幕烧录、任务队列），而配音（C1）还没有模型与配额。先把闸门拆成两步：这一条先把「连起来看」做出来，**默片预演**；等配音接上再把声轨放进去。

## 决策

1. **预演在浏览器里播，不渲染文件**：按 IR 里每镜的 `durationMs` 依次显示，到点切下一镜。不生成、不上传、不占服务端。
2. **画面按可用性降级**：这一镜有视频 take 就放 `<video muted autoPlay loop poster={首帧}>`；否则首帧；否则尾帧；都没有就放场景占位图并标 `没图 · 占位`。
3. **字幕与审片同源**：`StageShot` 新增 `subtitle`（这一镜所有台词按顺序拼起来），预演、审片台共用，不得各拼一套。
4. **读模型 `toAnimaticView(project)`**：输出 `{ title, segments, totalSec, missing, withVideo }`；`segments` 带 `id / no / dur / art / imageUri / videoUri / subtitle / hasPicture`。只读，不写事件。
5. **入口与操作**：分镜页顶栏 `▶ 预演` → 全屏覆盖层；`播放 / 暂停`、`上一镜 / 下一镜`；空格暂停、`←` `→` 切镜、`Esc` 退出；底部按镜头时长分配宽度的进度条，点哪段跳哪段。播到头停住并给「再看一遍」。
6. **明示这不是成片**：顶栏灰签 `这不是成片`，右栏写 `还没有配音：这一版是默片预演`。
7. **不写事件、不锁分镜**：ADR-0009 的「确认后解锁视频生成并锁定分镜」留到配音与渲染齐了再接；现在的预演是只读回放。

## 理由

- **先解决「能不能连着看」**：节奏问题只有在连续播放里才暴露；渲染文件是分发问题，不是判断问题。
- **浏览器播放零成本、零等待**：关键帧本来就是 data URI，直接显示；比「等 2 分钟渲染一个 540p」更符合闸门的初衷（低成本、快反馈）。
- **降级链让预演永远有东西可看**：缺帧的镜头给占位色块，用户能一眼看出「这镜还没画」，而不是预演报错。
- **不碰事件日志**：预演是查看，不是编辑；写日志会让「看了几遍」污染项目历史。

## 后果

**正面**

- 一条 30 秒的片子能在几秒内看完全程，字幕与镜头时长对得上。
- 缺画面、有片子的镜头数在右栏直接可见，先补哪几镜一目了然。
- 同一份 `subtitle` 供审片与预演，改台词后两处同时变。
- 测试：IR 100、web 235（新增 2：读模型）、gateway 17、pipeline 23，合计 375。`pnpm typecheck`、`pnpm test`、`pnpm build` 通过。

**负面**

- **没有声音**：默片预演判断不了对白节奏与停顿，这正是 ADR-0003 看重的部分；等 C1。
- **不导出**：只是一个覆盖层，没生成可分享的文件（E6）。
- **播放依赖浏览器解码**：无头 Chrome 环境里连 data URI 视频都停在 `readyState 0`，所以自动化验收只能验到元素与状态；真实播放要人在浏览器里看。
- **转场与运镜**：镜头之间硬切，没有转场预览，也没有推拉摇移的轻微动效。
- **时长来自 IR**：没有按配音量过、也没有校验过，`durationMs` 不准时预演跟着不准。

**跟进**

- 配音（C1）：每句一条音轨，预演按音频实际时长播放并据此校正镜头时长。
- 临时音乐与音量平衡（C2 / E10 声轨部分）。
- 540p 文件渲染与导出（E6），以及「确认预演 → 解锁视频生成并锁定分镜」的闸门动作。
- 轻微推拉 / 转场预览。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 直接做服务端 540p 渲染 | 要 ffmpeg、任务队列与存储；配音未定时渲染出来还得重做 |
| 做成时间线编辑器里的一条轨 | 与 UX「时间线默认不露」相反，C 端看不懂 |
| 只在关键帧页做幻灯片 | 没有连续时长、没有字幕、没有总长，判断不了节奏 |
| 预演时把 `durationMs` 按字幕字数估算 | 会让预演与真实镜头时长不一致；宁可先如实按 IR 播 |
| 用 Canvas 合成再录制成视频 | 这又是渲染问题，且浏览器编码器在无头环境不可靠 |
