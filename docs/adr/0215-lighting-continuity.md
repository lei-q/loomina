# ADR-0215：光影跨镜一致性放进走位台账，不做视觉比对（B4 第一档）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：B4、B11、I2、B14、ADR-0097、ADR-0168

## 背景

B4「连续性监工（自动 QA）」写的是「抽帧 + 视觉模型比对：人物 / 服装 / 道具 / 光线 / 左右关系」。
这条路要视觉模型，而项目当前的供应商侧本来就不通（视频 / TTS / ASR 都在 403 或配额上卡着），
把 B4 整个押在视觉模型上等于不做。

但拆开看，这五项里**有两项不需要看画面**：

- **左右关系**：B11 已经在查（翻面、朝向、前后景、道具）；
- **光线**：I2 的 `Shot.lighting` 已经逐镜写了 `{ source, position, mood, note }`，
  但**没有任何跨镜检查**——两镜主光一个侧一个逆，提示词各自都对，连起来看就是换了时间。

CONSISTENCY.md 里「光影」这一维当时被标成「未测，只能靠人眼」，理由是「没有 LightingSpec
与画面比色」。前半句已经过时：LightingSpec 在 ADR-0168 就有了。

## 决定

1. **光影跨镜检查放进 `scene-space.ts`**，与左右 / 朝向 / 前后景 / 道具共用同一套
   「同场相邻两镜」的对比骨架。不新开模块：这两件事问的是同一个问题——同一场戏里
   相邻两镜之间，有没有什么东西无缘无故变了。
2. **只判结构化的两个字段**：
   - **主光方向**：`front` / `side` 之间互换算软变化（不报）；其中一侧是
     `back` / `top` / `under` 就报——那是换了一套光，观众看得出。
   - **光源**：`window` → `lamp` 这类变化一律报，并提示「要有交代（关灯、拉窗帘、天黑）」。
3. **一边没写就不判**：与左右 / 朝向同一口径——不知道是「没写」还是「换了」。
   没写光影的镜头在台账里显示「·」。
4. **跨场不判**：换场换光是正常的（与 B11 一致）。
5. **只提示不阻断**：`severity: "review"`。光影是创作选择，工具不该替作者判死。
6. **台账加一行「光影」**：逐镜显示「窗光 / 侧面」，作者能横向对照哪一镜岔出去了。
   光影问题不显示「调这一镜的走位」按钮——那个按钮改的是 `blocking`，改不了 `lighting`。
7. **更新 B14 的「未测」措辞**：光影从「完全没测」改成「结构化的主光 / 光源跨镜已查，
   画面里的实际色温与亮度仍需人眼或视觉模型」；空间同理点明 B11 已查的部分。

## 理由

- **不依赖供应商**：这是本次能真正落地的部分。视觉比对留给供应商通了之后再做，
  而且那时候它是在这个结构化检查之上加一层，不是替代它。
- **放走位台账而不是新面板**：作者看「这一场哪里不对」时不该开两个抽屉。
- **只判方向与光源，不判色温 / 光比**：后者在 `Project.look` 里是全片统一的，
  逐镜没有独立字段；硬造一个逐镜色温字段等于给 IR 加没人会填的字段。

## 后果

**正面**

- 光影从「完全未测」变成「主光方向与光源跨镜已查」，CONSISTENCY.md 的 8 个维度里
  第 4 维有了结构化的一半。
- 不花钱、不调模型、不写事件：纯函数，跑一次几毫秒。
- 与 B11 共用骨架，作者在一个抽屉里看到「翻面 / 跳景 / 转身 / 道具 / 光影」。

**负面 / 代价**

- **画面里的实际色温、亮度、光比仍然没测**——提示词写对了不代表出图对了。
  这一半要等视觉模型。
- 依赖作者逐镜填 `lighting`；没填的镜头查不了（台账里显示「·」）。
- 「正面 ↔ 侧面」判为软变化是经验阈值，没有用样片标定过。
- 人物 / 服装 / 道具的**画面**一致性（B4 原文里的三项）仍然完全没做。
