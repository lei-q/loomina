# ADR-0022 成本以有效通过率为核心，双档渲染与点数计费

- 状态：已接受
- 日期：2026-11-09
- 决策者：用户 + Claude
- 关联：P14、P21、H4、H10、COST.md、R13/R23

## 背景

模型 API 用量充足，掩盖了一个事实：**单位经济可能不成立。**

一条 60 秒短剧，视频生成占成本 60–80%。按当前量级，中性情景单条 250–400 元；若首次通过率只有 25%，成本会到 600–900 元。而 C 端单条付费意愿远低于此。

成本不是"单价"问题，而是"废片率"问题：重试是乘法，通过率从 40% 降到 25%，平均生成次数从 2.5 次变 4 次。

## 决策

1. **把"有效通过率"作为成本核心指标**：`C_effective = 总成本 ÷ 通过镜数`。
2. **双档渲染**：`draft`（540p/720p，低码率）用于一切确认前环节；`final`（1080p+）只在确认后。
3. **模型单价表 `ModelPrice` 版本化**，业务代码不硬编码价格。
4. **逐笔记账 `CostLedger`**，按项目/镜头/模型/档位归因。
5. **双层预算护栏**：项目级 + 镜头级；超限阻断或降级。
6. **重试停止条件**：预算上限、次数上限（3–5）、质量提升阈值、同维度连续失败。
7. **计价采用点数制**：点数映射真实资源消耗；默认套餐覆盖"一条完整片"。
8. **同维度连续两次失败禁止继续重试**，回到设计层修改。

## 理由

1. 通过率是唯一能同时改善成本与质量的杠杆。
2. 草稿/定稿分档是"在便宜阶段验证"的直接实现（与 Animatic 闸门同构）。
3. 点数制让成本透明、重试有感知，且模型调价时不用改产品逻辑。
4. 无诊断的重试是纯浪费，必须用规则挡住。

## 后果

**正面**
- 成本可预测、可归因、可止损。
- 与 Animatic、短镜头、一致性系统形成合力。
- 定价可随模型价格平滑调整。

**负面**
- 点数制增加用户理解成本，需要好的默认套餐。
- 记账与估算增加实现与运维复杂度。
- 单条成本仍可能高于 C 端付费意愿，需要靠规模与降价解决。

**跟进**
- S1 能力测绘时产出真实单价与通过率基线。
- 建立成本看板：单条成本、首次通过率、重试占比。
- 定价与套餐在验证出片价值后再定。

## 替代方案

- **按条定价**：成本波动时容易亏损，放弃。
- **包月不限量**：重度用户会把毛利打穿，放弃。
- **只靠模型降价**：不可控，不能作为唯一出路，放弃。
