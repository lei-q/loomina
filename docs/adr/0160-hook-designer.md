# ADR-0160：钩子设计器与规则评分

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：A19、A7、A2、ADR-0121、准则 P15

## 背景

`StoryBible.hooks` 从第一版就在：`opening` 是前 3 秒抓住注意力的那一句，`ending` 是这一集结束时留下的悬念。生成会写这两个字段，`story.updated` 也允许改，但界面只在结果卡里只读展示。A19 要的是「钩子设计器」：一个钩子类型库，加上好奇度 / 紧迫度 / 可视化 / 新鲜度四个评分，帮作者判断这一句是不是真的能抓人。

这件事不该调用模型：钩子很短，判断的是「有没有具体物件、有没有时间压力、有没有套话」，规则能解释、能离线、能立刻给反馈；模型打分反而多一次花钱的调用和一份不可复现的结论。

## 决定

1. 新建纯函数层 `apps/web/lib/hooks.ts`：
   - `HOOK_TYPES` 八种写法：反差、悬念、危机、秘密、倒计时、身份揭露、误会、反常动作；每条带一句说明、填空式骨架、例子与适用落点（开场 / 结尾）。
   - `hookTypesOf(text)` 按关键词识别命中类型。
   - `scoreHook(text, position)` 给四个 0–100 分项与一个总分：好奇 ×0.3、紧迫 ×0.25、可视化 ×0.25、新鲜 ×0.2；同时回 `notes` 说明加分 / 扣分原因。
2. 评分规则全部可解释：
   - 好奇：问句 / 省略号、秘密类物件加分；少于 8 字、超过 60 字扣分。
   - 紧迫：时间词、危险词加分；结尾钩子没有时间压力轻微扣分。
   - 可视：具体物件与动作加分；没有物件、只有抽象词扣分。
   - 新鲜：套话（总裁、重生、车祸、失忆等）扣分；具体数字、引号里的原话加分。
3. 界面放在故事圣经的「钩子设计器」段：开场 / 结尾两张卡，显示当前文字、总分、四个分项、命中类型与两条原因；「改 / 写」打开编辑框，按「存」走既有 `editStory` 写一条 `story.updated`。
4. 类型库折叠展示八种写法；「填进开场 / 结尾」只把例子填进编辑框，不直接保存——作者改完再按「存」，避免一次点击就覆盖当前钩子。
5. 分数只做提示：不写 IR、不阻断生成、不自动改写；空钩子返回 0 分与一句提醒，不伪造分数。

## 理由

- **钩子是句子级问题**：四个维度都能用关键词与长度解释；作者看得懂为什么扣分，比一个黑箱分数有用。
- **不新增 IR**：`hooks.opening` / `hooks.ending` 与 `story.updated` 白名单都已存在，设计器只是换了一种编辑方式。
- **类型库给的是骨架，不是答案**：填空式 pattern 与例子让作者有起点，但最终仍要自己改；直接写入会覆盖已有钩子，所以只填编辑框。
- **与 A7 模板衔接**：模板把两个钩子写进生成输入；生成后落到 `StoryBible.hooks`，作者再用设计器逐句打磨。
- **不调用模型**：短句评分用模型既慢又花钱，还无法解释；规则版能离线、可测试、结果稳定。

## 后果

**正面**

- 作者能在故事页直接看到钩子的四个分项与扣分原因，改完立刻重算。
- 八种写法有骨架与例子，冷启动时不用从零想。
- 不新增依赖、不新增 API、不新增 IR 字段或事件；旧项目打开就能用。
- 评分是纯函数，规则与边界都有测试。

**负面 / 代价**

- 规则打分识别不了反讽、语境与画面外的信息；高分不等于一定好看。
- 关键词表是人工维护的，新题材的黑话可能漏判；作者要自己判断。
- 没有历史分数、没有 A/B、没有按平台或题材校准。
- 类型库只有中文短剧常用八类，不是完整叙事学分类。

**不做**

- 模型打分、模型自动改写钩子、按分数自动重生成。
- 钩子历史版本、分数趋势、跨项目对比。
- 按平台（抖音 / 快手 / 小红书）或题材调整权重。
- 把分数写进 IR、事件日志或导出前的硬闸门。
- 自动从分镜反推钩子或从钩子生成分镜。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 调用文本模型给钩子打分 | 多一次花钱调用，结论不可复现，也解释不了扣分原因 |
| 只给类型库，不打分 | A19 明确要求四个评分；没有分数作者仍不知道哪句更抓人 |
| 点类型直接写入钩子 | 会覆盖作者已经写好的句子；先进编辑框更安全 |
| 把评分做成生成前的硬闸门 | 分数是启发式，不该阻断创作；准则 P15 也要求规则只做合法性 |
| 新增 `HookPlan` IR 实体 | 两个字符串已经够用；多实体要多事件、回放与迁移 |
| 按平台训练权重 | 没有授权样片与标注数据，先做可解释的统一定价 |
