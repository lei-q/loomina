# ADR-0200：废片「作参考」（C2 第五档）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：C2、C14、C16、ADR-0193、ADR-0196

## 背景

废片库（ADR-0193 / ADR-0196）到这一档为止只有「取回」：
淘汰 / 删掉的拍放回本镜、旧关键帧换回这一帧、删掉的配音放回试听台。

但用户的 C.2 要求是「之后可取回**或作参考**」。一张被换下来的关键帧往往
构图、光线都对，只是表情或道具差一点；把它直接丢掉或必须换回原位，
都不如「挂成某个角色的参考图」——下一镜、下一集都能照着它生成。

## 决定

1. **废片库里旧关键帧多一个「作参考」按钮**
   - 只有 `kind === "keyframe"` 的行有（视频 take / 配音 take 是影音，不是图）。
   - 点开一个对话框，按「人物 / 场景 / 道具」列出当前项目里所有能挂参考图的实体，
     每个实体一个按钮；已经挂着这张图的显示「已挂」并禁用。
   - 没有实体时显示「还没有人物 / 场景 / 道具可以挂：先去定妆页建一个」。

2. **只登记引用，不复制文件**
   - 新动作 `attachTrashReference(assetId, { kind, id })`：
     一条 `character.updated` / `location.updated` / `prop.updated`，
     `referenceImages` 追加同一个资产 id。
   - 不新建资产、不写 `asset.updated`、不复制字节、不调模型、不花钱。
   - 不走 `makeReferenceAsset`：它按地址建新记录；这里的图已经在资产里，
     再建一条会让同一个文件在库里出现两次。

3. **校验与既有参考图一致**
   - 只接受 `kind === "image"`：视频 / 音频 / 调色表拒绝（「只有图片能当参考图；视频要先抽一帧」）。
   - 同一张图对同一条只挂一次（「这张图已经挂过了」）。
   - 受 `REFERENCE_IMAGES_MAX` 限制（与定妆页「加一条参考」同一个上限）。
   - 资产不在项目里、实体找不到、`readOnly` 都拒绝且不写事件。

4. **反馈**
   - 成功：按钮下方写「挂到了「林」的参考图：只登记同一个文件，不复制、不花钱。」
   - 失败：`castError` 原样显示在同一个位置，对话框不关，作者可以换一条再挂。

## 理由

- **参考图是跨集的**：一张好画面当参考，比再生成一次便宜也更好控制；
  C16 / C17 / C20 / C21 已经把「复用不花钱」做成统一口径，这里只是把废片接进同一条路。
- **不复制文件**：同一个资产 id 挂到多条参考位，资产库、账目、`referencedAssetIds`
  都自然正确；复制会让清库误判孤儿。
- **只给关键帧**：视频 / 音频不是参考图的形态；把它们也挂上会逼着下游去抽帧，
  那是另一个功能（未做）。
- **不放宽上限**：参考图越多提示词越长；超过上限就按定妆页的规矩拒绝，
  不在这里悄悄放宽。

## 后果

**正面**

- 废片里的好画面能直接变成人物 / 场景 / 道具的参考图，下一镜与下一集都能用。
- 不新建资产、不花钱；挂错了一条 `character.updated` 就能摘掉，日志里看得见。
- 与 C14 的取回、C16 的挑图共用同一个资产位，资产库计数不变。

**负面 / 代价**

- 只覆盖关键帧；视频 take 想当参考得先有抽帧功能。
- 一次只能挂一条实体；要挂给三个人得点三次。
- 挂成参考后不提示「这张来自废片」，资产页也看不出它原来是哪一镜的旧版。
- 挂上会占参考图名额；名额满了要先摘一张才能挂。
- 对话框不显示缩略图，只显示镜号与描述——作者要凭记忆挑。
