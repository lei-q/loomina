# ADR-0051 动作的版本历史：从 shot.updated 里读出改写

- 状态：已接受
- 日期：2026-11-10
- 决策者：用户 + Claude
- 关联：ADR-0044（台词版本）、ADR-0049（动作改写）、FEATURES A21

## 背景

动作能改之后，改错了没有退路：只能手打回去，或者自己翻日志。台词有「改过 n 次 · 上一版 · 用这版」，动作没有——同一个页面上两种正文，一套有历史一套没有，说不过去。事件层面已经足够：每次动作改写都是一条带 `description` 的 `shot.updated`，最初那版在 `project.created` 的快照里。

## 决策

1. **不新增事件**：历史完全从日志里读，和台词版本同一套做法（ADR-0044 附记）。
2. **读模型**：`read-model.ts` 新增
   - `actionHistory(events, shotId)`：`original` 取引导事件快照里的 `description`，`edits` 按时间收每一条 `shot.updated` 里的 `description`；锁定等不带描述的 `shot.updated` 不算；
   - `previousActionText(history)`：上一版 = 倒数第二条改写，只有一条时回落到最初。
3. **回退就是再改一次**：动作没有时长，回退直接复用 `editAction(shotId, 旧文本)`，写一条新的 `shot.updated`。历史只增不减。
4. **界面**：动作下方一行 `改过 n 次 · 上一版「…」` 的折叠，展开是按时间倒序的版本（时间 + 全文 + `用这版`），最后一行是`最初`。与当前文本相同的行置灰。锁定镜头与只读标签页不显示回退按钮。
5. **按钮紧跟文本**：不加 `ml-auto`——动作历史横跨整列，把按钮推到最右边会与文本脱节。

## 理由

- **日志已经是版本库**：再存一张动作版本表，就有了两个事实来源，回放与「改过几次」会对不上。
- **复用回退动作**：动作的还原只涉及文本，不需要像台词那样连时长一起写回，`editAction` 就够了。
- **时间倒序 + 最初一行**：和台词版本面板一致，用户不用学两套阅读顺序。
- **同一行显示全文**：动作是一两句话，不像长台词需要截断；看到全文才能判断用哪版。

## 后果

**正面**
- SH-01 改过一次后出现 `改过 1 次 · 上一版「走廊尽头，灯管闪了一下」`；展开看到 20:39 的改写与`最初`两行。
- 点`最初`那行的`用这版`：动作回到「走廊尽头，灯管闪了一下」，面板变成 `改过 2 次 · 上一版「走廊尽头，灯管闪了两下。」`；日志多一条 `shot.updated { description }`，页头 35.6s 不动。
- 锁定镜头、只读标签页没有回退按钮，不会给出点不动的希望。
- 测试：web 122 条（新增 3 条：历史取值与过滤、上一版、别人 / 锁定事件不计入）；IR / gateway / pipeline 不变，合计 223。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：headless Chrome 展开历史、点`最初`的`用这版`；IndexedDB 第 27 条为恢复后的 `shot.updated`。

**负面**
- **只记文本**：改动作时没有备注，为什么改、谁改的，日志里只有时间。
- **没有「撤销」语义**：回退是一次新的改写，不是把历史抹掉；想要「回到上一版」得自己认时间。
- **与台词历史分开**：动作和台词各自一套折叠，一镜改得多的时候页面会多出几行小字。
- **动作 / 台词的历史不联动**：改台词不会让动作历史多一条，反过来也一样。
- **没有差异高亮**：两版之间改了什么字，要自己对比。

**跟进**
- 版本行做字符级差异高亮。
- 给每次改写加一句备注（事件加可选 `note`）。
- 结构变化（换人、排序）也进历史。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 新建 `ActionRevision` 表存版本 | 事件日志已经是版本库，再存一份会打架 |
| 新增 `shot.description.updated` 事件 | `shot.updated` 已经带 `description`，历史读得出来 |
| 回退时把中间的历史删掉 | 历史是事实，删掉就说不清「改过几次」 |
| 把动作历史并进台词面板 | 两种正文的版本混在一起，回到哪一版不清楚 |
| 按钮靠右（`ml-auto`） | 动作历史横跨整列，按钮会飘到与文本无关的右边 |
