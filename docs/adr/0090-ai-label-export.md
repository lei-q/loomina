# ADR-0090 AI 生成内容标识：导出与预览都带显式角标，不可关闭

- 状态：已接受
- 日期：2026-11-11
- 决策人：用户 + Claude
- 关联：ADR-0008（合规与 AI 标识内建）、ADR-0021（发布是底线）、ADR-0086（时间线与导出）、H5 / G1 / G8

## 背景

ADR-0008 定了原则：AI 标识进入 Project IR 与发布包，导出时写显式标识与隐式标识。发布包这边已经落地——`apps/web/lib/export-cut.ts` 的 `AI_LABEL` 写进 OTIO `metadata.loom.aiLabel` 与 `PublishPackage.aiLabel`，IR 的 `PUBLISH_AI_LABEL` 不变量也会拦住缺显式 / 隐式标识的发布包。

但「看得见」这一半还空着：

- 成片页 `/edit` 的播放器只有镜号与「已锁定」，没有任何 AI 标识。
- 导出的自包含预览 HTML 没有角标，也没有 `<meta>` 隐式标识；用户把 HTML 发给别人，对方看不出这是生成内容。

法规要求的是「显式标识」与「隐式标识」同时存在。只写在 JSON 字段里，等于只有隐式标识；画面与预览上看不到，显式标识就没做到。

## 决策

1. **显式标识是一枚右下角常驻角标，不给开关。** 成片页播放器与导出预览 HTML 都在画面右下角显示「AI 生成」。位置避开字幕基线、安全区参考线与「已锁定」标签；`pointer-events: none`，不挡播放与拖动。没有「隐藏标识」选项——它不是用户偏好，是导出条件。
2. **隐式标识写进预览 HTML 的 `<head>`。** 加 `<meta name="ai-generated" content="true">` 与 `<meta name="ai-label-standard" content="AI生成">`。OTIO 的 `metadata.loom.aiLabel` 与发布包的 `aiLabel` 保持不变，仍写 `{ explicit: true, implicit: true, standard: "AI生成" }`。
3. **标识文案固定为「AI生成」。** 不做多语言、不做模型名后缀。模型名已经在导出结果与故事页出现，标识本身越短越不容易被裁掉。
4. **标识是导出层常量，不进项目事件。** `AI_LABEL` 只存在于 `export-cut.ts`，不新增 `project.updated` 字段，也不让用户改。原因：标识是强制项，没有选择就没有状态；写进事件只会让每个项目多一份永远相同的字段，还要处理历史项目的迁移。
5. **mp4 还没接，标识烧录写进待办而不是假装已做。** 当前没有服务端渲染，`video` 如实为 `null`。文档与界面都写明：mp4 接上后，角标与隐式元数据必须一起烧进文件；在那之前，预览 HTML、OTIO 与发布包是标识的载体。
6. **界面明确标识不可关闭。** 导出区加一句说明：预览 HTML 的角标、HTML 元数据、OTIO 元数据与发布包 `aiLabel` 都会带上；mp4 接上后角标也要烧进画面。

## 理由

- **显式与隐式必须同时存在**：一个给观众看，一个给平台与下游工具读。只做一边，合规上就是缺项（R2）。
- **不可关闭**：一旦做成开关，默认值、误关、历史项目都会成为漏洞。强制项最便宜的形态就是没有开关。
- **预览 HTML 是当前唯一「能发给别人看」的成片形态**：在它上面加角标，等于把显式标识提前落到真实可传播的文件里，而不是等 mp4。
- **不进 IR**：标识与项目内容无关，是导出格式的一部分；放常量比放事件更不容易被改坏，也少一次数据迁移。
- **角标放在画面内而不是页面外**：截图、录屏、转发都会带走画面；页面外的说明带不走。

## 后果

**正面**

- 成片页与预览 HTML 都能直接用眼睛确认显式标识存在。
- 预览 HTML 的 `<meta>` 与 OTIO / 发布包的 `aiLabel` 形成两份隐式标识，下游工具至少能读到一份。
- 标识是常量，测试可以逐字断言，不会被某个项目的旧数据带偏。
- 没有新增事件、没有改 IR、没有迁移成本。

**负面**

- **mp4 仍未烧录**：真正上传平台的文件还没有生成，标识也还没有进视频帧。这是渲染管线（E6）缺席，不是标识设计缺席。
- **角标可能被平台二次裁切**：右下角靠近安全区边缘，部分平台 UI 会覆盖；等平台规格库（G7）落地后要按平台调整位置，而不是让用户自己挪。
- **预览 HTML 的 `<meta>` 不是签名**：任何人可以改 HTML；隐式标识只能证明「原始导出带过」，不能防篡改。真正的强隐式标识（水印 / 签名）还没做。
- **固定文案「AI生成」**：不区分「AI 辅助」与「全 AI 生成」，也不写服务提供者名称；更细的分级要等监管口径与产品分级明确。
- **没有全局导出闸门**：现在四个导出按钮都带标识，但未来新增导出路径时，需要 G8 合规预检统一拦截，而不是靠每个调用点记得写常量。

**跟进**

- mp4 渲染接上时，把角标与 `aiLabel` 一起写进视频帧与容器元数据；渲染产物缺标识即视为失败。
- G8 合规预检：导出前统一检查 AI 标识、内容安全与授权链，未过不得导出。
- 平台规格库（G7）：按平台安全区调整角标位置，避免被平台 UI 遮挡。
- 强隐式标识：内容哈希、签名或不可见水印；需要服务端密钥与验签流程。
- 标识分级：区分全生成 / 辅助生成，以及是否展示服务提供者名称；等法规细则与上线地区确定。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 只在发布包 JSON 里写 `aiLabel` | 只有隐式标识，画面与预览上看不到，显式标识缺项 |
| 给标识加开关，默认开 | 强制项一旦可关，误关与历史数据都会成为漏洞 |
| 把标识写进 Project IR | 标识与项目内容无关，是导出格式的一部分；会多一次迁移与一份永远相同的字段 |
| 只在页面外写一行说明 | 截图、录屏与转发不会带走页面说明，等于没有显式标识 |
| 等 mp4 渲染做完再一起做 | 预览 HTML 已经是可传播的成片形态，标识不该继续缺位 |
| 把模型名写进角标 | 角标要短、要稳定；模型名会变，也会让画面更像广告 |
