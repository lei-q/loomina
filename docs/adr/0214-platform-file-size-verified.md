# ADR-0214：文件上限逐条核验，填了就必须给出处（G2）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：G2、G7、ADR-0099、ADR-0112

## 背景

ADR-0112 把 `maxFileBytes` 留成「有逐条复核过才填」的接口，当时一个平台都没填，
面板如实写「没有可引用的公开上限（未核验）」。这留下一件事：**没人去核**。

核验的难点在可查性，不在填数：

- 各平台把上传规格写在帮助中心 / 开放平台文档里，**没有统一的公开接口**；
- 文档站多为单页应用，纯 HTTP 抓取拿不到正文；
- 平台改版频繁，同一个数在论坛、博客、聚合问答里的说法互相矛盾
  （抖音的文件上限在不同二手来源里从「无限制」到「4GB」都有人说）。

所以决定的关键不是「填几个数」，而是**让每个数都带着能被复查的出处**，
没核过的继续写「未核验」——不拿二手转述冒充官方。

## 决定

1. **`PlatformSpec` 增加 `maxFileSource`**：`{ url, checkedAt, quote }`。
   `url` 是官方页面，`checkedAt` 是复核日期（绝对日期），`quote` 是那句原文。
2. **填了上限就必须给出处**：`platforms.test.ts` 有一条遍历全部规格的用例，
   `maxFileBytes` 有值的必须同时有 `maxFileSource`，且 `url` 是 https、
   `checkedAt` 是 `YYYY-MM-DD`、`quote` 非空。数字不许凭空来。
3. **面板同时写出上限、出处与原文**：文件大小那行变成
   「上限 16.0 GB（2026-11-14 核：文件大小：不超过16G……）」。
   没导出过时也写出来，不再等到导出后才知道。
4. **超限就是硬阻断**：有 `maxFileBytes` 时按它拦，与 ADR-0112 的约定一致，
   校验代码不改。
5. **`maxFileNote` 写清适用场景**：同一个平台不同路径的上限不一样
   （B 站手机投稿 16G / lv3 web 投稿 64G；快手那条是 App 相册导入），
   面板要把口径写出来，不能只给一个数。
6. **`formatSize` 补 GB 档**：上限到了 GB 级，写成「2048.0 MB」读不出量级。

### 本轮核到的（2026-11-14）

| 平台 | 上限 | 出处 | 原文要点 |
| --- | --- | --- | --- |
| B 站 | 16 GB | 帮助中心 `#/?qid=3845`（2026-04-01 更新） | 单 P 不超过 16G；权益等级 lv3 以上 web 投稿 64G |
| 快手 | 2 GB | 帮助中心「如何发布长视频」 | 相册导入最多 31 段，大小不超过 2G，时长不超过 15 分钟 |

其余七个平台（抖音 / 小红书 / 视频号 / TikTok / YouTube Shorts / X / 通用）
**仍然空着**，继续写「未核验」。原因写在下文。

## 理由

- **出处比数字重要**：平台随时改规则，一个没有出处的数字三个月后就没人敢信。
  带上 `url` + `quote` + `checkedAt`，复查成本降到「点一下、看一眼」。
- **适用场景必须写**：B 站 16G 与 64G 是两个不同路径的上限，只写一个数会让
  作者以为 20G 的成片一定发不了；快手的 2G 是 App 相册导入的上限，不代表
  web 端。写清口径比给一个更大的数更诚实。
- **宁可少填**：七个平台没拿到官方原文，就不填。ADR-0112 的立场不变。

## 后果

**正面**

- B 站与快手的文件大小从「未核验」变成硬校验，超了在导出前就拦住。
- 每个数都能顺着 `url` 回到官方那句话；复核日期也在界面上。
- 测试保证「填了上限必须有出处」，以后加平台不会漏。

**负面 / 代价**

- 只有 2 / 9 个平台有上限，其余仍要作者自己判断。
- 抖音 / TikTok / YouTube 的文档站在本次核验的网络环境下不可达
  （`developers.tiktok.com`、`support.google.com` 超时），抖音开放平台的
  文档目录里没有视频上传接口页——不是没核，是**这次核不了**，需要换个网络
  环境再补。
- 快手那条是 App 相册导入的口径，web 端上限仍未核；`maxFileNote` 已如实写明。
- 平台改版后 `url` 可能失效；`checkedAt` 是唯一能看出「这条有多旧」的线索。
