# ADR-0169：转场与调色（E4）

- 状态：已采纳
- 日期：2026-11-13
- 决策者：用户 + Claude
- 关联：E4、I3、E6、H5、C12、准则 P5 / P15

## 背景

到这一刻，成片是**硬切到底**：`apps/web/app/api/render/route.ts` 的 `buildCommand`
把每段素材各自规整成同一尺寸、同一帧率，再用 `concat=n=N:v=1:a=0` 首尾相接，
一段接一段，接缝处没有任何过渡。整条片子的色彩也只有出图时模型给的那一份——
`Project.look` 编译的是**提示词**（让模型画成什么样），不是对已拍好的画面做的调整。

两个缺口都在「导出」这一层，与模型无关：

1. 场与场之间、时间跳跃处，硬切会让人觉得「跳了一下」。短剧里最常见的补救是淡到黑。
2. 各镜来自不同批次、不同模型，色温与饱和度天然不齐。`docs/CONSISTENCY.md`
   早就把「调色统一」列为掩盖差异的手段，但没有任何地方能调。

## 决定

1. **转场只做不改变时长的淡入淡出**
   ```ts
   TimelineItem.transitionIn?: { kind: "black" | "white"; durationMs: number }
   ```
   - 挂在**后一段**上：删掉前一段时，后面那段的接法跟着它一起走。
   - 只收 `black` / `white` 两种：短剧里真正用得上的是「黑场断开」与「白场闪回」，
     擦除、旋转、圆形展开这些在竖屏里只会让人出戏。
   - 时长 100–600ms，且**单侧不超过这一段的一半**：300ms 的转场接在 400ms 的短镜上，
     淡出还没完就要淡入，画面会一直黑着。夹完不足 100ms 就不做——40ms 的闪黑是故障，不是转场。

2. **不用 `xfade`，用两段各自的 `fade`**
   - `xfade` 让两段画面**重叠**：成片比时间线短一个转场时长，后面的字幕、配音、
     角标全部提前，整体错位。
   - 时长是音轨定的（准则 P5）：不为一个转场让整条时间线让步。
   - `fade=t=in` / `fade=t=out` 各自作用在一段上，`concat` 之后时长一分不少。
   - 编译位置固定在 `setpts=PTS-STARTPTS` **之后**：`fade` 按时间戳算起止，
     时间戳没归零就会淡在错误的帧上。

3. **调色是 `Project.grade`，与 `Project.look` 分工**
   ```ts
   Grade = { presetId, contrast, saturation, temperature, vignette }
   ```
   - `look` 决定**生成时**提示词里的质感（模型画成什么样），改它要重出图；
   - `grade` 决定**导出时**对已拍好的画面做多少色彩调整，改它只重渲一遍。
   - 两者成本不同，合成一个旋钮就得二选一。
   - 三档对比 / 三档饱和 / 三档色温 + 暗角开关；五个预设（原样 / 电影 / 暖忆 /
     冷峻 / 明亮日常）。默认档**不产生任何滤镜**，旧项目导出与以前逐字节同构。
   - 真正的 LUT（`.cube` 导入）属于 I3，这里不做。

4. **调色的位置：拼好画面之后、字幕与角标之前**
   ```
   [vbase] eq=…,colorbalance=…,vignette=… [vgraded] → overlay 字幕 → overlay 角标
   ```
   - 顺序反过来，白字会被调成米黄、角标会跟着变暗——两样都有合规要求（H5）。
   - 不调色时不插这一段，滤镜图与以前逐字一致。

5. **校验在两头都做**
   - `checkTimeline`（IR）：转场颜色、时长、单侧不超过一半；`timeline.updated`
     落库前按 `TimelineItemSchema` 解析补默认值。
   - `validateRenderManifest`（服务端）：清单里的 `fadeIn` / `fadeOut` / `grade`
     不合法就**拒收**而不是悄悄丢掉——作者设了淡到黑、成片却是硬切，
     「看着成功其实不一样」比一次失败更难发现。

6. **界面：成片页顶栏「调色」抽屉 + 时间线下的接缝条**
   - 抽屉上半：五个预设、逐项三档、暗角开关、**会送进渲染的滤镜原文**（`eq=…`）、
     「存调色 / 恢复原样」。
   - 抽屉下半：每一处接缝一张卡（后一段的镜号、接缝位置、后一段多长），
     硬切 / 淡到黑 / 淡到白三选一 + 时长滑杆（上限是这一段的一半）。
   - 时间线下面一排接缝 chip：`SH-03 黑300` / `SH-04 硬切`，点一下打开抽屉。
   - 预览（播放器与导出的预览 HTML）都按同一套 `clipFades` 近似：接缝处盖一层
     黑 / 白遮罩，调色用 CSS `filter` 近似。**不是逐像素等价**，界面如实说明。

## 理由

- **时长不动**：这条片子的时间线是音轨定的。叠化让画面重叠，字幕与配音就得整体
  重算，那是一次比转场大得多的改动。
- **挂在后一段上**：删片段是常见操作。挂在「接缝」上的话，删掉一段还要去找
  后面那一段把接缝清掉；挂在后一段上，它跟着自己走。
- **只给两种颜色**：给十种擦除，作者会挨个试一遍；给两种，选的是「要不要断开」。
- **调色与风格分开**：改一个旋钮就要重出全部图，还是只重渲一遍——这是作者
  最需要分清的一件事。
- **默认不产生滤镜**：旧项目重渲一遍，输出与以前逐字节同构；已出图的溯源仍然对得上。
- **不合法就拒收**：悄悄夹短转场或丢掉调色，会让成片与作者看到的设置不一致。

## 后果

**正面**

- 场与场之间第一次能有过渡；时间跳跃、回忆、段落收尾都有了说法。
- 各批素材的色温与饱和度第一次能统一，`CONSISTENCY.md` 里的「调色统一」有了落点。
- 调色只影响导出：改它不花钱、不重出图，调完马上能重渲一版看。
- 预览、抽屉、渲染三处用的是同一份 `clipFades` / `gradeFilters`，不会各说各话。

**负面 / 代价**

- 没有叠化。想做「溶解」得等时间线支持重叠，那是另一条路。
- 转场只挂在接缝上，不能给整条片子统一设「每处都淡 300ms」——要挨个点。
- 调色是 `eq` + `colorbalance` + `vignette` 的组合，不是真正的 LUT；
  胶片质感只能近似，做不到「柯达 2383」那种颜色映射。
- 预览是近似：CSS 滤镜与 ffmpeg 滤镜不是同一个公式，抽屉里写了「以导出为准」。
- 服务端拒收不合法清单时，旧客户端（不认识这两个字段）送来的清单仍然通过——
  兼容性保住了，但也就意味着「清单没带转场」与「转场被忽略」在服务端看来一样。

**不做**

- 叠化 / 溶解 / 擦除 / 旋转等改变时长或需要两段重叠的转场。
- `.cube` LUT 导入与胶片模拟（I3）。
- 按场批量设转场、全片统一接法。
- 单镜级调色覆盖（调色是整条片子的）。
- 音频淡入淡出与转场对齐（混音已经由 C12 的响度归一化管）。

## 备选方案

| 方案 | 不采用的原因 |
| --- | --- |
| 用 `xfade` 做叠化 | 两段重叠会让成片比时间线短，字幕与配音整体错位；时长是音轨定的（P5） |
| 把转场挂在「接缝」实体上 | 删片段时要去改别人的字段；挂在后一段上它自己跟着走 |
| 给十几种擦除 / 旋转 | 竖屏短剧里花哨转场让人出戏；选项越多越会挨个试 |
| 调色并进 `Project.look` | 改风格要重出图，改调色只重渲；合成一个旋钮就得二选一 |
| 调色作用在字幕与角标之后 | 白字被染成米黄、角标变暗，两样都有合规要求（H5） |
| 清单里转场不合法时悄悄丢掉 | 作者设了淡到黑、成片却是硬切，「看着成功其实不一样」更难发现 |
| 把调色编译结果存进 IR | 编译是纯函数，毫秒级；存了就要配失效机制 |
| 预览直接渲染一段低码率视频 | 播放器里没有服务端；预览 HTML 要能双击打开、自包含（P20） |
