# ADR-0143 对白按句归一响度

- 状态：已接受
- 日期：2026-11-12
- 决策人：用户 + Claude
- 关联：ADR-0099（对白优先混音）、ADR-0085（配音）、ADR-0124（表演参数）、C12、C9

## 背景

ADR-0099 的混音做对了三件事：对白落总线、音乐按台词窗 ducking、整片两遍 loudnorm 到 −14 LUFS。但 loudnorm 是**整片**的：两句对白一响一轻，整片拉平之后它们之间的差还在。

配音是逐句生成的，不同句子来自不同请求、不同音色，甚至不同供应商；静的那句不会因为整片达标就变清楚。观众听到的是「这句听不清，那句震耳朵」。这不是音量旋钮能解决的：成片已经导出，作者没有分轨。

## 决策

1. **每句对白先量后抬。** 渲染时在混音之前，对每条对白轨单独跑一遍 `loudnorm ... print_format=json`，取 `input_i`（集成响度）。
2. **统一拉到 −18 LUFS 再进总线。** 对白目标准位 `DIALOGUE_TARGET_LUFS = -18`：比成片目标低 4 dB，留给整片 loudnorm 与音乐床的余量；句与句之间对齐，整片再一起抬到 −14。
3. **单句增益封顶 ±12 dB。** `segmentGainDb` 把差值夹在 `[-12, +12]` 并按 0.1 dB 取整。超过 12 dB 多半是文件坏了或几乎无声，拿增益硬修只会把底噪推上来。
4. **量不到就不动。** `null`、非有限值、以及 ≤ −70 LUFS 的静音段一律返回 0：静音不是「很小声的台词」，按它去抬 12 dB 是错的。
5. **增益写进对白滤镜，按帧生效。** `buildAudioMixCommand` 在 `adelay` 之后、`atrim` 之前插 `volume=<linear>`；0 dB 不插，滤镜串保持干净。
6. **报告里留证据。** `LoudnessReport.dialogueGainsDb` 记每句实际用的增益；成片页在响度块下面多一行「对白按句归一：n 句，增益 −8.0 … +12.0 dB（有一句已触 12 dB 上限）」。没有对白或一句都没量到就不显示。
7. **不碰音乐与音效。** 只归一对白：音乐有自己的基准增益与 ducking，音效总线还没做（见「未做」）。

## 理由

- **整片归一救不了句间差**：loudnorm 求的是全片积分响度，一句轻一句响平均下来可以「达标」，但听感不对。
- **−18 而不是 −14**：对白先对齐到 −18，整片再过 loudnorm 到 −14；如果直接拉到 −14，音乐与音效叠上来会顶到真峰值上限，loudnorm 只能压回去，白做。
- **±12 dB 是安全线**：正常录音的句间差不该超过这个量级；超了是数据问题，不是混音问题。
- **证据要可见**：作者看不到内部滤镜串，报告里写明每句用了多少增益，才知道系统真的动过手。
- **静音不抬**：这是最常见的错法——把一段空白当成「音量很小」，抬完底噪全出来了。

## 后果

**正面**

- 一句轻一句响的配音被拉到同一水平，整片 loudnorm 只做最后 4 dB 的统一。
- 报告里能看到每句增益与是否触顶，异常句有据可查。
- 纯函数 `segmentGainDb` 可测；滤镜串的插入位置也有断言。

**负面**

- **多一遍 ffmpeg**：每句对白多一次解码测量，渲染时间随句数增长（示例 2 句几乎无感；长片几十句会明显变慢）。
- **只按集成响度**：不看短时响度与峰值，句内忽大忽小修不了；那需要压缩器 / 限制器。
- **触顶不报警只写一行**：一句被夹到 12 dB 时成片仍然交付，作者要自己看那一行。
- **先量后混**：测量的是原始文件，不是 ducking 之后的混音；对白本身不受 ducking 影响，所以成立，但以后若给对白加效果链要重新想。

## 未做

- 自动二次归一（输出偏离 >1 LU 时自动修正，目前直接判 fail、不交付）。
- 多声道 / 5.1 输出。
- 音效总线与独立音效轨。
- 句内压缩 / 限制（短时响度）。

## 验证

- 单测 3 条（`render-audio.test.ts`）：目标位 ±12 dB 夹取与 0.1 dB 取整；`null` / `NaN` / −70 返回 0；带增益的对白滤镜插入 `volume=1.584893`（+4 dB），0 dB 不插。
- web 884 条全过；`tsc --noEmit` 与 `next build` 干净。
- 浏览器（`/edit`，示例项目）：灌两句配音（0.5 振幅 220Hz / 0.04 振幅 330Hz 的 WAV）→ 导出闸门打开后点「导出草稿 MP4」→ 成片 `-14.0 LUFS / -11.4 dBTP`，响度块下出现「对白按句归一：2 句，增益 -8.0 … +12.0 dB（有一句已触 12 dB 上限）」。
