# ADR-0232：配乐与音效可淡入淡出（C7 收口）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：C7、C4、C12、ADR-0184、ADR-0218

## 背景

C7 的未做项里一直有「淡入淡出」。这不是花哨功能：配乐直接硬切进来会「啪」一下，
结尾突然消失会让整条片子像被掐断。作者现在只能靠调增益或换素材绕过。

## 决定

1. **`MusicCue` / `SfxCue` 各加 `fadeInMs` / `fadeOutMs`**：0–5000 毫秒，默认 0
   （旧日志读出来就是 0，渲染与以前逐字节同构）。
2. **从这一段自身算，不从整片算**：淡入从这一段开头、淡出在这一段结尾前。
   「这一段怎么进、怎么出」是作者在配乐卡 / 音效卡上直接调的事。
3. **落地时夹到长度内**：写 5 秒淡出但这一段只有 2 秒，就淡 2 秒；
   两边加起来超过长度时**按比例缩**——不缩的话淡出起点会变负，`afade` 直接报错。
4. **放在 `adelay` 之前**：那一刻时间轴还从 0 开始，`afade` 的 `st` 才是这一段相对时间。
5. **清单校验**：`fadeInMs` / `fadeOutMs` 只认 0–5000 的整数，不在范围里不报错、
   当作没写（旧客户端不带这两个字段）。
6. **命名区分**：渲染层已有视频用的 `fadeFilters`（render-effects），音频这个叫
   `audioFadeFilters`，避免两件事混成一个名字。

## 验证（本地 ffmpeg 实测）

4 秒粉噪，淡入 1 秒 / 淡出 1 秒，分段测平均音量：

| 位置 | 原始 | 加了淡入淡出 |
| --- | --- | --- |
| 开头 0–0.2s | −34.9 dB | **−54.3 dB** |
| 中间 1.9–2.1s | −34.5 dB | −34.5 dB（不变） |
| 结尾 3.8–4.0s | −34.2 dB | **−52.6 dB** |

两端各降约 19 dB、中间不变，正是淡入淡出该有的形状。

## 理由

- **硬切是听得出来的**：配乐与音效的起止是「声音事件」，不是数据边界。
- **从这一段自身算**：作者在卡片上看到的是「这一段多长」，淡出就该相对这一段。
  相对整片算会让同一份模板在不同位置行为不同。
- **按比例缩而不是报错**：作者写「淡入 3 秒、淡出 3 秒」而这一段只有 4 秒，
  报错让他去算比例，不如工具自己缩——效果上都是「两端各淡一半」。
- **默认 0**：不改变任何已有项目的行为。

## 后果

**正面**

- 配乐与音效可以自然进出，不再硬切。
- 旧项目完全不受影响（默认 0，滤镜串不变）。
- 实测数据在案，不是「应该能行」。

**负面 / 代价**

- **不做对白的淡入淡出**：台词淡出会听不清，这一档不给这个选项。
- 只支持线性淡（`afade` 默认曲线），没有指数 / 对数曲线。
- 淡入淡出写在 cue 上，不与转场联动——视频转场改了，音频淡变要自己跟着调。
- 单位是毫秒，界面上是数字输入框，没有滑杆。
