# ADR-0217：情绪词落到光影字段（F7 第一档）

- 状态：已采纳
- 日期：2026-11-14
- 决策者：用户 + Claude
- 关联：F7、E11、H19、I2、B4、ADR-0039、ADR-0168、DIRECTOR-GRAMMAR.md

## 背景

F7「语义编辑（自然语言改镜头）」在 FEATURES 里举的例子就是「再压抑一点 → Camera/Lighting patch」。
但 `parseInstruction`（ADR-0039 的查表实现）能改的只有五样：景别、机位、运镜、时长、亮度补充。
**`Lighting` 一个字都改不了**——「再压抑一点」会落到 `promptNotes` 里当一句补充要求，
结构化字段 `Shot.lighting` 不动。

后果有两个：

- **走位台账看不到**：ADR-0215 的跨镜光影检查读的是 `Shot.lighting`，只写进 promptNotes
  的情绪词对它是隐形的，同一场里「压抑 → 明亮」这种断裂查不出来；
- **提示词编译读不到**：`compileLighting` 只读 `Shot.lighting`，情绪词进不了那一句，
  只能靠 promptNotes 兜底。

## 决定

1. **`ShotPatch` 增加 `lighting`**：`parseInstruction` 可以返回光影补丁。
2. **只认四组能明确落到「主光方向 + 塑形」的情绪词**，对应 DIRECTOR-GRAMMAR.md 的 L 组：

   | 说法 | 主光方向 | 塑形 | 依据 |
   | --- | --- | --- | --- |
   | 压抑 / 沉重 / 压迫 / 悬疑 / 紧张 | 顶光 | 剪影 | L5「顶光压迫」 |
   | 神秘 / 暧昧 / 看不透 / 阴森 | 逆光 | 立体 | L5「侧逆光神秘」 |
   | 柔和 / 温情 / 温柔 / 暖一点 / 软一点 | 正面 | 平 | L2 低光比 |
   | 硬朗 / 冷峻 / 凌厉 / 锐利 | 侧面 | 立体 | L1 高光比 |

3. **只改情绪的维度，不改光源**：光源是「这个房间里有什么灯」（窗 / 台灯 / 顶灯 / 实用 / 月光），
   情绪词说不到那么具体。原来写了光源就沿用，没写就按默认（窗光）起一份。
4. **与结构字段可以叠加**：「太暗了，再压抑一点」同时改 `note` 与 `lighting`。
5. **落成结构字段就不重复写 promptNotes**：一件事只记一处。
6. **没听懂时的提示补上新说法**：让作者知道现在认得「压抑一点 / 柔和一点」。

## 理由

- **这正是 F7 原文举的例子**：不是新造需求，是把文档里写了、代码没做的事补上。
- **接上 ADR-0215**：光影一旦进 `Shot.lighting`，跨镜检查与提示词编译立刻都能用上，
  不需要改那两处。
- **四组而不是十组**：情绪词到光影的映射没有权威依据，多认一组就多一次猜。
  先只收 L 组里有明确对应的四种，其余仍然落 promptNotes 如实说「这是补充要求」。
- **不动光源**：把「压抑」解释成「关掉台灯换成顶灯」是过度推断，作者没这么说。

## 后果

**正面**

- 「再压抑一点」从一句备注变成可回放的结构字段，跨镜检查与提示词都能读到。
- 与 H19 的既有口径一致：能落结构字段就落，落不了才进 promptNotes。
- 不需要新 UI：指令框本来就在，认得的说法多了一类。

**负面 / 代价**

- 四组映射是经验判断，没有用样片标定；「压抑」在别的语境里可能想要别的光。
- 只认词面：说「像《教父》那样」仍然听不懂（那是模型兜底那条路）。
- 不会撤销：改错了要再下一句（「柔和一点」）或走历史抽屉。
- E11（意图层自然语言修改全流程）仍然没做，这一档只在单镜层面。
