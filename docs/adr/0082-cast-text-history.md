# ADR-0082 名字与描述的历史回退

- 状态：已接受
- 日期：2026-11-11
- 决策人：用户 + Claude
- 关联：ADR-0051（动作版本）、ADR-0058（场头版本）、ADR-0071 / 0072 / 0079（人物 / 道具 / 地点的文字与参考图）、FEATURES B1 / B8 / F2

## 背景

人物、道具、地点都只有一个名字加一段描述，改起来是就地覆盖：`character.updated { name, appearance }`、`prop.updated { name, description }`、`location.updated { name, description }`。日志里其实留着每一版，但界面只显示最新那一版。改坏一句外形、把人物名试了一个不合适的写法，想退回去只能凭记忆重打一遍；参考图和「不许变」清单都已经能逐条摘、逐条划，文字反而没有退路。

动作、场头、台词、台词顺序已经有「改过几次 / 上一版 / 用这版」的读法（ADR-0051 / 0058），缺的是把同一套用到定妆页的人与物上。

## 决策

1. **读模型 `castTextHistory(events, kind, id)`**（`kind` 为 `character` / `prop` / `location`）返回：
   - `original`：建出来那一版，取自 `project.created` 快照或对应的 `*.added` 事件；
   - `edits`：从旧到新，每次名字或描述变化一条，每条是**改完之后完整的** `{ at, name, body }`（人物 `body` 是外形，道具 / 地点是描述）。
   逐条把 patch 叠到上一版上，与动作、场头的读法一致。没出现过这个 id 返回 `undefined`。
2. **历史按「版」记，不按字段记**：名字与描述常常一起改，界面上一版就是一行「名字 · 描述」。只改「不许变」清单、换参考图、换地点模板都不算一版——它们不是这一栏的文字。
3. **界面上收成一行小字**：名字 / 描述下面写 `改过 n 次 · 上一版「…」`，点一下展开列表，最新的在上、`最初` 在最后，每行 `时间 · 名字 · 描述`；当前正在用的那一版标 `正在用`，其余右侧有 `用这版`。
4. **回退写普通事件，不回滚**：点 `用这版` 就是一次正常的 `*.updated`，名字与描述整版一起写回。日志里多一条，历史里多一版；再点刚才那一版就能"恢复"回来，等于前进也是同一套。
5. **边界**：
   - 只读标签页不显示 `用这版`，历史仍可看；
   - 名字的唯一性照旧（同一类里不能重名）：要退的那版名字后来被别人占了，回退被拒绝，原因写在页头；
   - 空白描述可以退（它也是真实的一版）；
   - 已删除的人物 / 道具 / 地点没有历史入口。

## 理由

- **完整版本比字段历史好读**：用户想的是"上周那个人长什么样"，不是"名字改过 3 次、外形改过 5 次"；拆成两条时间线还要处理并发改动。
- **与已有历史同一套形状**：`original` + `edits` 已经是动作、场头、台词的通用读法，测试与界面都能借用。
- **回退走正常写入**：不发明 `character.reverted` 之类的事件，也不删日志（ADR-0011）；"回退"在日志里就是一次普通编辑，任何读模型都不用特判。
- **只收文字**：模板决定画哪种剪影、参考图是资产引用、`mustNotChange` 是清单；它们各有自己的撤销 / 替换入口，混进文字历史会让"这一版"说不清是什么。

## 后果

**正面**
- 人物 / 道具 / 地点改过之后，下面能看到「改过 n 次 · 上一版「…」」，展开按时间列出版本，点 `用这版` 整版写回。
- 回退本身留痕，可以再退回去；刷新、换设备后历史仍在（日志存在本地）。
- 测试：IR 100、web 226（新增 4：读模型的原始版 / 改名改外形 / 道具合并 / 地点 `*.added`）、gateway 17、pipeline 22，合计 365。`pnpm typecheck`、`pnpm build` 通过。
- 真实链路：定妆页把「周」改成「周小雨」、外形改成「短发，黑色风衣」，保存后名下出现「改过 1 次 · 上一版「周 · 高个，衬衫袖口卷起」」；展开见最新、上一版与 `最初` 三行，点 `最初` 那一行的 `用这版`，名字与外形一起回到「周 / 高个，衬衫袖口卷起」，历史变成 3 条，最初那版标 `正在用`。

**负面**
- **名字与描述绑在一起退**：只想退外形、保留现在的名字做不到，要退完再改一次名字。
- **没有逐字差异**：一版一行，长描述在窄栏里截断，只能靠悬停看全。
- **每改一次都留一版**：反复微调会攒出很长的列表，暂无上限与清理。
- **不做全局回滚**：项目版本、镜头、场次的历史仍各管各的。
- **模板、参考图、「不许变」不进这条历史**。

**跟进**
- 回退时保留当前名字 / 只退描述的分字段回退。
- 版本列表加 diff 或"只看我改的字段"。
- 历史折叠到最近 3 版，更早的再展开一层。
- 与项目级快照（版本回滚）打通。

## 替代方案

| 方案 | 未采用的原因 |
| --- | --- |
| 每个字段一条历史（名字一条、描述一条） | 拆成两条时间线，界面更碎，还要处理同一次保存里两字段一起改的情况 |
| 回退写专门的 `*.reverted` 事件 | 读模型与校验都要特判；正常 `*.updated` 已经够表达"整版写回" |
| 回退时删掉后面的日志 | 违背只追加（ADR-0011），也会丢别的编辑 |
| 直接按时间倒序全局撤销栈 | 会把参考图、模板等不同种类的改动混在一起，撤销粒度说不清 |
| 只在内存里记上一版（像换人撤销 ADR-0081） | 文字改动往往过一会儿才想退，刷新就没了；这里要的是可回看的版本，不是即时撤销 |
| 弹窗里看历史 | 定妆页一行就能展开，弹窗会打断对照其它人物 |
