## 一、为什么推翻 v1

v1 是三栏编辑器：左竖阶段图标轨、中画布、右属性面板。问题不在配色，在骨架。

1. **骨架抄了编辑器。** 左轨 + 画布 + 属性板是 Photoshop / Premiere 的解剖。它假设用户"操作面板"，而用户实际在"做判断"。
2. **流程被做成了导航。** 六个阶段变成竖向图标栏，用户要在脑子里维护"我在第几步"。
3. **藏起了整条片子。** 胶片轨默认折叠，等于把短剧最要紧的节奏收进抽屉。
4. **三版配色是陈词滥调。** 近黑 + 琥珀、近黑 + 青、米白 + 靛蓝。青色那版还撞上本文档明确否定的"赛博朋克"。
5. **用渐变假装画面。** CSS 渐变当视频、色块当缩略图，样机一眼假。

v2 的原则：**大画面、一条带、一句话。**

## 二、布局：一屏三带

```
┌──────────────────────────────────────────────────────────────┐
│ 顶带 46px  项目名 v3   故事·剧本·分镜·关键帧·声音·成片   ¥18.96/60  导出 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│ 中台   [SH-02]        [ SH-03 当前 ]        [SH-04]           │
│        253×450         253×450 满亮          253×450           │
│                        画面内烧字幕                             │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 下带   胶片轨（常驻，一格一格等比，留用红 / 淘汰蓝 / 当前白）      │
│        [ 她笑得太早了 · 说哪里不对        ⌘⏎ ] [重做 ¥2.12] [留用] │
└──────────────────────────────────────────────────────────────┘
```

### 三条规则

1. **上面是当前，下面是整条。** 任何时刻都不需要点开东西就知道"在看哪一格"和"整条多长"。
2. **没有常驻侧栏。** 参数、提示词、参考图走浮层，从画面或胶片格上长出来，做完就收。
3. **每个动作都带价。** 重做按钮写 ¥2.12。用户不是在调参数，是在再买一条。

### 各带职责

| 带 | 放什么 | 绝不放什么 |
| --- | --- | --- |
| 顶带 | 项目名、六阶段一行小字、已花/预算、导出 | 图标导航、设置、账号菜单 |
| 中台 | 前一格 / 当前 / 后一格，当前满亮、左右 48% | 属性、滑块、图层 |
| 下带 | 胶片轨 + 一句话指令 + 留用/重做 | 完整时间线、素材库 |

### 为什么是"三格并排"

竖屏片子在宽屏上居中会留下大片空白。左右两格暗化的相邻镜头把空白变成上下文：
观众能感到"前后是什么"，而不是"这里什么都没有"。这是这一版最像"审片"的地方。

### 同一骨架换内容

早期没有画面，中台换成**纸**：剧本按场记格式排（场次行用等宽小字，动作 15px/2.0，对白缩进），
下带从胶片轨换成**节拍带**（入局 / 错认 / 试探 / 反转 / 代价 / 收束 / 钩子）。

> 一条布局规则：**中台换内容，下带换单位，顶带不变。**

### 手机（审批形态）

只有进度点、画面、两颗按钮。不给参数，不给时间线。滑到下一格预览，长按撤销上一格。
桌面创作、手机确认，共享同一份 IR。

## 三、令牌

落地文件：[`packages/design-tokens/tokens.css`](../packages/design-tokens/tokens.css)（`@loomina/design-tokens`，纯 CSS，零依赖）。
下面三块是同一份变量表的说明；组件里只用 `var(--bg)` 这类语义令牌，不写死颜色。

合作方式：**主案一个颜色——白**。颜色留给画面。红与蓝不是强调色，是批注。

### 共用（三套主题一致）

```css
--space-1: 4px;  --space-2: 8px;  --space-3: 12px; --space-4: 16px;
--space-5: 24px; --space-6: 32px; --space-7: 48px;

--text-xs: 10.5px; --text-sm: 12.5px; --text-base: 15px;
--text-md: 17px;   --text-lg: 20px;   --text-xl: 26px; --text-2xl: 34px;

--radius: 2px;                     /* 全站唯一圆角，没有胶囊 */
--dur: 160ms;
--ease: cubic-bezier(.2,.8,.2,1);  /* 只动透明度与位移 */
```

### 印片（主案 · 暗）

```css
--bg:        #0C0C0D;
--surface:   #131316;
--line:      #1E1E21;
--line-2:    #2B2B2F;
--text:      #F2F2EF;
--muted:     #7B7C7F;
--muted-2:   #4A4B4E;
--pick:      #E0442E;   /* 留用 */
--reject:    #3D6DDB;   /* 淘汰 */
```
用在：分镜、关键帧、成片。

### 影厅白（亮）

```css
--bg:        #F4F4F1;
--surface:   #FFFFFF;
--line:      #E3E3DE;
--line-2:    #F0F0EC;
```

用在：剧本、设置、帮助、手机审批。**不用于看片**——亮底会把暗场视频压成一块黑。

### 钨丝（暖，备选）

```css

--line:      #2A2521;
```

用在：夜间模式 / 用户自选主题（后续）。温度来自底色与字色，不来自强调色。

## 四、标记系统

胶片轨是唯一的彩色区域，只用三种标记：

| 标记 | 形式 | 含义 |
| --- | --- | --- |
| 留用 | 2px 红线在格子底边 | 已确认，不再看 |
| 淘汰 | 2px 蓝线 + 50% 压暗 | 留作对照 |
| 当前 | 1px 白描边 | 正在看的这一格 |

不填充、不发光、不加角标。颜色只在 2px 的线上出现。

## 五、图标与标志

图标：24 网格、1.4 线宽、圆头。**只替代动作**（播放 / 上下格 / 重做 / 留用 / 新增 / 帧 / 导出），阶段、镜头、对白一律用字。

标志三案，均在 64 / 24 / 16 三档验证：

| 方案 | 构成 | 判断 |
| --- | --- | --- |
| 字幕线 | 一片格 + 一条红字幕线 | 缩到 16px 只剩一条红线，最直白，未采用 |
| 双格 | 两片格并肩，正反打 | 最稳，但"织光"得靠名字解释，未采用 |
| **经线**（已采用） | 片格内三根经线，中间一根是光 | 即"被织出来的光"；可延伸出图标网格，也能做动效 |

配色：深底用白 + 红 `#E0442E`；亮底用墨 + 红 `#C43A24`。

## 六、实施顺序

1. **`tokens.css`**（已完成，`packages/design-tokens/tokens.css`）：三套主题合成一份变量表，组件里不写死颜色。
2. 三带骨架：`TopBar` / `Stage` / `ReelBar`，先静态再接数据。
3. 胶片轨：当前 / 留用 / 淘汰三态完整交互——这一步决定手感。
4. 一句话指令：先把"太暗了""换个角度"两条解析成参数改动 + 重做。
5. 剧本态：同一骨架换成纸面，验证"中台换内容"成立。

判断标准：走完 8 个镜头，不打开第二层菜单，不读文档。
