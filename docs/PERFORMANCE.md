# 表演与镜头内调度

> 核心判断：**观众记住的不是运镜，是人的脸和选择。运镜服务于表演，不是反过来。**
> AI 拍不了长表演，就把表演拆成可生成的单元：关键帧 + 微动作 + 反应镜头 + 剪辑。

---

## 一、AI 短剧里"表演"特殊在哪

真人拍摄里，表演 = 演员 + 导演 + 剪辑。在 AI 里它被拆成六件事：

| 组成 | 谁来定 | 可控性 |
| --- | --- | --- |
| 外观（脸/身体/服装） | 角色资产 | 高（参考图锁定） |
| 表情 | 首尾帧 + 提示词 | 中（微表情弱） |
| 身体姿态 | 首尾帧 | 中 |
| 动作 | 图生视频 | 低（长动作易漂） |
| 视线 | 提示词/参考图 | 低–中（容易飘） |
| 节奏 | 音频时长 + 剪辑 | 高 |

**结论：把"表演"当成一组可分别控制的参数，而不是让模型自由发挥。**

模型的已知短板：微表情、手部、多人互动、长动作、复杂转身、口型。产品必须主动设计绕开它们，而不是硬碰。

---

## 二、竖屏改变了表演空间

9:16 不是 16:9 裁一刀，它改变了调度方式：

- **两侧被裁掉**：横移、并肩、群戏都吃亏；脸和上半身成为主体。
- **纵深成为主要手段**：前后景、过肩、遮挡、由远及近。
- **手和一件道具**比全身动作更有表现力。
- **构图更紧**：中景≈别人的近景，特写≈别人的大特写。

竖屏适合：**一张脸 + 一双手 + 一件道具 + 一个视线方向。**
竖屏不适合：群戏、横向走位、复杂肢体动作、大场面。

---

## 三、表演的五个层次

由内到外，每一层都要在 IR 里有对应字段：

| 层 | 内容 | 例子 |
| --- | --- | --- |
| 1 意图 objective | 这场戏他想要什么 | 让她留下 |
| 2 情绪 emotion | 表层情绪 + 潜台词 | 表面平静，内里恳求 |
| 3 微表情 micro | 眼、眉、嘴、呼吸 | 眨眼变慢、喉结动 |
| 4 身体 body | 姿态、重心、肩、手 | 身体前倾又停住 |
| 5 动作 action | 走、坐、拿、推、转身 | 伸手又收回 |

**铁律：一个镜头只表达一个意图、一个情绪转折。** 想表达两个，就拆成两个镜头——这正好符合短镜头原则（P13）。

---

## 四、表演节拍（Performance Beat）

一个镜头内的表演不是连续的，是"节拍"：

```
起（listen / react） → 转（decide） → 落（act / speak）
```

对应到台词，就是 **台词前 / 台词中 / 台词后**：

- **台词前 0.3–0.5s**：反应。观众看的是"听到之后的表情"，不是台词本身。
- **台词中**：说，但表演在眼神和手上。
- **台词后 0.5s**：余韵。谁先移开视线，谁就输了。

**反应镜头是表演的主战场。** 短剧里大量情绪靠"听的人"完成，而不是"说的人"。

---

## 五、AI 可生成的表演语法

把"情绪"翻译成**模型能稳定生成的具体动作**，而不是形容词。

| 表演意图 | 可生成的手段 | 要避免 |
| --- | --- | --- |
| 压抑的愤怒 | 下颌收紧、眨眼变慢、手指收拢 | 面部扭曲、大吼 |
| 心虚 | 视线下移、假笑、摸脖子/耳后 | 复杂手部动作 |
| 震惊 | 停顿、瞳孔、后退半步 | 夸张后仰、张大嘴 |
| 亲密 | 距离缩短、视线停留、呼吸起伏 | 长拥抱、复杂接触 |
| 决绝 | 起身、转身、背影 | 边走边说长台词 |
| 轻蔑 | 嘴角单侧、抬眼、缓慢转头 | 大幅挥手 |
| 崩溃 | 低头、肩膀塌、手遮脸 | 嚎哭、剧烈抖动 |

**原则：情绪越强，动作越小。** 模型演不了"大"，但能演"准"。

## 六、关键帧表演法（核心方法）

这是把表演变成可控生成的关键：

```
首帧（情绪起点：姿态 + 表情 + 视线）
        │
        ▼   图生视频：只做微动作 + 运镜
尾帧（情绪终点：姿态 + 表情 + 视线）
```

- **首尾帧定情绪的两端**，中间不做大表演。
- **三帧法**：起 / 转 / 落 → 需要三个关键帧、切两段生成，用剪辑接起来。
- **表情与身体分开控**：表情靠首尾帧和参考图，身体靠姿态描述。
- **视线必须显式**：看谁、看哪里、看不看镜头。视线是 AI 最容易飘、也最影响"演技"的参数。
- **超过模型安全时长的表演，一律拆段**（B3.1 / ADR-0012），不要赌长镜头。

## 七、镜头内调度（Blocking）

调度不是"人站哪"，是**用空间关系讲故事**。

### 三个基本手段

1. **站位**：三角站位避免呆板；纵深站位制造层次。
2. **运动**：进入/离开画面、穿过前景、坐下/起身、逼近/后退。
3. **道具**：一件道具胜过一句台词（递伞、放钥匙、捏碎杯子）。

### 距离即关系

| 画面距离 | 关系 |
| --- | --- |
| 极近（脸贴脸） | 亲密 / 威胁 |
| 一臂 | 对话 / 试探 |
| 两步以上 | 疏离 / 对峙 |
| 隔一个前景 | 隔阂 / 窥视 |

### 竖屏调度

- 少横移，多纵深。
- 用前景（门框、肩膀、杯子）制造层次与遮挡。
- 人物不要并排站，改为前后错位。
- 一镜一个调度变化：走近、转身、坐下、拿起——**只做一件**。

### 调度的目的

每个调度必须回答：**它改变了什么？** 权力关系、信息、距离、压迫感。不能回答的调度就是多余动作。

## 八、表演与镜头语言的配合

| 情绪 / 意图 | 景别 | 机位 | 焦段 | 运镜 |
| --- | --- | --- | --- | --- |
| 脆弱 | 特写 | 略俯 | 85mm | 静止 |
| 压迫 | 近景 | 仰拍 | 广角 | 缓慢逼近 |
| 疏离 | 全景 | 平视 | 长焦压缩 | 固定 |
| 失控 | 近特 | 手持 | 35mm | 晃动 |
| 权力翻转 | 由近到远 / 由仰到平 | — | — | 拉 + 升 |
| 秘密 | 过肩 | 侧后 | 50mm | 静止 |

**顺序：先定表演，再定镜头。** 先想"观众要看到什么变化"，再选景别和机位。

---

## 九、口型与对白

- **只给特写做口型**；中景用侧背、遮挡、反应镜头规避。
- 台词前留反应，台词后留余韵。
- 呼吸、停顿、吞咽都是表演，不要用 TTS 一路平推。
- 对白镜头优先"听的人"，说的人可以用背影/侧脸/过肩。

## 十、表演 QA

| 检查 | 方法 | 失败处理 |
| --- | --- | --- |
| 情绪匹配 | VLM 判断表情与 Beat 意图 | 重生成 / 换首尾帧 |
| 视线一致 | 检测视线方向与对象 | 改提示词 / 换机位 |
| 动作完整 | 手部畸变、穿模、肢体断裂 | 重生成 / 缩短动作 |
| 表演强度 | 过火 / 面瘫 | 调整首尾帧表情幅度 |
| 情绪连续 | 剪辑点前后是否接得上 | 补反应镜头 |
| 口型 | 若启用 | 只特写启用 |

阈值按景别分级：特写看微表情，中景看姿态，全景看调度。

## 十一、失败模式

| 失败 | 表现 | 原因 | 对策 |
| --- | --- | --- | --- |
| 面瘫 | 全程中性脸 | 模型默认表情 | 首尾帧给明确表情 |
| 过火 | 狰狞/夸张 | 提示词写情绪形容词 | 改成具体微动作 |
| 手崩 | 六指/穿模 | 手部生成弱 | 少用手，或遮挡 |
| 视线飘 | 不知在看谁 | 未显式指定 | `GazeTarget` 必填 |
| 长动作漂 | 越演越不像 | 超模型时长 | 拆段 + 尾帧 |
| 多人穿帮 | 谁是谁分不清 | 多人同框 | 减少同框人数 |
| 情绪断层 | 剪辑点跳 | 前后镜情绪不接 | 补反应镜头 |
| 竖屏切头 | 构图失误 | 未按 9:16 设计 | 竖屏安全区预检 |

## 十二、IR 映射

```ts
interface PerformanceSpec {
  shotId: ID;
  objective: string;          // 这场戏他要什么
  emotion: { surface: string; subtext: string };
  beats: ActionBeat[];        // 起 / 转 / 落
  gaze: GazeTarget;           // 看谁 / 看哪 / 看镜头
  intensity: 1 | 2 | 3 | 4 | 5;
  avoid: string[];            // 明确不做什么（防过火/防手部）
}

interface ActionBeat {
  phase: "before" | "during" | "after";
  micro: string;              // 微表情
  body: string;               // 姿态/手
  action?: string;            // 动作
  startMs: number;
  endMs: number;
}

interface GazeTarget {
  target: "character" | "prop" | "camera" | "off-screen";
  targetId?: ID;
  direction: "left" | "right" | "up" | "down" | "center";
}
```

**新增不变量**

21. **每个 Shot 必须有 `PerformanceSpec`**，且只有一个 objective。
22. **`GazeTarget` 必填**；缺失不得进入生成。
23. **表演动作必须与所选模型的能力矩阵兼容**；超能力范围的动作必须拆段或改设计（B12）。
24. **首尾帧的表情/姿态必须与 `PerformanceSpec` 的起止一致**，否则视为关键帧不合格。

**实现说明（2026-11-11，ADR-0103）**

- `Shot.performance` 已落到 IR，类型是**可选**的 `PerformanceSpec`；嵌入 Shot 而不是单独带 `shotId`。落库前由 zod 补默认值，回放与实时状态一致。
- `before` = 首帧、`after` = 尾帧、`during` = 中段。首帧提示词只写 `这一帧的表演：起：…`，尾帧只写落，视频提示词写完整 `表演节拍：起…；转…；落…`。
- 不变量 21 / 22 **当前未硬拦生成**：存量项目没有该字段，硬拦会让整条片子无法续做。改为分镜检查的 **V10 warning**（列出还没设计表演的镜头，并在顶栏「表演」按钮上计数）。恢复生成守卫的条件与理由见 ADR-0103 决策 6。
- 不变量 24 已成为可执行行为：首尾帧各取对应节拍，不再三拍混写。
- 编辑入口：工作台顶栏「表演」→ 右侧「表演与调度」抽屉。

---

## 十三、一句话

**表演是镜头的目的，运镜是手段。**
AI 演不了长戏，就用"关键帧定两端 + 微动作演中间 + 反应镜头补情绪 + 剪辑接节拍"，把表演拆成模型能稳定生成的单元。
