# 前端与交互形态

> 核心判断：**用户不是来"操作时间线"的，是来"把一条想法变成能发的片子"的。**
> 界面按**任务**组织，不按**工具**组织；专业能力渐进披露，不挡主路径。

---

## 一、先立反面教材

这类产品最容易做成三种样子，都要避免：

| 反面 | 表现 | 为什么错 |
| --- | --- | --- |
| **剪辑软件化** | 首屏就是时间线、轨道、参数面板 | 用户第一眼就不知道该干什么（违反 P10） |
| **节点图化** | ComfyUI 式连线，能力全暴露 | 把"能力"当"产品"，C 端直接劝退 |
| **聊天框化** | 一个输入框，全靠提示词 | 不可控、不可回退、无法精细修改 |

正确形态在两者之间：**有明确阶段的一条流水线，每一阶段都有"默认结果 + 改的入口"。**

---

## 二、产品隐喻：导演工作台

不是"素材库 + 时间线"，而是**"拍一条片"的过程**：

```
想法 → 故事 → 分镜 → 预演 → 拍摄 → 剪辑 → 声音 → 发布
```

用户在界面上的心理模型应该是"我在导一条片"，而不是"我在用软件"。

对应到文档里的四道闸门（OPERATIONS.md），界面就是四个"确认点"。

---

## 三、双形态：桌面创作，手机审批

| | 桌面 Web | 手机伴侣 |
| --- | --- | --- |
| 定位 | **主创作** | **看、批、发** |
| 能力 | 全流程 | 审片、确认、改一句台词、换一个 Take、分享 |
| 不做 | — | 时间线、分镜编辑、参数面板 |
| 关键场景 | 坐下来做一条片 | 通勤时审批、睡前发一条 |

**手机不是缩小版编辑器。** 强行把桌面搬过去，两边都做不好（TECH-SELECTION 里已定 Web 优先、Tauri 后置）。

手机端最有价值的三个动作：

1. **推送审批**：镜头生成好了，点开看，通过/重做。
2. **一句话修改**："第三镜她别笑"，直接改。
3. **一键分享**：分享扩展发到平台（PUBLISHING.md）。

## 四、信息架构

```
首页
├── 新建（一句话 / 模板 / 导入小说）
├── 继续创作（按阶段显示进度）
└── 我的作品

创作流（核心）
├── ① 故事        一句话 → Logline → 人物 → Beat
├── ② 定妆        三视图 / 主镜 / 道具参考 → 锁定资产（闸门 1）
├── ③ 分镜        Beat → 镜头卡 → 3D 走位
├── ④ 预演        Animatic（第一道贵闸门）
├── ⑤ 生成        镜头墙 + Take 对比
├── ⑥ 成片        时间线（折叠）+ 声音 + 字幕
└── ⑦ 发布        预检 + 发布包

侧边
├── 资产库（角色 / 场景 / 道具 / 音乐）
├── 预算与消耗
└── 设置
```

## 五、阶段式主流程 + 自由工作台

两种模式，默认前者：

### 阶段式（默认）

- 顶部一条阶段进度条，当前阶段高亮。
- 每阶段只露出**该阶段需要的东西**。
- 底部固定"确认条"：`[上一步] [这里可以改…] [确认，进入下一步]`。
- 确认后阶段锁定，可回退（回退会提示下游影响）。

### 自由工作台（进阶）

- 熟练用户可切到"全部展开"：分镜、预览、时间线同屏。
- 入口藏在右上角，不主动推。
- 两模式共享同一份 IR，切换不丢状态。

**关键：默认路径不需要教程；专业能力收进"进阶"。**

## 六、四道闸门的 UI 表达

所有闸门用同一个组件，降低学习成本：

```
┌─────────────────────────────────────────┐
│  资产确认                        3/5 角色 │
│  ─────────────────────────────────────  │
│  [角色卡] [角色卡] [角色卡]              │
│  这次确认会锁定：脸、发型、服装、音色      │
│  之后修改需要重新生成已完成的镜头           │
│                                          │
│  [ 再看看 ]        [ 确认，开始分镜 ]      │
└─────────────────────────────────────────┘
```

三条规则：

1. **说清楚"确认什么"**：这次锁定哪些资产。
2. **说清楚"代价"**：确认后改，会影响多少下游。
3. **永远给"再看看"**：不逼用户做决定。

## 七、时间线放哪

**默认不露。** 折叠在"成片"阶段的"精细调整"里。

理由：

- C 端用户不会用时间线，看到轨道就慌。
- 大多数修改可以用**语义编辑**完成（F7）："这里快一点""把这个镜头换成第二个 Take"。
- 时间线是给"想精修的人"的，不是主路径。

时间线一旦展开，保留专业交互：拖拽、吸附、多轨、快捷键。但它是**第二层**。

## 八、参数面板的四层披露

同一个"光影"，对四个人说四种话：

| 层 | 用户看到 | 例子 |
| --- | --- | --- |
| **L0 结果** | 看片、选 Take | "这版更好" |
| **L1 意图** | 自然语言/滑杆 | "更压抑一点" |
| **L2 参数** | 结构化参数 | 光比 1:4、色温 3200K、85mm |
| **L3 提示词** | 编译后的 prompt | 只给排障用，不默认展示 |

默认停在 L0/L1。L2 给进阶，L3 基本不给。

**这是"摄影语言可量化"（P11）的产品化方式**：量化在底层，用户感知在意图层。

## 九、核心交互组件

### 1. 镜头卡（Shot Card）

分镜阶段的基本单位：

```
┌──────────────────┐
│  [首帧缩略图]      │
│  S03 · 近景 · 2.4s│
│  "她把杯子放下"    │
│  情绪：克制 → 决绝 │
│  [换一版] [编辑]   │
└──────────────────┘
```

一屏 6–8 张，可拖拽排序，可批量操作。

### 2. Take 对比

- 并排 / 滑动对比 / 逐帧对比。
- 显示 provenance（模型、seed、成本）。
- 一键"用这版"，非破坏。

审片台（ADR-0026）把它压成一条动作，规则见 ADR-0027：

- 留用 / 淘汰各写一条 `take.updated`；切换当前镜只是界面状态，不写事件。
- 锁定的镜头只读，要改先解锁。
- 重做按钮永远带价；生成链路没接通时禁用并写明原因，不做假进度。

### 3. 首尾帧编辑器

左右两个画框，中间一条时间轴。改首帧 = 改起点情绪；改尾帧 = 改落点。

### 4. 情绪曲线

横轴时间、纵轴强度，叠在 Beat 上。音乐、表演强度、剪辑节奏都挂在这条曲线上。

### 5. 预算条

始终可见的一条细条：`已用 12.4 / 预算 30 点`。接近上限变黄，超限阻断。

顶栏的金额可以点开，给三行数：已花、**全部重做一遍**、预算。整片报价是逐镜相加，依据写在下面（`12 镜，minimax-h3 @ 768p + 首帧 gpt-image-2-c`）；有镜头报不出价时不给总数，只说明原因——少算一镜的价格比不给更糟。

定妆页也显示同一个金额：出图按单价记进已花；价目表里没有那个模型时，写一行「另有 N 张定妆图没有价目，没算进已花」（ADR-0033）——未知不是免费。`IMAGE_MODEL` 现在是 `gpt-image-2-c`（¥0.12 / 张），新图都带价。

预算可在同一个面板里改：输入新数、点「改预算」，写入 `project.updated`，刷新后还是这个数（ADR-0035）。超预算时顶栏那个数字变 `pick` 色，展开里多一行「超出」。**不弹确认框**：超限的处置是"先提高预算"，不是一次点得动的橡皮章。

定妆页的生成按钮上先报价：`生成三视图 ¥0.48`（四格 × 单价）、`生成主镜 ¥0.12`、`生成参考图 ¥0.12`；价目拿不到时不标价、也不拦，取不到价的时候不猜。

金额左侧偶发两个状态词，都不是装饰：**未保存**（`text-pick`，悬停看原因）表示这次的改动没写进本地日志，界面照常可用但不能以为存住了；**只读**表示另一个标签页正拿着写权，这一页能看进度、不能改（ADR-0034），刷新后才能接管。

### 5.5 分镜页的关键帧（首帧 / 尾帧）

分镜页的画面位置显示关键帧，剪影只是还没生成时的占位。画面下方一条两格缩略条「首帧 / 尾帧」：点哪一格，大画面就显示哪一帧，右边的按钮也变成「生成首帧 ¥0.12」或「重生成尾帧 ¥0.12」（有图后是重生成）。缩略条里还没生成的格子显示剪影，正在生成的格子盖一层"……"。两帧可以同时生成，进度分开记，互不覆盖（ADR-0037 / ADR-0038）。

出图后真图替换剪影；镜头锁定时按钮换成"镜头已锁定 · 只读"。生成失败或超预算时，舞台上沿出现一行 `pick` 色的说明，点名是哪一镜。

出图之后又改过画面输入时，大画面左下角挂`过期`小签，缩略条对应格右上角一个小红点、帧名变 `pick` 色；底部胶片轨那一格左上角也有一枚 `pick` 圆点，不用点进去就知道哪几镜的帧对不上。三处悬停都写清改了哪几项（「首帧出图之后改过：动作、场头，建议重生成」），与关键帧页同一套判据（ADR-0057）。

刷新后默认回到首帧——"刚才在看哪一帧"是临时状态，不写进日志。

### 5.6 一句话指令

下带的输入框回车（或 ⌘⏎）即生效，**是查表，不是理解**（ADR-0039）：现在认得「太暗了 / 太亮 / 换个角度 / 靠近一点 / 拉远 / 手持 / 稳住 / 快一点 / 慢一点」九类说法。

- 亮度类落成补充要求：锚点上方出现一行「补充 整体提亮，补足曝光，阴影保留细节」，同一句说两次不会记两条；
- 换角度轮换机位、靠近 / 拉远紧松一档景别：镜号那一行（"特写 · 仰拍"）当场变；
- 快一点 / 慢一点一档 0.5 秒（"太快了"放慢、"太慢了"加快），镜号行后面的秒数与「重做」的报价当场变，提示词不变；
- 认不出的句子什么都不写，舞台上沿直说「没听懂这句」，并列出认得哪些；
- 成功的指令清空输入框；锁定的镜头输入框不可用。

改的是一条 `shot.updated`，刷新与重放都还在。每条补充是一个虚线小签，右侧 `×` 可以划掉（同样写一条 `shot.updated`）；不能直接编辑某一条，要改就划掉再说一遍。

画面下方还有一块折叠区「这一镜会送出的提示词」：点开显示当前选中那一帧的完整提示词，切换首 / 尾帧时跟着变，只读不可编辑（ADR-0040）。"太暗了"有没有进句子，在这里对得上。

折叠区下面一行 `出场`：每个角色一枚小签，点亮即进这一镜，点灭即移出；紧挨着的 `锚点` 行立刻跟着变（多出或少了谁的三视图），提示词同步。出场顺序就是点名顺序。锁定的镜头与只读标签页上签是灰的；有台词的人不能直接点掉——舞台上沿写「周在这一镜还有台词：先删掉，或去剧本页点他的名字换人，再把他从出场里拿掉。」（ADR-0065 / ADR-0070）。
- 签按**出场顺序**排：已出场的人排在前面，未出场的排在后面。已出场的签里带一对 `‹` / `›`（两人以上才出现）：点一下与相邻的人互换，提示词里的顺序同步变；排头 / 排尾那一侧置灰，锁定的镜头不显示这对箭头（ADR-0077）。

`出场` 下面再一行 `道具`：同一套点签，点亮即把这件道具写进这一镜的 `propIds`，提示词里多一句「道具：…」，锚点里多一张道具参考图（没有参考图时写「缺 道具「X」缺参考图」）。道具没有台词，所以点灭不受限制；锁定的镜头同样置灰（ADR-0066）。道具签同样按出场顺序排，两件以上时每枚带 `‹` / `›` 互换位置（ADR-0077）。`道具` 标签右边一个虚线 `只列本场`：点了只列这一场里出现过的道具（实线框表示正在筛），再点回到全部；本场一件都没用过时写「这一场还没用过道具。点「只列本场」列全部。」默认不筛（ADR-0078）。两排签都在提示词折叠区与锚点之间；900 高的屏幕上多了这一排后要往下滚一点点才看得全。

### 5.7 锁定这一镜

下带「留用」右边是一个描边的「锁定」：**先留用一条 take 才能锁**（不可锁时置灰，悬停说明原因）。最新 take 还没留用时，这个按钮直接改叫「留用并锁」，一次点击写两条事件（`take.updated` + `shot.updated`），不用再回胶片轨找这一镜（ADR-0041 附记）。锁住之后动作整排换成「已锁定 · 只读」与「解锁」，舞台按钮变成"镜头已锁定 · 只读"，一句话指令输入框禁用，补充的 `×` 也不显示（ADR-0041）。锁与解锁各写一条 `shot.updated{locked}`，可回放。胶片轨上锁住的格子右上角带一枚小锁标，不用逐格点开就知道哪些镜已经定了。

注意：留用与留用并锁都会把选中挪到下一格还没定的镜头；要再改这一镜，从胶片轨点回去。

### 5.8 关键帧页（总览）

顶栏「关键帧」进 `/keyframes`：一镜一张卡（9:16 画面、两个按钮、一行景别 / 机位 / 有无帧小字），十二镜一屏看完。页头三个数：`首帧 n / 12`、`尾帧 n / 12`、`关键帧已花 ¥x`——最后一个只算这两类帧的资产，另有没价目的图单列张数（ADR-0042）。

- 卡上「首帧 / 尾帧」两个按钮各自标价（`¥0.12`），有图后按钮名下写"重生成"；生成时画面盖一层"生成中…"，另一帧的按钮同时禁用，一次只跑一帧。
- 两帧都有时点画面在首帧 / 尾帧之间切换，右上角一个小签写「首」或「尾」；只有尾帧时优先显示尾帧。点画面只切显示，不花钱。
- 出图之后又改过画面输入（动作、景别、机位、人物、道具、补充要求，或所在场头的内外景 / 日夜 / 地点），这一帧的画面左下角挂一枚`过期`小签，页头多一个 `过期 n 帧`；小签悬停写「首帧出图之后改过：动作、场头（21:21），建议重生成」——改了几项就列几项，时刻取最后一次改动（ADR-0057）。分镜页同一帧也挂：大画面左下角同一枚小签，缩略图右上角一个小红点，悬停写「出图之后改过：动作，这一帧已对不上」。生成按钮悬停写「画面改过，这一帧已对不上：重生成」。重生成后小签消失。
- 锁定的镜头卡上带锁图标，两个按钮置灰。
- 卡片下方小字 `特写 · 仰拍 · 首✓ · 尾—` 说清这一镜有没有帧，不靠猜。
- 筛子一排：`全部 12 · 缺首帧 10 · 缺尾帧 11 · 两帧齐 1`，点哪个看哪个；计数写在筛子上，空档会写清"想看的帧都已经有了"（ADR-0042 附记）。
- 筛子右边两个批量按钮：`补缺首帧 9 张 · ¥1.08` / `补缺尾帧 9 张 · ¥1.08`（跳过锁定镜头）。点了按镜号顺序一张一张来，进度写 `补首帧 n / m`，旁边「停下」在**当前这张结束后**生效；任何一张失败就停。批量中单卡按钮全部禁用，避免插队。
- 生成走与分镜页同一个动作：同一 job key、同样一条 `asset.updated` + `shot.updated`、同样的预算拦截；刷新后图还在。
- 另一个标签页在编辑时这一页只读：单卡的两个生成按钮一并置灰，悬停写「另一个标签页在编辑：这一页只读」。
- 每张卡再多一个「出视频 / 重拍视频」按钮（有首帧才能点，没有时按钮名下写「先出首帧」），标价按这一镜秒数算（`¥1.44`）；生成中按钮与两个帧按钮一起禁用，画面不换。右上角多一个小签 `▶` 表示这一镜已经有片子，页头多一个 `视频 n / 12` 计数（ADR-0083）。

### 5.8.1 分镜页的视频与多 Take（ADR-0083）

画面下方的缩略条里最左一格始终是「视频」（没有片子时虚线框、点了进去也能导入）：点它大画面换成播放器（`<video>`，带原生控件、循环、用首帧当封面），再点首帧 / 尾帧就切回静帧。还没有片子时大画面写「这一镜还没有片子：出一次视频，或在下面贴一条地址」。第一次出片后，缩略条下面多一排 `TAKE 1 · 留用 / TAKE 2 · 待定` 签：点哪一拍看哪一拍，没有地址的拍显示但不可点；留用 / 淘汰仍然只作用于最新一拍。

「视频」这一档右边是「出视频 / 重拍视频」按钮，报价按这一镜秒数 × 每秒价；报价拿不到时只写动作，不写金额。按钮下面是折叠的「贴视频地址导入」：贴 `https://…` 或 `data:video/…` 回车，就把这条地址当一拍 take 挂上来，不花钱、不改首尾帧（配额不通时的兜底）。出片失败时页面顶上一行红字：`「SH-03」没出片：<供应商原因>。可以先「贴视频地址导入」顶上。` 服务端说这次失败「重交安全」时，客户端自动再试，最多 3 次：顶上一行写 `「SH-03」第 1 次没出片：<原因>。正在重试（2/3）…`，出片中的状态写 `第 2 次尝试`。超时、轮询中断、连接断开都不自动重交——任务可能还在跑，界面会劝先去供应商后台确认，免得多花一笔（ADR-0097）。

底部胶片轨的「重做」从禁用变为可用：有首帧就能按这一镜重拍一条，报价按秒算，没有首帧时禁用并写「先出首帧」；轨道条每格右下角有 `▶`，代表这一镜至少有一拍片子。锁定的镜头与只读标签页上这些入口都不给用。

### 5.8.2 分镜检查（ADR-0096）

顶栏「预演」左边是「检查」，有错误或提示时右上角带数量（`pick` 色）。点开右侧抽屉 `分镜检查`：

- 顶部四格：覆盖率、已覆盖拍数 / 总拍数、错误、提示。覆盖率的定义写死为「每一拍同时有信息镜头与情绪 / 反应镜头」。
- 当前镜一行：节拍与镜头目的两个下拉，选项带一句人话任务（`铺垫 · 交代人物、关系、目标`）。值是推断来的时，下面写「这一镜的节拍与镜头目的还没有手动标注：先按镜序推断，改了才会写进项目」；改一个字段，这条提示就只提另一个。
- 节拍列表：按场次列每一拍，写镜号区间、时长、`信息 + 情绪` 或 `缺信息 / 缺情绪`；点一行跳到这一拍第一镜。
- 校验列表：`V1` / `V2` / `V4` / `V5` / `V6` / `V8`、人话说明、`去 SH-xx` 跳转；多镜问题写共几镜。V4 是错误，其余是提示。
- 底部如实写：V3 轴线、V7 切率曲线、V9 模型能力还没查；覆盖率不评价故事好坏。
- 改节拍或目的写一条 `shot.updated`，刷新还在；锁定镜头拒绝并写「这一镜已锁定，先解锁再改节拍或镜头目的」；只读标签页不能改。抽屉打开时不响应 ← → 换镜，Esc 或点遮罩关闭。

### 5.8.3 一致性体检（ADR-0097）

顶栏「检查」左边是「体检」，有待复核或不达标镜头时右上角带数量（`pick` 色）。点开右侧抽屉 `一致性体检`：

- 顶部四格：平均分、通过、待复核、不达标。有还没出片的镜头时补一行「n 镜还没有 take：只算了锚点准备度，不判定成片一致性」。
- 当前镜：`SH-07`、结论签（通过 / 待复核 / 不达标 / 未出片）、景别与通过线、总分；下面五行分数条——身份 / 服化道 / 场景 / 风格 / 溯源。某一维不适用时显示 `—`，不按 0 分算。
- 问题区：这一镜缺什么、怎么补。例如「「周」只有三视图，没有表情 / 服装参考：3 条不可变特征没有可对照的图」+「在定妆页给「周」补一张表情或服装参考图」；老 take 会写「这一拍没有记录参考图」与「没有 seed 记录：供应商接口目前不支持固定 seed」。
- `需要看的镜头`：待复核 + 不达标按分数从低到高排列，写镜头号、景别、最弱维度、分数 / 通过线；点一行跳到那一镜。
- `未测`：光影、空间、表演 / 动作三项与原因；底部写清「查的是结构化锚点与溯源，不是人脸或像素相似度」。
- 体检只读，不写日志；与「检查」抽屉互斥，打开一个会关掉另一个；抽屉打开时不响应 ← → 换镜，Esc 或点遮罩关闭。

### 5.8.4 设置页的能力矩阵（B12 / H16，ADR-0098）

`/settings` 的「模型」下面是「能力矩阵」，读的是**已保存的配置**，保存后自动刷新；右上角「刷新」可手动重读。

- 顶部一行：`5 个模型 · 已保存配置 · 5 个商用条款未确认`。条款未确认数用 `pick` 色。
- 按文本 / 图像 / 视频 / 配音 / 识别分组，每组下每个模型一张卡：显示名、单价（`¥0.12 / 张 · gpt-image-2-c`；查不到时写「单价未知」+ 原因）、能力事实、商用条款、匹配到的 S1 报告。默认模型带「默认」小签。
- 能力事实只写代码实际发送的字段：视频首帧支持、尾帧 / 多参考图 / seed / 音频输入不支持、1–8 秒；图像不收参考图；文本 JSON + 16000 `max_tokens`；配音 mp3、无语速情绪；识别 multipart + `verbose_json`。并发 / 延迟 / 上下文窗口这类没测过的标「未测」，颜色更淡。
- 商用条款来自每个模型行新加的「商用条款 / 备注」输入框；没写时卡片显示「未确认 · 需人工核对供应商条款」。
- S1 报告：按模型名匹配最近一次测绘，写尝试数、通过数、花费与失败码（`deadline_exceeded×1`）。视频报告的分辨率与当前配置不同时，后面用 `pick` 色写「报告是 768p，本模型配的是 720p」；没有报告的模型写「S1 · 还没有这个模型的测绘报告」。
- 矩阵下方「S1 测绘报告」列最近 5 次：时间、`视频模型 @ 分辨率 + 图像模型`、通过数 / 尝试数、花费、失败码；空时写「运行 pnpm probe:s1」。
- 底部如实写：只读本地 `artifacts/s1` 汇总字段，不读密钥 / Base URL / 逐镜报错；失败码不是质量评分。矩阵不参与路由或降级。



顶栏「剧本」进 `/script`：按场次与场内镜序摊平，每镜先动作、后台词，最后一行技术信息（`特写 · 仰拍 · 2.4s`）。页头四个数：场 / 镜 / 台词条数 / 总时长（ADR-0043）。

- 场头一行：`⠿ 第 1 场 [内 · 夜] 走廊`，右侧 `7.9s · 3 镜`。方括号里的小签可点，就地变成三个下拉——内外景 · 日夜 · 地点，边改边生效；点编辑器外面收起（ADR-0050 / ADR-0056）。地点下拉只列已有地点；要加新的，去定妆页的`新建地点`（ADR-0059）。
- 场号可点改：`第 1 场` 点开变成输入框 + `存` / `取消`，`Enter` 保存、`Esc` 取消、点外面收起；写 `2A`、`12B` 这类 1–4 位字母数字，**清空即回到按顺序编号**。输入旁边写「1–4 位字母数字；空着按顺序编号」，不合格或与别的场重复时红字贴在输入旁边（「场号只能是 1–4 位字母数字，比如 2A。」「已经有「2A」这一场了。」）（ADR-0080）。
- 场号跟场走：挪场次后，写了场号的那一场还是原来的场号（`2A` 挪到第二位仍是「第 2A 场」），没写场号的按新位置显示「第 N 场」；导出、`挪到…` 下拉、跨镜移台词的目标标签都跟着换。只读标签页场号不可点。
- 场头改动过时，下面多一行折叠 `改过 2 次 · 上一版 内 · 夜 · 走廊`；展开是按时间倒序的各版（`21:09 内 · 夜 · 桌边`），每版一个`用这版`，与当前相同的那版置灰；`最初`单独一行。恢复写一条 `scene.updated`，不抹掉历史（ADR-0058）。
- 场头行最左一个 `⠿` 手柄：按住拖到另一场上松手，这一场就落到那一场的位置（中间各场顺次补位），只写一条 `scene.moved`；拖动中源场变淡，目标场描一圈 `pick` 色（ADR-0080）。只有一场或只读标签页不显示手柄；触屏与键盘仍用 `↑` / `↓` / `挪`。
- 场头行右侧 `n.ns · m 镜` 后面两个小钮 `↑` / `↓`：一次挪一位，第一场的 `↑`、最后一场的 `↓` 置灰；挪完场号按新顺序连续重排（写了显式场号的场次除外，见上），全局镜号（SH-01…）跟着重算，台词 / take / 帧 / 场头历史都按 id 挂着不动（ADR-0060）。只读标签页不显示这两个钮。
- `↓` 旁边第三个钮 `挪`：点了就地变成一个场次下拉（`挪到…` + 除本场外的每一场，写 `第 N 场`），选完这一场直接落到那一场的位置，中间各场顺次补位；只写一条 `scene.moved`，长片从第 8 场挪到第 2 场不用连点六次（ADR-0060 附记）。下拉失焦或按 Esc 收起，不改任何东西。只读标签页不显示 `↑` / `↓` / `挪`。
- 每场末尾一个虚线 `＋ 加一镜`、整页末尾一个通栏虚线 `＋ 加一场`（只读标签页都不显示）：新场出现在末尾，地点 / 内外景 / 日夜沿用前面那一场（一场都没有时是第一个地点 · 内 · 日），以 `第 N 场 内 · 日 地点 0.0s · 0 镜` 出现，场头照旧可点改；新镜写 `（这一镜还没有动作描述）`、默认 `中景 · 平视 · 3.0s`，计入页头镜数与时长（ADR-0064 / ADR-0069）。一场都没有时，正文先写一句「还没有场次。下面加一场，从场头与第一镜开始写。」
- 场头行最右一个 `删`：点了原地变成 `确认删` 或 `确认删 N 镜` 与 `取消`。删一场会先把它里面的镜头逐条删掉，再删场；场号立刻连续重排。这一场里有锁定的镜头时不删，场头下面一行红字写「这一场里的第 N 镜（SH-0N）已锁定：先解锁再删这一场。」（ADR-0067）。
- 每镜技术行下面一个 `删这一镜`：同样两步确认（`确认删` / `取消`），旁边写「删这一镜，台词与 take 一起删」。锁定的镜头这个钮置灰，悬停写「这一镜已锁定，先解锁才能删」。删掉当前这一镜时，分镜页的选中挪到下一格（没有下一格就退回上一格）。删光了不报错：分镜页写「还没有镜头。去「剧本」页加一场，再回来点名出场、生成关键帧。」（ADR-0067）。
- 删完镜头或场次，页头多一行「刚删掉 镜 SH-01」（场次写「刚删掉 第 N 场」）+ `撤销`：点一下把它和它的台词、take 一起按删除之前的样子放回来，镜头选中跳到这一镜；日志里追加补偿事件，不抹掉删除记录。撤销的是"最近一次还缺着的删除"——撤完这一条，这一行会换成更早的那一条；放回场次再放回它的镜头，正好是删除的逆序（ADR-0076）。只读标签页不显示这一行。
- 需要插在中间时：每镜 `删这一镜` 右边是 `＋ 插一镜`，点一下就在这一镜后面插一镜，后面几镜的镜号顺次后移；每场末尾 `＋ 加一镜` 右边是 `＋ 插一场`，点一下就在这一场后面插一场空场，后面的场号顺次后移，新场的地点 / 内外景 / 日夜沿用被插的那一场（ADR-0068 / ADR-0069）。两个都是虚线小签，与「加在末尾」的 `＋ 加一镜` / `＋ 加一场` 分得开。
- 镜号缩窄列（`SH-01`），动作正文 13px、行距略松；台词缩进在一条细竖线里，说话人小字在上、台词在下。
- 台词小字带时长：`周 · 2.1s`，旁边一个「改」（ADR-0044）。点开就地变成文本框，`保存` / `取消`，⌘↩ 保存、Esc 取消；说明一行「时长按 0.3 秒 / 字重估，镜头跟着挪」。
- 保存后：台词行与镜头技术行的时长同时变，页头总时长跟着变；日志里落两条事件（`dialogue.updated` + `shot.updated`）。
- 改过的台词下面多一行折叠：`改过 n 次 · 换过 m 次人 · 上一版「…」`；展开是按时间倒序的版本，`换人`一段写 `时间 周 → 林` 并带`换回`，最后一行是`最初`那版。不另建版本表，读的是事件日志（ADR-0044 附记 / ADR-0052）。
- 每一版后面一个`用这版`：点一下把文本与那一版的时长一起写回，镜头跟着挪；与当前文本相同的行置灰。回退是追加一条新版本，不抹掉历史。
- 每句台词旁还有`删`：点了变成`确认删 / 取消`；删掉后镜头时长减这一句（ADR-0045）。
- 说话人小字可点：变成下拉，选完立刻换人（一条 `dialogue.speaker.updated`，文本与时长不动，ADR-0046）。
- 每镜技术行下面还有一排 `出场`：这一镜里谁在场（没有出场人物时不显示）。点名字就地变成下拉 `换下 林 →`，选谁就把这一镜的这个人换成谁：出场顺序保持原位，这一镜里他说的台词说话人一起换过去（一次写 `shot.updated { characterIds }`，每条台词各一条 `dialogue.speaker.updated`，ADR-0070）。换上的人本来就在这一镜里时并成一位。锁定的镜头与只读标签页上这些签是灰的，悬停写「这一镜已锁定，先解锁才能换人」；换人被拒的原因贴在这一镜下面。这一镜已经出过首帧或尾帧时，下拉旁边写「换人后已出的帧会挂过期」（ADR-0081）。
- 换完人，这一镜下面多一行「刚把「周」换成「林」」+ `撤销`：点一下出场顺序与这一镜的说话人一起换回去；有帧时后面补一句「已出的帧挂了「过期」」。撤销只留最近一次，刷新或切页就没了；锁定的镜头撤不了，换完之后又被改过说话人的句子不动（ADR-0081）。
- 一镜里有两句以上时，每句后面多 `↑` / `↓`：一次挪一位，到顶到底置灰；单句镜头不显示箭头（ADR-0047）。
- 每句台词旁还有`移`：点了变成目标镜头下拉（`SH-03 · 第 1 场`，不含本镜），选完这一句就去那一镜的队尾；源镜与目标镜时长一减一加，页头总时长不动（ADR-0054）。锁定镜头置灰。
- 镜头台词下面一行 `这一镜的顺序改过 n 次`：展开是倒序的顺序版本（`时间 门开着呢。/ 谁在那儿？`），带`用这版`；旧版本里含已删句子时按钮置灰。句子有进出（加句 / 删句 / 跨镜头挪）不算一次「换顺序」（ADR-0053 / ADR-0054）。
- 镜头下面还有一行 `删过 n 句`：展开倒序，每行 `时间 带删除线的正文` + `恢复`；恢复把这一句原样（同 id、同说话人、同长度）放回这一镜队尾，镜头与全片时长加回。已经恢复过的记录按钮置灰，锁定镜头置灰（ADR-0055）。
- 每镜台词末尾有`+ 加一句`：点开是说话人下拉（这一镜里有谁排前面）+ 文本框；保存后镜头时长加这一句。锁定镜头两者都置灰。
- 锁定的镜头：技术行后缀 `已锁定`，「改」置灰，悬停说明先解锁。
- 顶栏`导出`把这一页打成纯文本下载，文件名 `标题-v版本.txt`：标题与版本、四数页头、场头、`SH-xx · 景别 · 机位 · 时长`、动作、缩进的`角色：文本`（ADR-0048）。导出不写事件，日志不变。
- 动作整段可点：点了就地变文本框，`保存` / `取消`，⌘↩ 保存、Esc 取消；改字不动时长（一条 `shot.updated { description }`，ADR-0049）。锁定镜头与只读标签页不可点，悬停说明原因。
- 改过的动作下面有 `改过 n 次 · 上一版「…」` 折叠：展开按时间倒序，每行全文 + `用这版`，最后一行是`最初`；回退是一次新的改写（ADR-0051）。
- 场次的地点仍只在场头下拉里改；场号在「第 N 场」上就地改（ADR-0080）。
- 分镜页改过的时长、机位，刷新这一页就同步；整片镜号一致（第二场第一镜是 SH-04，不是 SH-01）。

### 5.10 预演（ADR-0084）

分镜页顶栏的 `▶ 预演` 打开一个全屏覆盖层，把整条片子按镜头时长一张张放过去：

- 大画面：这一镜有片子就放 `<video muted autoPlay loop>`（封面用首帧），否则首帧，其次尾帧，都没有就出场景占位图并挂 `没图 · 占位`。
- 字幕跟着这一镜的台词走；画面左上角是 `SH-xx · 第 n / m 镜 · 全长 秒数`，右上角标签写 `这不是成片`。
- 右侧一栏说明「关键帧按镜头时长一张张过……」，并列出全长、镜数、有片子的镜头数、还没有画面的镜头数，以及 `还没有配音：这一版是默片预演`。
- 控制：`播放 / 暂停`、`上一镜`、`下一镜`；空格暂停，`←` `→` 切镜，`Esc` 退出。播到头停住，给 `再看一遍`。
- 底部一条按镜头时长分宽的进度条：每一镜一段，点哪段跳哪段；没画面的段用虚线。
- 预演只读现成的帧与片子：不生成、不写事件、不改项目，也不锁分镜（ADR-0009 的闸门等配音齐了再接）。
- 已经配好音轨的镜头会按台词顺序把音轨放出来：暂停时音轨真停，切镜从新一镜的第一句念起；一句都没有的版本仍是默片（ADR-0085）。右栏相应改成「有配音的镜头 n 个（其余是默片）」。

### 5.11 声音页（ADR-0085）

顶栏的「声音」打开配音页，一句台词一行：

- 页头写「一句台词一条音轨。音轨挂上之后按它的真实时长校正镜头——镜头服从配音，不是反过来。」右侧三个数：已配 n / m 句、台词总长、已配有声时长。
- `谁的声音`：每个角色一行，一个音色输入框（回车或失焦保存，Esc 还原），右边 `已配 n / m 句`。空着用服务端默认音色；输入框占位符写默认音色名。没有配 TTS 模型时，这一段右侧如实写「还没配配音模型：服务端加上 TTS_MODEL 后才能出声，现在可以先贴自己的音轨」。
- `一句一句配`：按镜头顺序列出每一句——`SH-xx`、角色名、IR 时长（有音轨时再写「音轨 x.xs」）、`有声` / `还没配` 标签、台词正文。
- 已配的句子下面出现播放器（`<audio controls>`），浏览器读出时长后自动把 IR 里的台词与镜头校正到真实时长（差不到 40ms 就不写，避免日志抖动）。
- 每行右下角 `出声`：让供应商念这一句；已有音轨时写 `重配`，换掉这一句的旧音轨，不累积成 take。没配模型时按钮禁用，悬停说明原因。出声失败时页头红字写「「SH-01 · 周」这句没出声：<供应商原因>。可以先「贴一条音轨」顶上，或稍后再试。」
- 每行还有一个 `识别`（ADR-0087）：把这一句的音轨送去 ASR，结果先放在虚线框里——标「识别结果」、模型名、段数，下面是文字与 `用这句替换` / `忽略` 两个按钮。替换只改文字，时长与镜头不动（音轨才是时长的准）；忽略直接收起，不写日志。没配 `ASR_MODEL` 时按钮禁用并写「还没配识别模型」；没有音轨时也禁用，悬停说明先配一条。
- 识别失败时页头红字写「「SH-01 · 周」这句没识别出来：<供应商原因>。」，不留下半条结果。
- 每行还有 `贴音轨`：单行输入贴 `http(s)://` 或 `data:audio/` 地址，回车或点 `贴上` 即挂上，供应商不通时靠它收工。
- 锁定的镜头不出声、不贴音轨（提示先解锁）；只读标签页能看不能改。音轨存在本地事件日志里，刷新不丢。

### 5.12 成片页（ADR-0086）

顶栏的「成片」打开时间线。这一页回答的是「整条片子现在长什么样」，不是「某一镜该怎么改」。

- 页头一句话：「初剪按剧本顺序排好每一镜；换 take 之后，这里的时间线就是最终决定。」右侧五个数：全长、片段数、字幕条数、没画面片段数（有缺口时红字）、有配音的镜头数。
- 时间线为空时给出空状态：说明初剪的选 take 规则，一个主按钮 `自动初剪`；下面写「已经有 take 的镜头 n / m」。没有可用 take 时按钮不假装成功，页头红字说清「一条能用的 take 都还没有」。
- 有片段时左侧是 9:16 播放器：有视频放视频（静音），没有就定住首帧 / 尾帧，三样都没有就是斜纹占位并写镜号。字幕按当前台词覆盖在下方；安全区参考线默认显示，可关。左上角标 `SH-xx · n 版`，锁定镜头右上角标「已锁定」，画面右下角常驻「AI 生成」角标（ADR-0090，不可关，不挡播放）。
- 播放条：`播放 / 暂停`、`重来`、`安全区` 开关、`当前时间 / 全长`，下面一条可拖的进度条。播放是 50ms 一跳；对白音轨在每句的起点触发。切走页面不会继续放。
- 右侧时间线轨道按片段时长分宽：点哪段跳到哪段并选中。没画面的片段用斜纹，选中的片段用暖色。轨道下面写「剧本里还有 n 镜没进时间线」「n 个片段三样都没有」。
- 轨道下面是字幕 lane（ADR-0087）：每条 cue 按自己的时长分宽，播放到哪条哪条亮，点一下跳到那一句的起点；右侧「每行字数」下拉（12 / 16 / 20 字，默认 16），切档立刻重排。下面一句小字说明「按标点断句，时间按字数分」。
- 选中片段后出现「SH-xx 用哪一版」：这一镜全部 take 排成按钮，写「第 n 版 · 留用 / 草稿 / 已淘汰」与「无视频」；当前版本与已淘汰的按钮禁用。下面列这一镜的台词：绝对时间、角色、正文、断成几行、有没有声。换 take 写一条 `timeline.updated`，起点与其它片段不动。
- 导出区：字幕样式下拉（默认 / 大字）、标题、话题、简介；下面依次是「导出前检查」与五个按钮 `导出成片 MP4`、`导出预览 HTML`、`导出 .otio`、`导出字幕 SRT`、`导出发布包`。每次导出在按钮下方留一句结果（文件多大、还缺什么），发布包会把 `warnings` 原样说出来。
- 导出前检查（ADR-0095）：四项逐条写状态与说明——AI 标识、内容安全、素材授权、平台规格；右上角写「通过 / n 处待确认 / n 处阻断」与 8 位内容指纹。命中项列出位置、命中词、上下文与建议；有 review 时出现确认勾选，勾选才放行；改标题 / 简介 / 话题或项目内容后指纹变化，确认自动失效，五个导出按钮重新禁用。硬阻断没有确认框，必须改文案。
- `导出成片 MP4` 是主按钮：点击后按钮变「正在渲染 MP4…」，下面依次写「正在排版字幕与占位画面…」「正在提交渲染任务…」，随后每秒刷新「排队中（第 n 位）…」或「编码中（n 段） · 42%…」；完成写文件大小、分辨率、占位片段数与未下载的远端素材数；失败把 ffmpeg 的最后几行带回来。有片段时才可点（ADR-0091 / ADR-0093）。
- 导出预览 HTML 的画面右下角同样有「AI 生成」角标，`<head>` 带 `<meta name="ai-generated" content="true">` 与 `<meta name="ai-label-standard" content="AI生成">`。导出区下方写明标识不可关闭：预览角标、HTML 元数据、OTIO 元数据、发布包 `aiLabel` 与成片 MP4 都会带上（ADR-0090）。
- 页面底部如实写成片 MP4 的边界：1080×1920、H.264、带字幕与「AI 生成」角标，提交后进入渲染队列、同一时间只跑一条；远端素材只从 `RENDER_ALLOWED_HOSTS` 白名单域名下载，取不到时用首帧或占位图顶上并计数；发布包仍是清单，不含视频文件（ADR-0092 / ADR-0093）。

### 5.13 故事页（ADR-0088 / ADR-0089）

顶栏的「故事」打开 `/story`。这一页回答的是「这台机器能不能从一句话或一段现成文本开始」，不是「怎么改已有项目」。

- 页头一句话：「一次生成会同时给出 logline、人物弧光、地点、场次与分镜初稿；看过之后再决定要不要拿它开工。生成不写项目，确认才写。」右侧写当前项目的「n 场 / m 镜」与文本模型下拉：下拉空值显示「默认 · <模型>」，选了只影响当前浏览器（ADR-0094）。
- 页头下面两个标签：`从想法开始` / `导入剧本 txt`。切换清掉上一份草稿，但保留两边的输入；导入标签右侧写「选一个 txt 或粘贴原文，模型把它改成一条 60–90 秒单集。会保留人物关系、核心冲突与结局，允许合并次要人物与场次；不是逐字导入。」
- 想法模式：`一句话 / 大纲` 文本域（2000 字，右下角实时字数），下面三条示例想法，点一下填进去；右侧 `生成故事` 在没写内容、没配模型或正在生成时禁用。
- 导入模式：`剧本文本（txt）` 文本域，右上角 `选择 txt 文件`（选完显示文件名；UTF-8 / GBK 都认，文件上限 2 MB），下方写「目标是 60–90 秒单集：会压缩与合并，原文不会原样保存。文字会作为一次模型请求的输入发给文本供应商。」与 `n / 20000` 字数；再下面是必勾的「我确认有权使用这段文字（原创或已获授权）」。超过 2 万字或没勾选时按钮禁用，并写明原因。按钮写 `改编成剧本`。
- 题材四个按钮 `都市逆袭` / `甜宠` / `悬疑` / `家庭伦理`，两种模式共用。生成中按钮写 `正在生成…`，下方一行「正在让 <model> 写故事、拆场次与分镜，通常要 40–100 秒。不要关页面。」（导入模式写「读剧本、合并场次并拆成分镜」）。没有配置文本模型时按钮禁用，并写「还没配文本模型：服务端在 secrity.env 里加上 TEXT_MODEL 之后才能生成。断句、场次与时间线仍然可以手改。」；也可以点下拉里的「配置文本模型」去 `/settings`。；失败时同一位置红字给原因。
- 结果先给标题、`由 <model> 生成` / `由 <model> 改编`、logline、梗概与题材 / 受众 / 基调标签，导入稿多一个「改编稿 · 原文 n 字」标签；右侧六个估数：人物、地点、场次、镜头、台词、估时。估时按台词 0.3 秒 / 字 + 每镜 1 秒表演余量、空镜 5 秒算，和开工后写进项目的时长一致。
- 逐段展示：`人物与弧光`（身份、可拍外形、want / need / wound / flaw / secret / agency、这一集弧光）、`关系张力`、`地点与道具`、`钩子`（开场 / 结尾）、`场次与分镜初稿`（SH-xx 全局编号、场景与日夜、每镜描述、景别 · 机位 · 运镜 · 焦段 · 时长 · 出场人物、台词）。
- 底部写清草稿只存在内存里，刷新即丢；`用它开工` 先变成 `确认开工` / `再想想` 两个按钮，确认后才写一条新的 `project.created`，当前项目被整条换掉，旧事件仍留在本地。成功后跳到 `/script`，直接看新项目的场次、镜头与台词。导入稿的 provenance 只写文件名、字数与正文前 300 字，不把原文塞进日志。
- 另一个标签页在编辑时整页只读，按钮换成「另一个标签页在编辑：这里只读。」
- 没配模型、读文件失败、超过字数、没勾权利、生成失败、结构不合规都如实写在输入区下方，不把 403 或半截 JSON 伪装成成功。

### 5.14 设置页（ADR-0094）

顶栏右侧「设置」打开 `/settings`，管的是「这台机器接哪家、用哪个模型」，不是某个项目的内容。

- 页头一句话：「可配多个供应商，每种模态可配多个模型并指定默认。密钥只写进本机配置文件，不会出现在页面或接口返回里；页面顶栏的选择只影响当前浏览器。」右侧写供应商数与模型数。
- 下面是配置文件路径与状态标签：`已落盘 · 0600`，或 `尚未落盘 · 当前由 secrity.env 生成`。未落盘时多一行说明「第一次保存之前，这一页显示的是环境变量里的配置；保存后会以配置文件为准。」
- 供应商卡片：名字、Base URL、API Key（`type=password`，已保存时占位写「已保存，留空沿用」/「沿用 secrity.env 的密钥，输入可覆盖」）、视频接口（跟随环境 / treecloud / litellm）。第二行 `探测`（只读 `GET /v1/models`，不花钱；新供应商要先保存）与 `删除`（旗下还有模型时拒绝并说明）。卡片底部一行：密钥状态、`清空密钥` / `取消清空`、供应商 id、探测结果。
- 模型区按五种模态分组。每组标题写模态名、用途、数量与 `+ 添加`；没配时写「没配。需要用到时再到这里的加一个。」
- 每个模型一行：供应商下拉、模型名、显示名（留空自动用「供应商 / 模型名」，占位写「自动」）、视频多一个分辨率、配音多一个音色、`默认` 单选、`删除`。每模态第一个模型自动成为默认；删掉默认后自动落到同组下一个。
- 保存按钮在校验失败时就地写原因：供应商缺名字、Base URL 不是 http(s)、模型缺供应商或模型名、同一供应商同一模态下模型重复、某模态有模型但没默认。成功写「已保存。各阶段的顶栏下拉会立刻用新配置。」，同页立即换成返回的脱敏配置。
- 页面底部写明：怎么在页里切换、密钥安全（接口只回「有没有」、文件 0600 / 目录 0700、改完不用重启）。

### 6. 定妆台

定妆阶段的整页形态（ADR-0028），不是弹窗：

```
定妆
先把脸和空间钉住，再谈镜头。
5 / 7 已锁定  ────────────────────────────

人物 · 三视图
林  ▪ 已锁定        正面  3/4  侧面  背面        8:59 锁
短发，深色外套      [ ]  [ ]  [ ]  [ ]           [解锁]
不许变
左眼下的痣
齐肩黑发，中分

场景 · 主镜
走廊  ▪ 已锁定      [master]  同一场的所有镜头都带这张图  [解锁]

道具 · 参考
搪瓷杯  ▪ 可锁定     [ref 1]  在镜头里出现，就要有一张参考图  [锁定道具]
白底蓝边            ↑ 锁住后，带它的镜头都引这一张
```

- 人物按"四格"排：正面 / 3-4 / 侧面 / 背面，各是一张独立的图；缺格的角色显示"缺 N 格"，锁定按钮禁用。
- 人物行有一个"生成三视图"：逐格生成，当前格盖一层"生成中…"，落一张换一张真图（ADR-0031）；锁定的角色没有这个按钮。
- `人物 · 三视图` 标题右侧一个 `新建人物`（只读标签页不显示）：点开是虚线框内联表单——名字输入 + 外形描述框（选填，200 字以内）+ `创建` / `取消`，Esc 收起。新建的人从四格空白开始，三视图随后逐格生成；外形描述整句进提示词（ADR-0071）。
- 每个角色名旁一个 `改`：点开就地变成名字输入 + 外形描述框 + `保存` / `取消`。外形留空时卡片写「还没写外形描述。」；改的是名字或描述，三视图与参考图不跟着变（ADR-0071）。
- 名字 / 外形改过之后，描述下面多一行灰字 `改过 2 次 · 上一版「周 · 高个，衬衫袖口卷起」`：点一下展开历史（提到 `收起历史`），最新的在上、`最初` 在最后，每行 `时间 · 名字 · 描述`，当前正在用的标 `正在用`，其余右侧有 `用这版`。`用这版` 把名字与描述整版一起写回（一条普通 `character.updated`），历史里多一版，可以再退回来；只读标签页能看历史但没有按钮。只改「不许变」、换参考图不算一版。地点与道具用同一套（ADR-0082）。
- `不许变` 清单每条右侧一个 `×`（悬停写「划掉「X」：从之后的每一张图里去掉了」），清单下 `＋ 加一条` → 单行输入（回车保存 / Esc 取消，60 字上限，最多 20 条）；空清单时写「还没写：痣、疤、发型分缝这些必须原样带进每一张图。」整份替换，日志一条 `character.updated { mustNotChange }`；已出的三视图不标过期（ADR-0074）。
- 四格下面一排 `参考`：`referenceImages` 里的图（表情表、服装变体、手拿道具）逐张排开，从 `ref 1` 数；每张右上角一个 `×` 摘掉（只读不显示），右边虚线 `＋ 挂一张` → 单行输入贴地址（`http(s)://` 或 `data:image/`，最多 8 张，重复地址拒绝）。挂一张写两条事件：`asset.updated`（`source: upload`）+ `character.updated { referenceImages }`；摘掉的图留在资产里，可以再挂回来。空时写「还没有参考图：表情表、服装变体、手拿道具都挂在这里。」（ADR-0079）
- 名字旁还有一个 `删`（只读标签页不显示）：点了变成 `删这个人？` + `确认删` / `取消`。还在镜头出场里时拒绝，页头写「「林」还在 1 镜的出场里：先去分镜页把他点掉（有台词的要先换人）。」；还有台词时写「「林」还有 2 句台词：先删掉或换人。」。删不掉时确认块也收起——原因在页头，那一行修不了；三视图不随删除清理（ADR-0073）。
- 场景只排一张主镜，旁边一句说明它为什么会被每个镜头引用；旁边一个"生成主镜"，出的是空镜，锁定的场景没有这个按钮（ADR-0032）。
- `场景 · 主镜` 标题右侧一个 `新建地点`（只读标签页不显示）：点开是虚线框内联表单——名字输入 + 模板下拉（走廊 / 门口 / 桌边 / 门厅）+ 描述框（选填）+ `创建` / `取消`，Esc 收起。描述会进主镜提示词（ADR-0063）。新地点立刻多一行，还没挂场次时状态词写`未挂场次`、副标题写`主镜 · 还没挂场次`，不冒充必锁项；到剧本页把它挂到场上之后，状态词变`缺 主镜`并计入应锁数（ADR-0059）。
- 每行地点名旁一个`改名`：点开就地变成名字输入 + 模板下拉 + `保存` / `取消`。只写真正变了的字段；什么都没改时直说「地点没改。」不收按钮（ADR-0059）。
- 地点行中间那栏是场景描述：有描述时直接显示，没有时显示灰字 `＋ 写一句这地方长什么样`，点一下就地变成三行文本框（`保存` / `取消`，Esc 收起），下面一行提示「整句进主镜提示词：空间、陈设、光线，200 字以内」。描述整句进主镜提示词，留空则只按名字画（ADR-0063）。名字 / 描述改过之后，下面同样有「改过 n 次 · 上一版」与可展开的历史（ADR-0082）。
- 主镜缩略图左下角挂 `过期`（与关键帧同一套）：场景描述在主镜出图之后改过时出现，悬停写「主镜出图之后改过：场景描述（21:21），建议重生成」；重生成后消失。改名字、换模板不挂（它们不进主镜提示词，ADR-0075）。
- 名字旁还有一个`删`：点了变成`确认删` / `取消`，确认后整行消失，日志留一条 `location.removed`；已经生成的主镜图不随删除清理（ADR-0061）。还有场次在这个地点时，确认块里多一个「先搬到哪里」的地点下拉，主按钮改叫`搬过去再删`，确认后这些场次整批换到所选地点再删（ADR-0062）；被占用又没有别的地点可搬时`删`置灰，悬停写「先新建一个地点」。
- 道具一行一张参考图，带一个"生成参考图"；被镜头引用（`Shot.propIds`）的道具算必锁项，没被引用的仍显示，但不计入进度（ADR-0030）。锁定后不能再生成（ADR-0032）。生成是**往后挂一张**，不覆盖已有的 `ref 1`；`ref 1` 大图右上角一个 `×` 可以摘掉，旁边的 `参考` 排（`＋ 挂一张`）与人物同一套，可再挂多张（ADR-0079）。
- `道具 · 参考` 标题右侧一个 `新建道具`（只读标签页不显示）：点开是虚线框内联表单——名字输入 + 描述框（选填，200 字以内）+ `创建` / `取消`，Esc 收起。描述整句进提示词；新道具参考图待生成，先显示`缺参考图`（ADR-0072）。一件道具都没有时列表处写「还没有道具。上面新建一件，再到分镜页把它点进出场。」
- 每件道具名旁一个 `改`：点开就地变成名字输入 + 描述框 + `保存` / `取消`。描述留空时卡片写「还没写道具描述。」；参考图不跟着变（ADR-0072）。名字 / 描述的历史与人物同一套（ADR-0082）。
- 每件道具名旁还有一个 `删`：点了变成 `删这件道具？` + `确认删` / `取消`。还在镜头里时拒绝，页头写「「台灯」还在 1 镜里：先去分镜页把它点掉，再删。」；确认块同样收起，参考图不随删除清理（ADR-0073）。
- 定妆页删掉人物 / 道具 / 地点之后，页头多一行「刚删掉人物「阿棠」」+ `撤销`：点一下整份放回来（原 id、名字、描述、「不许变」清单与已出的图都还在），日志追加补偿事件。撤的是最近一条还缺着的删除；再点一次就是更早的那条。场次与镜头的撤销在剧本页，不在这一行（ADR-0076）。只读标签页不显示。
- 顶部是进度（已锁定 / 应锁定），底部是闸门：没锁完时"进分镜"是灰的，并写明"定妆没锁完，分镜不开"。
- 只对有近景 / 特写的角色要求四格；群演和背影角色不白白生成三视图。

## 十、等待：生成是分钟级的

这是体验设计里最容易被忽略的部分。

- **异步 + 可离开**：提交后可关页面，完成推送。
- **进度可见**：不是转圈，而是"第 7/25 镜生成中"。
- **先给草稿**：draft 先出，用户先看构图，再决定要不要 final。
- **队列透明**：高峰期显示预计等待。
- **失败可续**：中断后从断点继续，不从头再来。

**等待时的正确做法是让用户去干别的，而不是盯着进度条。**

---

## 十一、空状态与默认值

P6 说"默认 AI 初稿，人只做改"。UI 上要落实：

- 新建项目：给 3 个 logline 候选，不是一个空输入框。
- 每个阶段：进入即有可用结果，按钮是"换一个"而不是"生成"。
- 参数：有推荐值，不是空白。
- 没有灵感：模板库 + 题材矩阵（STORY.md）。

---

## 十二、错误不是报错，是诊断

生成失败时，不要弹"生成失败 (code 500)"。要给：

```
这张脸和角色档案不一致（相似度 0.62，阈值 0.75）
可能原因：角度太侧 / 光线太暗
[ 换正面角度 ] [ 提高亮度重试 ] [ 用这版 ]
```

对应 CONSISTENCY.md 的"失败维度 + 修复路由"。**每个错误都要有下一步动作。**

---

## 十三、设计语言

来自 PRODUCT.md 的品牌调性：**暗房 / 影院**，不是赛博朋克。

- 深色底，低饱和，留白多。
- 强调色克制，只用于"当前动作"和"确认"。
- 光影是视觉主角：缩略图大、边框少。
- 字体：无衬线为主，字幕预览用实际字体。
- 动效：少而慢，服务于"确认感"，不炫技。

具体令牌、布局解剖与图标规范见 [DESIGN-SYSTEM.md](DESIGN-SYSTEM.md)。

## 十五、失败模式

| 失败 | 表现 | 原因 | 对策 |
| --- | --- | --- | --- |
| 功能堆砌 | 首屏全是按钮 | 按工具组织 | 按阶段组织 |
| 时间线恐惧 | 用户不敢动 | 专业界面前置 | 默认折叠 |
| 参数焦虑 | 不知道该调什么 | 参数全暴露 | 四层披露 |
| 等待流失 | 生成时关掉 | 无异步/无推送 | 可离开 + 通知 |
| 错误劝退 | 报错看不懂 | 技术错误直出 | 诊断卡 + 修复 |
| 移动端照搬 | 手机上没法用 | 缩小版桌面 | 只做审批/分享 |
| 确认后悔 | 锁了才发现错 | 没讲清代价 | 闸门说清影响 |

## 十六、验收指标

| 指标 | 目标 |
| --- | --- |
| 首次出片时间 | ≤ 30 分钟（P10） |
| 新建 → 首个可用 logline | < 2 分钟 |
| 阶段流失率 | 每阶段 < 15% |
| 闸门确认耗时 | < 3 分钟/次 |
| 用户手动改镜比例 | 20–40%（太低=没参与感，太高=AI 不行） |
| 移动端审批占比 | > 30%（说明伴侣端有用） |

## 十七、一句话

**默认路径是一条"向导"，不是一块"画布"。**
用户每一步都看到"下一步做什么"，每个结果都能"换一个"，每个错误都有"怎么办"；时间线和参数是第二层，永远不挡在主路径上。
