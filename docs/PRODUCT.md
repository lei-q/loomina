# 产品定位

## 一句话

**织光机 Loomina：让一个人也能做出有电影感的竖屏短剧。**

`Loomina = loom（织机）+ luminous（光）`；中文"织光机"取"编织光影"。名字承诺的不是"AI 生成视频"，而是**视听语言**。

## 目标用户（C 端）

**核心用户**
- 个人短视频创作者 / 剧情号博主
- 网文作者、短剧爱好者
- 影视/传媒专业学生

**共同点**：有表达欲、有故事，但**没有剧组**（没有演员、场地、摄影、后期）。

**初期不做**
- 专业影视公司（B 端）：需求是产能与流程管控，不是易用性
- 电商带货 / 口播视频：另一套产品逻辑
- 通用 AI 视频工具用户：红海，不碰

## 市场

- 首发：**中国大陆**，竖屏 9:16，单集 60–180 秒。
- 分发目标：抖音、小红书、B 站、微信视频号；后续 TikTok、X。
- 语言：中文配音 + 中文字幕优先。

## 非目标（Non-goals）

明确不做，避免摊薄：

1. 不自研基础生成模型（只做网关与编排）。
2. 不做移动端剪辑（移动端只做**发布伴侣**）。
3. 不自研专业 NLE（不自建达芬奇/剪映级编辑器）。
4. 首期不做多人实时协作。
5. 首期不做全平台 API 发布（先导出 + 手动 / 分享扩展）。
6. 不做通用素材库 / 图床 / 社区（除非后期证明是增长引擎）。

## 差异化（四条，按重要性排序）

1. **一致性**：角色/场景/道具有档案，有"连续性监工"自动查穿帮。这是短剧的生死线。
2. **故事结构**：内置竖屏短剧语法（3 秒钩子、15–20 秒一个拐点、结尾留钩）+ 剧本医生。
3. **光影表达**：可量化的摄影语言系统（光比/色温/焦段/运镜/构图/LUT），名字的承诺。
4. **一条龙**：剧本 → 分镜 → 生成 → 配音 → 配乐 → 字幕 → 发布包，不换工具。

## 品牌与视觉调性

- 中文名：**织光机**；英文：**Loomina**；Slogan：*stories woven into light*。
- 调性关键词：暗房、放映厅、暖光、胶片颗粒、留白、克制。
- 避免：紫蓝渐变、赛博朋克、"AI 味"的廉价科技感。
- 产品气质应是**导演的工作台**，不是**模型的控制台**。

## MVP 成功指标

| 指标 | 目标 |
| --- | --- |
| 首次出片时间 | 非专业用户 30 分钟内产出 60s 可发布竖屏片 |
| 镜头一次通过率 | ≥ 50%（无需人工重试） |
| 整体生成成功率 | ≥ 70% |
| 角色一致性人工通过率 | ≥ 80% |
| 单条 60s 成本 | 记录基线，后续优化（不设硬指标） |

## 商业模式

暂不设定，先打磨产品。但保留三种可能，设计时注意不要堵死：

1. **订阅制**（工具费）
2. **按生成量计费**（算力加价）
3. **创作分成 / 平台分账**（内容侧）

成本敏感点：视频生成的重试次数是成本大头，必须在架构上支持草稿预览与缓存复用。

## 关键约束（来自当前团队）

- **单人开发**：架构必须"少运维、可托管、模块边界清晰"。
- **模型 API 预算充足**：可以不省钱，但要不浪费（缓存、预览、批量）。
- **无短剧行业资源 / 无 IP**：内容侧先做原创生成 + 模板，版权合作放后期。
