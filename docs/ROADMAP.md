# 路线图

> 约束：**单人开发**。所以每个阶段都必须是"能独立发布、能验证假设"的闭环。
> 原讨论中的 8–12 周按单人全职调整为 **16–22 周**（含契约层、能力测绘与 3D 最小版），宁可慢，不要烂尾。

## Phase 0 — MVP：证明"一个 C 端用户能 30 分钟出片"

**周期**：约 16–22 周（单人全职，含契约层、能力测绘与 3D 最小版）
**目标**：一句话/一段大纲 → 60 秒竖屏短剧 → 导出可发布文件。

### 验收标准（缺一不可）

1. 无视频经验的人，30 分钟内完成一条 60s、3–5 个镜头、1 个场景、2 个角色的竖屏片。
2. 角色在全部镜头中可辨识为同一人（人工通过率 ≥ 80%）。
3. 对白时长与画面时长自动对齐，无需手动变速。
4. 自动出字幕、自动配乐、自动混音，可逐项手动改。
5. 导出 MP4（1080×1920，H.264），带 AI 标识，可直接上传抖音/小红书。
6. 全流程成本可记账，能回答"这一条片子花了多少钱"。

### 明确不在 MVP

- 剧本医生（A2）、口型同步（C3）、节拍卡点（C5）、自动 QA（B4）
- 多比例适配（E5）、移动端分享扩展（G3）、官方 API 发布（G4）
- 协作、模板市场、摄影指导面板完整版

### 落地顺序（按风险退休，不按功能堆叠）

详细步骤见 [TECH-SELECTION.md](TECH-SELECTION.md) 第八节，这里只列节奏：

| 步骤 | 周期 | 先验证什么 |
| --- | --- | --- |
| S0 契约层 | 1–2 周 | IR、网关接口、状态机、提示词契约是否够用 |
| S1 能力测绘 | 1 周 | 模型的真实边界、单价、**商用条款** |
| S1.5 3D 最小版 | 2–3 周 | 灰盒场景板能否支撑摆位/机位/轴线 |
| S2 Animatic 闭环 | 2–3 周 | 低成本能否看出故事与节奏问题 |
| S3 单镜质量 | 3–4 周 | 一致性阈值与重试成本 |
| S4 前端骨架 | 3–4 周 | C 端能否在 UI 内走到 animatic |
| S5 时间线与渲染 | 3–4 周 | 预览与成片的差距 |
| S6 发布包 | 1–2 周 | 发布流程是否顺畅 |

> **S0–S3 不写 UI，先用脚本验证契约与质量。** 这四步验证的是不可逆或高成本的东西；先做 UI 会导致返工。

>
> **S1 进行中**：适配器与测绘 CLI 已完成（[MODEL-GATEWAY.md](MODEL-GATEWAY.md)、ADR-0025）；真实样片被配额 429 阻塞，首次通过率与失败维度待补。
>
> **S5 部分完成（2026-11-11）**：时间线（`timeline.updated`）、自动初剪、时间线上换 take、成片页 `/edit`、字幕两档模板，以及本地导出 HTML / OTIO / SRT / 发布包（ADR-0086）。字幕断句与识别链路已补上（ADR-0087）。**成片 MP4 已通本地路径（ADR-0091）**：1080×1920 / 30fps / H.264 + AAC，字幕与「AI 生成」角标烧进画面，容器元数据写 `AI生成`；远端视频不下载，用首帧或占位图并计数。**仍未满足的部分**：供应商远端视频没有转存，带真实视频的项目只能渲到首帧 / 占位；没有配乐、响度归一化与平台码率校验。
>
> **S4 故事入口打通（2026-11-11）**：`/story` 用一次文本模型调用产出标题、logline、人物弧光、关系、地点、道具、场次、镜头与初稿台词（A1 / A3 / A4，ADR-0088）。草稿只留在页面内存，确认「用它开工」才写一条新的 `project.created`，随后跳到 `/script` 继续改。`TEXT_MODEL` 已配 `claude-sonnet-5-5`；实测一次 60–100 秒，一份 12–14 镜 18–23 句的草稿估时 60 秒上下。**未做**：逐段重生成、草稿暂存、Beat / 覆盖率、成本记账。
>
> **F6 导入剧本 txt 打通（2026-11-11）**：`/story` 增加「导入剧本 txt」：本地读 `.txt`（UTF-8 / GB18030，≤2MB）或粘贴，最多 2 万字，必须勾选权利声明。模型把原文改写成 60–90 秒单集草稿，保留人物关系、核心冲突与结局意思，允许合并次要人物与场次；结果标「改编稿」，确认后同样写新项目（ADR-0089）。实测 199 字原文生成 13 镜 / 21 句 / 62.6s。**未做**：逐字导入、章节拆分、保真校验、原文对照。
>
> **H5 AI 标识落地（2026-11-11）**：成片页播放器与导出预览 HTML 都有常驻「AI 生成」角标，不可关闭；预览 HTML 带 `ai-generated` / `ai-label-standard` 元数据，OTIO 与发布包写 `aiLabel`，成片 MP4 烧进角标并写 `comment=AI生成`（ADR-0090 / ADR-0091）。**未做**：强隐式标识（签名 / 水印）、按平台安全区调整角标、G8 导出前统一合规预检。

## 明确砍掉 / 长期不做

| 事项 | 原因 |
| --- | --- |
| 自研基础模型 | 重资产，非差异化 |
| 移动端剪辑 | 交互不适合，违反 P10 的"简单"反而更复杂 |
| 自研 NLE | 数人年投入，难超剪映（ADR-0004） |
| 全平台逆向自动发布 | 封号与法律风险（ADR-0006） |
| 通用素材社区 | 分散精力，除非验证为增长引擎 |
