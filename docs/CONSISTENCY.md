# 跨镜头一致性：8 个维度与 5 层防线

> 本文回答"跨镜头一致性如何解决"。
> 结论先行：**一致性不是一个开关，而是 8 个独立问题；没有任何单一手段能同时解决，必须分层。**
> 量化指标与阈值需要在自有样片上标定，本文给的是方法与默认值。

---

## 一、先把"一致性"拆开

观众说"这不是同一个人"，背后可能是完全不同的原因：

| 维度 | 具体表现 | 主要手段 | 可量化指标 |
| --- | --- | --- | --- |
| 1. 身份 | 脸型、五官、发型、年龄、体型变了 | 角色三视图 + 多参考图 + 身份 LoRA + 路由到身份保持强的模型 | 人脸 embedding 余弦相似度 |
| 2. 服化道 | 衣服颜色/款式、配饰、伤口、手持物变了 | 服装/道具参考图 + 清单式提示词 + 局部重绘 | VLM 清单 + 颜色相似度 |
| 3. 场景 | 同一个房间的布局、家具、窗外景色变了 | 场景主镜 + 场景参考图 + 3D 灰盒 | VLM + 感知哈希 |
| 4. 光影 | 主光方向、色温、光比、明暗关系变了 | LightingSpec 参数化 + 统一 LUT | 色温估计、Lab 均值、直方图 |
| 5. 空间 | 人物左右关系、朝向、轴线错乱 | 3D 场景板 + ContinuityLedger | 机位参数 + 人工 |
| 6. 表演 | 情绪断裂、姿态突变、能量不一致 | 关键帧表情 + 音频驱动 + 表演描述 | 人工 + VLM |
| 7. 动作 | 切点接不上、动作方向反了 | 在动作中段切（cut on action）+ 动作匹配 | 光流 + 人工 |
| 8. 风格 | 颗粒、锐度、镜头感、调色不统一 | LUT + 颗粒 + 统一提示词模板 | 人工 + 风格分类 |

> 产品上不要给用户一个"一致性"滑块；要给**分维度的诊断与修复**。

## 二、五层防线

### 第 1 层：资产锚定（最强、最便宜）

**角色**
- 生成角色**三视图**（正面、3/4、侧面、背面）+ 表情表 + 服装变体，作为"定妆照"。
- 参考图不是越多越好：**每次生成 2–4 张**（脸 + 全身 + 服装），过多会互相干扰。
- 可选增强：在角色定妆图上训练 **identity LoRA**（若自建推理）或使用支持主体参考的模型。
- 角色档案里明确 `mustNotChange`：痣、疤、发型分缝、耳饰、纹身。

**场景**
- 每个场景先生成一张 **master shot（主镜）**，作为该场景所有镜头的"空间与光线锚点"。
- 场景参考图 2–3 张（全景 + 细节 + 不同机位）。

**道具**
- 关键道具单独生成特写参考图，尤其是"有叙事作用"的道具（戒指、伞、伤口、信件）。

**锁定**
- 资产一旦通过闸门 1，写入 `Approval.lockedAssetIds`；下游只能引用，不能悄悄替换。

### 第 2 层：结构锚定（3D + 关键帧）

**3D 灰盒场景板**
- 用简单几何体搭出场景（房间、街道、办公室），人物用胶囊 + 朝向箭头表示。
- 相机用真实焦距可视化视锥；直接得到机位、朝向、焦段。
- 自动检查 180 度轴线；导出 `CameraPosition` 与 `Blocking`。
- 可渲染 **depth / edge / normal** 参考图，作为关键帧生成的结构条件（图像阶段最可靠）。

**关键帧优先**
- 先出首帧/尾帧，确认角色与构图，再图生视频（ADR-0002）。
- **首尾帧只用于连续动作/同空间过渡**；跳切不要用尾帧接首帧，否则会把上一个机位的错误带进来。

**场景主镜**
- 同一场景的所有镜头都以 master shot 为参考图之一，减少"每镜重新想象房间"。

### 第 3 层：生成约束

- **seed 管理**：同一角色/场景在允许范围内复用 seed；换 seed 是修复身份漂移的第一手段。
- **提示词模板**：角色描述用固定 token 串（"same woman, 28, short black bob, mole under left eye, beige trench coat"），不要每次改写。
- **模型路由**：能力矩阵里记录每个模型的 `identityPreservation`、`referenceCount`、`firstLastFrame`、`cameraControl`；有人物的镜头路由到身份保持强的模型，空镜走便宜模型。
- **负向约束**：明确写"不要改变发型/服装/年龄"。

### 第 4 层：量化验收

每个镜头生成后，自动产出 `ConsistencyReport`：

```ts
interface ConsistencyReport {
  shotId: ID;
  identity: { score: number; perCharacter: { characterId: ID; score: number }[] };
  wardrobe: { score: number; issues: string[] };
  scene: { score: number; issues: string[] };
  lighting: { score: number; issues: string[] };
  spatial: { score: number; issues: string[] };
  style: { score: number };
  overall: number;          // 加权
  threshold: number;        // 按景别不同
  verdict: "pass" | "review" | "fail";
}
```

具体方法：

| 维度 | 方法 | 说明 |
| --- | --- | --- |
| 身份 | **人脸 embedding 余弦相似度**（ArcFace/InsightFace 类） | 与角色定妆图比对；抽 3–5 帧取中位数。阈值需在自有数据上标定，不要照搬论文 |
| 服化道 | **VLM 检查清单** + 主色相似度 | 让多模态模型回答"是否同一件衣服/是否戴戒指" |
| 场景 | VLM 对比场景参考图 + **pHash** | 静态背景可用感知哈希；动态镜头用 VLM |
| 光影 | 估计色温 + Lab 均值 + 直方图距离 | 比 VLM 更稳定；用于发现"突然变冷/变亮" |
| 空间 | 3D 机位参数 + 人工 | 自动估计相机姿态不可靠，不硬做 |
| 表演/动作 | 人工 + VLM 抽查 | 目前最可靠的还是人眼 |

**阈值按景别分级**：
- 特写/近景：身份要求最严（脸占画面大）。
- 中景：身份中等，服装要求高。
- 全景：场景与空间要求高，身份可放宽。

### 第 5 层：后期统一

- **LUT / 调色**：统一色温、对比、饱和度，能掩盖一部分光影差异（但掩盖不了身份）。
- **颗粒 / 锐化**：统一质感，减少"这镜头是另一个模型做的"的感觉。
- **不要用换脸去修一致性**：法律与肖像风险高，artifact 也明显；应重生成。

## 三、失败诊断与修复路由

QA 失败时，先判断是哪个维度，再走对应修复，而不是盲目重抽：

| 失败维度 | 第一修复 | 第二修复 | 第三修复 |
| --- | --- | --- | --- |
| 身份 | 补/换参考图，固定 seed | 换身份保持更强的模型 | 重生成关键帧，再生成视频 |
| 服化道 | 补道具/服装参考，强化清单提示词 | 局部重绘 | 重生成 |
| 场景 | 加 master shot 作参考 | 换机位/角度 | 重建场景参考 |
| 光影 | 重新编译 LightingSpec | 调色统一 | 重生成 |
| 空间 | 3D 板重摆机位，修正轴线 | 补过渡镜 | 重分镜 |
| 表演 | 调关键帧表情/音频 | 换 Take | 重生成 |
| 动作 | 切点前移到动作中段 | 补反应镜 | 重分镜 |

**重试预算**：每镜默认 3 次；每次失败扣预算；超限转人工或降级（换模型/用已有 Take/空镜）。

## 四、诚实地说：一致性有天花板

以下情况当前技术做不到"完全一致"，产品要主动规避，而不是承诺：

1. **侧面/背面**：模型训练以正脸为主，侧后视角容易"变人"。
2. **复杂花纹/logo/文字**：衣服图案、徽章、纹身细节极易漂移。
3. **儿童、老人、特殊面容**：训练数据少，稳定性差。
4. **多人同框**：人数越多，身份越容易混淆。
5. **单镜内长时间**：5 秒以上，人物会逐渐变形。
6. **极端角度**：俯拍、仰拍、大特写、镜面反射。
7. **强光/逆光/暗部**：脸部信息不足，身份难以保持。

**产品策略**：
- 分镜时主动规避（少背影、少复杂花纹、少多人、少长镜）。
- 验收分级：特写严、全景松。
- 人工兜底永远是最后一道防线（准则 P6/P7）。

## 五、与数据模型的映射

| 概念 | IR 字段 |
| --- | --- |
| 角色定妆图 | `Character.referenceImages` |
| 不可变特征 | `Character.mustNotChange` |
| 场景主镜 | `Location.referenceImages[0]` |
| 场景空间 | `SceneState` / `Blocking` |
| 每镜参考图 | `Shot.referenceAssetIds` |
| 生成溯源 | `Take.model / seed / prompt / referenceAssetIds` |
| 验收结果 | `Take.qa` / `ConsistencyReport` |
| 锁定资产 | `Approval.lockedAssetIds` |
