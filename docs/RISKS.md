# 风险登记

> 只登记"会影响项目成立"的风险，不登记琐碎问题。
> 每季度回看一次；状态：未处理 / 缓解中 / 已缓解 / 已接受。
> 法规类条目**以主管部门最新口径为准**，本文仅作产品设计输入，不构成法律意见。

## 五、优先级最高的五件事

1. **R1 / R2 合规路径**——决定能不能上线。
2. **R16 一致性**——决定产品成不成立。
3. **R12 / R23 成本与单位经济**——决定能不能持续。
4. **R17 故事质量**——决定用户会不会回来。
5. **R18 单人节奏**——决定能不能做完。

> 这五条中任何一条失败，其他做得再好都没有意义。定期回看本表。
